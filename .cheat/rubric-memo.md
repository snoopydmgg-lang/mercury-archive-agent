### 2026-05-14 中国传统色v2-余上沅 (0eb93ce389ff) — composite 8.0 → 实绩 497（10x 高估）

- 预测：composite=8.0，bucket=命中(2,095-13,120)，中枢 5,000
- 实绩：播放 497（底部桶）/ 赞 8（赞播比 1.61%）/ 评论 0 / 收藏 5 / 转发 0
- 留存漏斗：2s 跳出 45% → 5s 完播 32-35% → 平均播放 7s → 完播率 3.91%（T+4d）
- Top 评论关键词：无（零评论）
- 判断：
  - **form_mismatch 是 10x 级误差源**：v0 rubric 为观点类设计，产品带货在所有维度系统性虚高——带货内容比观点内容多一层"用户初始排斥"
  - **HP=5 被多指标推翻**：2s 跳出 45% 说明近半数人没给钩子机会；5s=32% 看似还行但与 2s 跳出对照后真相是"没划走的人里有一部分多看了几秒"而非"钩子有效"；平均播放 7s 说明钩子到内容过渡断裂
  - **单一 5s 完播率不足以判断钩子** —— 必须组合 2s 跳出 + 5s 完播 + 平均播放 + 完播率四个指标
  - **AB=5 被推翻**：带货内容的受众宽度 = 刷到 3 秒内产生"我需要"的人数，远小于"对这个主题有兴趣"的人数
  - **零评论零转发 = 内容没有社交货币**：未设计让观众做任何动作的理由
- Rubric 调整方向：
  - 产品带货内容 → 所有维度降 1-2 档（不只是 AB/SR，HP 也要降）
  - HP 改用四指标组合判断（2s 跳出 / 5s 完播 / 平均播放 / 完播率）
  - 增加「互动触发点」检查
