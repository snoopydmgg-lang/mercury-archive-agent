# 中国传统色 v2 — 余上沅的奇妙屋

## 文案1：余上沅的奇妙屋风格

### 口播文案

红配绿，在中国传统色里从来不俗。黄配紫，也从来不脏。

不是古人审美有多好——他们用的配色系统，跟我们今天完全不一样。24节气。

立春的青色配雨水的水蓝色，是春天田野里刚冒出来的嫩芽配融雪。小暑的朱砂红配大暑的琉璃黄，是盛夏午后太阳晒在瓦片上的颜色。寒露的霜白配霜降的枯褐，是深秋清晨草叶上那层薄霜的颜色。

郭浩把这套系统整理成了384种中国传统色。不是随便排的——每种颜色在它的节气里都有天然CP。盈盈是桃花映水的少女粉，它的配色搭子是雨水节气的冻缥——冰镇美酒的半透明清冷。一暖一冷，天生一对。

这本书最狠的地方是：每种颜色标注了CMYK和RGB。不是让你欣赏的，是让你直接用的。暮山紫配米白是一套东方极简VI，老僧衣是茶叶研末的禅意灰，对标莫兰迪但有文化出处。

你不需要重新发明配色法则。老祖宗已经给你排好了384套。
