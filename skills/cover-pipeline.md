# 封面自动化流水线

将用户需求（产品名称 + 核心概念）转化为高质量 3:4 竖版封面，全自动完成。

## 视觉系统规范

### 色彩系统

| 角色 | 色值 | 名称 |
|------|------|------|
| 主背景 | #F5F4F0 | 羊皮纸白 |
| 主文本 | #2D2B2A | 暖炭灰 |
| 核心点缀 | #D36B4D | 赤陶土 |
| 辅助柔和 | #E6C8B5 | 灰桃色 |

### 字体规范
- 主标题：衬线体 (Georgia / 宋体)
- 副标题/元数据：无衬线体 (微软雅黑)

### 质感要求
- 必须：2-5% 单色噪点 + 纸张纹理
- 禁止：发光、高饱和渐变、重阴影

## 流水线三步骤

```
Step 1: 调用图生图API生成纯背景底图 (新古典人文主义Prompt)
         ↓
Step 2: PIL渲染文字 + 有机分形 + 噪点纹理
         ↓
Step 3: 输出封面 PNG
```

## 封面规格

| 参数 | 值 |
|------|-----|
| 画布尺寸 | 1080x1440 (3:4) |
| 图片区域 | 顶部 0-700px |
| 文字区域 | 700-1440px |
| 主标题 | 80px, 衬线体, #2D2B2A |
| 副标题 | 32px, 无衬线体 |
| 噪点纹理 | 2.5% 单色噪点 |
| 输出格式 | PNG, 95%质量 |

## 使用方法

```bash
python auto_cover_engine.py --title "版式之道" --concept "控制视觉熵的物理工程"
```

## Prompt 模板（新古典人文主义风格）

```
画面主体：根据'[核心概念]'转化的有机抽象形态，
例如折叠的纸张/贝壳纹理/花瓣分形/叶脉结构。
视觉约束：新古典人文主义风格，古典印刷术质感，
大地色系（米色/桃色/赤陶色），有机生命体隐喻。
构图约束：画面上半部分70%展示主体，
画面下半部分30%保持纯色负空间留白。
质感要求：细微纸张纹理，2%-5%噪点颗粒感。
反向约束：禁止文字、水印、3D效果、重阴影、霓虹光效。
```
