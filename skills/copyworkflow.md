# 文案生成工作流

完整的短视频文案生成工作流，串联背景信息收集、文案生成、配音全流程。

## 功能

| 步骤 | 功能 | 说明 |
|------|------|------|
| 1 | 收集背景信息 | 使用搜索 API 收集产品/书籍背景资料 |
| 2 | 上传飞书 | 将背景信息上传到飞书多维表格 |
| 3 | 生成文案 | 调用 LLM API 生成口播文案、详细分镜、BGM、音效 |
| 4 | 配音 | 从 MD 文件读取文案，调用 TTS API 生成配音 |
| 5 | 完整流程 | 一步完成所有步骤 |

## 输出格式（强制执行）

生成的文案必须包含详细分镜格式：

| 时间 | 画面分镜指令（摄影师看） | 口播文案（参考） | BGM与音效指令（剪辑师看） |
| :--- | :--- | :--- | :--- |
| 00-05s | 景别+运镜+动作 | 当前对应文案 | BGM：具体乐器+情绪 / SFX：具体动作音 |

**约束**:
1. 画面分镜：必须包含景别（特写/全景/中景）+ 运镜（推/拉/摇/移/固定）+ 主体动作
2. BGM：禁止"好听的音乐"，必须描述：乐器 + 节奏 + 情绪
3. SFX：必须精确到具体动作音
4. 节奏卡点：文案有转折时标注"音乐骤停"或"变奏"

## 使用方法

```bash
python copyworkflow_runner.py
```

### 完整流程

```
选择"完整流程" → 输入项目名称 → 选择风格
自动完成：
1. 收集背景信息 → 保存到项目文件夹
2. 上传到飞书多维表格
3. 生成文案 → 输出到 MD 文件
4. 配音 → 自动更新飞书（口播文案、画面脚本、BGM建议、音效建议、配音链接）
```

## 代码模块

- `workflow.py` - 工作流编排
- `search_client.py` - 背景信息收集
- `feishu_client.py` - 飞书操作
- `script_generator.py` - 文案生成（含详细分镜格式）
- `md_exporter.py` - MD 文件导出/读取
- `audio_generator.py` - 配音生成
