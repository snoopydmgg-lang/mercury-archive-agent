# 水星艺术馆 — AI Agent 驱动的短视频内容创作系统

基于 **Claude Code** 构建的多模型协作 Agent 自动化流水线，覆盖短视频电商内容生产全链路：

**选品 → 文案生成 → 内容诊断 → 封面设计 → 配音合成 → 飞书发布 → 数据复盘**

## 架构概览

```
用户输入产品名
    ↓
Agent 自主拆解任务
    ↓
┌─────────────────────────────────────┐
│  知识库检索（选题库/模板库/违禁词库）  │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  三套风格文案并行生成                  │
│  学术风格 / 走心风格 / 痛点风格        │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  内容诊断（自动评分 + 修正闭环）        │
│  AI味检测 → 开头强度 → 表达效率 → 认知落差 │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  多模态输出                           │
│  图生图 API → 3:4封面                 │
│  TTS引擎 → 配音合成                   │
│  飞书API → 多维表格自动上传            │
└─────────────────────────────────────┘
```

## 多模型协作

| 模型 | 角色 | 典型任务 |
|------|------|----------|
| Claude 系列 | 主控 Agent + 创意引擎 | 文案生成、内容诊断、任务编排、错误恢复 |
| DeepSeek 系列 | 辅助推理引擎 | 批量数据分析、关键词提取 |
| MiniMax 系列 | 多模态引擎 | 封面图生图、TTS 语音合成 |

## 48 个自定义 Skill

Agent 通过 Skill 体系编排全流程，每个 Skill 封装一个专业能力模块：

- **内容创作**: 文案工作流 · 内容诊断 · 开头优化 · 标题生成
- **商业诊断**: 商业模式诊断 · 对标分析 · 概念拆解 · 执行力诊断
- **多模态**: 封面流水线 · 图生图 · 封面生成器
- **自动化**: 文件夹整理 · CLI工具生成 · 网页抓取
- **集成**: 飞书文档/表格/日历/知识库/即时通讯

## 长链推理

一次文案生成涉及 8+ 决策节点：

1. 解析产品名 → 2. 检索知识库 → 3. 加载风格模板 → 4. 并行生成三套文案 → 5. 自动诊断评分 → 6. 发现开头偏弱 → 7. 检索模板库重写 → 8. 再诊断通过 → 9. 输出

Agent 具备错误自愈能力：脚本报错 → 读取日志 → 匹配历史教训库 → 定位根因 → 修改代码 → 重跑验证。
