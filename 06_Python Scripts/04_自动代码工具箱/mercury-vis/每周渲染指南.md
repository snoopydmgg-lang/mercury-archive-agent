# 每周渲染指南

> **超傻瓜教程** - 5分钟完成每周7个视频开场渲染

---

## 准备工作 (只需做一次)

```bash
# 进入项目目录
cd E:/1.work/douyin/1.shuixing/mercury-vis

# 安装依赖
npm install
```

---

## 每周工作流 (重复执行)

### Step 1: 修改文案

打开文件 **`video_data.json`**，修改里面的7组文案：

```json
[
  { "mainTitle": "本周主题1", "subTitle": "副标题1", "volNumber": "VOL.01" },
  { "mainTitle": "本周主题2", "subTitle": "副标题2", "volNumber": "VOL.02" },
  ...共7组...
]
```

| 字段 | 含义 | 示例 |
|------|------|------|
| `mainTitle` | 主标题(大字) | 宫崎骏的幻想世界 |
| `subTitle` | 副标题(小字) | 吉卜力的艺术美学 |
| `volNumber` | 期号 | VOL.01 |

---

### Step 2: 一键渲染

在终端输入：

```bash
node batch_render.js
```

等待约2-3分钟，7个MP4视频会自动生成在 `./dist/` 目录。

## 常见问题

**Q: 渲染失败？**
A: 确保已安装依赖: `npm install`

**Q: 想只渲染1个视频？**
A: 临时删除 `video_data.json` 中不需要的条目，只保留1个，然后运行 `node batch_render.js`

**Q: 视频尺寸是多大？**
A: 竖屏 1080x1920 (9:16)，适合抖音/小红书
