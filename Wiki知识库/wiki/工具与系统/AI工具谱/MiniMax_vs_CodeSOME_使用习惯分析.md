## 五、使用习惯演变分析

### 阶段一：MiniMax 单一依赖（03-12 至 04-11）

**特点**：
- 批量脚本为主（背景研究、文案生成）
- 高峰期（16时）遭遇限流
- 成本极低（¥49/月覆盖1.47亿token）

**痛点**：
- 16时峰值落在限流窗口（15:00-17:30）
- 单 Agent 并发限制
- 不支持 Claude Code 交互式开发

### 阶段二：MiniMax + CodeSOME 双轨（04-13 起）

**配置**：
- MiniMax：保留批量脚本调用（¥49/月）
- CodeSOME 月卡：Claude Code 日常开发（¥289/月）
- CodeSOME 按量：高峰/月卡不稳时备用（$100余额）

**优势**：
- 批量脚本继续走 MiniMax（成本优势）
- 交互式开发走 CodeSOME（工具优势）
- 双保险：月卡不稳时切按量

**成本**：
- MiniMax ¥49/月（批量）
- CodeSOME ¥289/月（交互）
- 总计：¥338/月（+ 偶尔按量消耗）

## 六、优化建议

### 1. 场景分离策略

| 场景 | 推荐工具 | 原因 |
|------|----------|------|
| **背景研究**（Perplexity脚本） | MiniMax | 成本低，批量调用 |
| **文案生成**（AI文案脚本） | MiniMax | 成本低，批量调用 |
| **数据分析**（pandas + AI） | MiniMax | 成本低，批量调用 |
| **Claude Code 开发** | CodeSOME 月卡 | 交互式，工具优势 |
| **高峰期紧急任务** | CodeSOME 按量 | 稳定性最好 |

### 2. 时段优化

**避开 MiniMax 限流窗口（15:00-17:30）**：
- 批量脚本任务调整到 10-14时 或 18-22时
- 16时高峰改用 CodeSOME

**利用深夜无限流时段（22:00-02:00）**：
- 定时任务（文案生成、数据分析）放深夜跑
- MiniMax 和 CodeSOME 都无限流

### 3. 成本控制

**当前配置成本**：
- MiniMax ¥49/月（保留）
- CodeSOME 月卡 ¥289/月
- 总计：¥338/月

**优化方案**：
- 如果 Claude Code 使用频率低 → 降级到 CC月卡15刀（¥138/月）
- 如果批量脚本可迁移到 CodeSOME → 停掉 MiniMax（省¥49/月）
- 如果高峰期不再限流 → 停掉 CodeSOME 按量备用（省$100）
