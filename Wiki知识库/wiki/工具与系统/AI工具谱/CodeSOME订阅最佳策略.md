## 二、场景分离策略（最优方案）

### 核心原则

**MiniMax 做批量，CodeSOME 做交互**

| 场景 | 工具 | 月成本 | 原因 |
|------|------|--------|------|
| 批量脚本调用 | MiniMax Coding Plan | ¥49 | 1.47亿token仅¥49，性价比无敌 |
| Claude Code 交互开发 | CodeSOME 月卡 | ¥138-289 | 工具优势，交互式体验 |
| 高峰/紧急备用 | CodeSOME 按量 | 按需 | 稳定性最好 |

### 方案对比

#### 方案A：MiniMax + CodeSOME 月卡15刀（推荐）

| 项目 | 月费 | 覆盖场景 |
|------|------|----------|
| MiniMax Coding Plan | ¥49 | 批量脚本（背景研究、文案生成、数据分析） |
| CodeSOME CC月卡15刀 | ¥138 | Claude Code 日常开发（日均$8.64，15刀够用） |
| CodeSOME 按量$100 | 备用 | 月卡用完或不稳时切换 |
| **总计** | **¥187/月** | 全场景覆盖 + 双保险 |

**优势**：
- 成本最低（¥187/月）
- 批量脚本走 MiniMax（极致性价比）
- 交互开发走 CodeSOME（工具优势）
- $100 按量兜底（稳定性保障）

**适用条件**：
- Claude Code 使用频率：中等（日均$8.64以内）
- 批量脚本需求：高（继续用 MiniMax）

---

#### 方案B：MiniMax + CodeSOME 月卡30刀（当前配置）

| 项目 | 月费 | 覆盖场景 |
|------|------|----------|
| MiniMax Coding Plan | ¥49 | 批量脚本 |
| CodeSOME CC月卡30刀 | ¥289 | Claude Code 开发（日均$30额度，冗余245%） |
| CodeSOME 按量$100 | 备用 | 高峰/不稳时切换 |
| **总计** | **¥338/月** | 全场景覆盖 + 高冗余 |

**优势**：
- 额度充裕（$30/天 vs 实际$8.64/天）
- 可应对峰值日（如03-27的1.30亿token）
- 双保险（月卡 + 按量）

**劣势**：
- 成本较高（¥338/月）
- 冗余过大（245%），浪费

**适用条件**：
- Claude Code 使用频率：高（可能超$15/天）
- 追求稳定性，不在意成本

---

#### 方案C：纯 CodeSOME 月卡30刀（不推荐）

| 项目 | 月费 | 覆盖场景 |
|------|------|----------|
| CodeSOME CC月卡30刀 | ¥289 | 所有场景（批量 + 交互） |
| **总计** | **¥289/月** | 单一工具 |

**劣势**：
- 批量脚本走 CodeSOME 成本高（MiniMax ¥49 vs CodeSOME 按token计费）
- 放弃 MiniMax 的极致性价比
- 单点故障（CodeSOME 不稳时无备用）

**不推荐原因**：
- 你的批量脚本消耗大（1.47亿token/月），走 CodeSOME 会快速耗尽月卡额度
- MiniMax ¥49/月包月太香，没理由放弃

## 四、最佳策略推荐

### 🏆 推荐方案：方案A（MiniMax + CodeSOME 月卡15刀）

**月成本**：¥187（MiniMax ¥49 + CodeSOME ¥138）

**配置**：
1. **MiniMax Coding Plan（¥49/月）**
   - 用途：批量脚本调用
   - 场景：背景研究、文案生成、数据分析
   - 时段：避开15:00-17:30限流窗口

2. **CodeSOME CC月卡15刀（¥138/月）**
   - 用途：Claude Code 交互式开发
   - 额度：$15/天（覆盖日均$8.64，剩余$6.36冗余）
   - 时段：全天可用

3. **CodeSOME 按量$100（备用）**
   - 用途：月卡用完或不稳时切换
   - 约可撑11.5天满负荷使用

### 操作步骤

#### 立即执行

1. **降级月卡**：
   - 当前 CC月卡30刀（¥289）到期后
   - 改买 CC月卡15刀（¥138）
   - 节省：¥151/月

2. **保留 MiniMax**：
   - 继续使用 Coding Plan（¥49/月）
   - 批量脚本不迁移到 CodeSOME

3. **配置 cc-switch**：
   - CodeSOME-Sonnet（月卡15刀）：日常 Claude Code
   - CodeSOME-Backup（按量$100）：备用
   - MiniMax：批量脚本

#### 监控指标

**每日检查**：
- CodeSOME 月卡消耗是否 < $15/天
- 如果超过 → 考虑升级到30刀或切按量

**每周检查**：
- MiniMax 是否在15:00-17:30限流
- 如果限流严重 → 调整脚本执行时段

**每月复盘**：
- 总成本是否 ≤ ¥187
- 月卡15刀是否够用
- 按量$100是否被动用

## 六、成本敏感度分析

### 如果 Claude Code 使用频率增加

| 日均消耗 | 推荐月卡档位 | 月费 | 总成本（含MiniMax） |
|----------|--------------|------|---------------------|
| $8.64（当前） | 15刀 | ¥138 | ¥187 |
| $12-15 | 15刀（紧张） | ¥138 | ¥187 |
| $15-25 | 30刀 | ¥289 | ¥338 |
| $25-35 | 40刀 | ¥389 | ¥438 |
| $35+ | 50刀 | ¥459 | ¥508 |

**临界点**：
- 日均消耗 < $15 → 月卡15刀最优
- 日均消耗 $15-25 → 月卡30刀
- 日均消耗 > $25 → 考虑按量付费（¥1/刀）

### 如果放弃 MiniMax

**纯 CodeSOME 方案成本**：
- 批量脚本消耗：1.47亿token/月 ≈ $441/月（按Sonnet 4.6计价）

- **结论**：放弃 MiniMax 会让成本从 ¥187/月 暴涨到 ¥459/月（+145%）

**不推荐放弃 MiniMax**。
