# Claude Code 高级配置指南

> 从临时工具到专属AI助手：双层级七文件配置体系

---

## 配置体系概览

**核心架构**：采用**双层级七文件**结构，实现全局与项目的精细化管理。

| 层级 | 文件数量 | 生效范围 | 核心功能 | 文件列表 |
|------|---------|---------|---------|---------|
| **系统层级** | 3个 | 全局生效（所有会话） | 定义基础身份、权限与规则 | `CLAUDE.md`、`settings.json`、`rules` |
| **项目层级** | 4个 | 当前项目生效 | 存储项目专属记忆与配置 | `CLAUDE.md`、`MEMORY.md`、`commands`、`settings` |

---

## 系统层级配置（全局基础）

### 1. CLAUDE.md - AI的"身份说明书"

**核心定位**：定义用户基本信息与工作方式。

**关键内容框架**：

#### (1) 身份信息
- 用户角色：如"我是独立开发者"、"我是抖音电商创业者"
- 技术栈：常用开发工具与技术框架
- 业务背景：当前从事的项目类型

**水星艺术馆示例**：
```markdown
## 用户身份
- 角色：抖音电商创业者（艺术书籍类目）
- 项目：水星艺术馆（抖音短视频带货）
- 技术栈：Python、飞书API、豆包API、GPT-SoVITS
```

#### (2) 工作准则

**三大核心准则**：

1. **先研究再动手**
   - 要求AI优先调研GitHub等平台现有工具
   - 避免重复开发
   - 示例："需要新功能时，先搜索现有开源方案"

2. **关键节点确认**
   - 重要步骤需用户确认后执行
   - 避免误操作
   - 示例："修改代码前先向用户说明计划"

3. **最小编辑面**
   - 明确工作风格与需求边界
   - 只改必要的部分
   - 示例："修复bug时只改相关代码，不重构整个文件"

#### (3) 特殊场景配置
- 多设备互联规则（如通过SSH连接操作辅助设备）
- 代理设置（如翻墙配置）
- 文件系统规则（如禁止在根目录创建文件）

**水星艺术馆示例**：
```markdown
## 特殊规则
- 禁止在根目录创建文件
- Python代码只能放在 06_Python Scripts/
- AI生成文件直接保存到对应产品项目文件夹
```

---

### 2. settings.json - 权限控制与环境管理中心

**核心定位**：权限控制与环境管理中心。

**三大功能模块**：

#### (1) 工具权限管理
- 可开启**Bypass模式**，无需重复确认即可授予AI写入/编辑权限
- 示例：允许AI自动创建文件、编辑代码

#### (2) 钩子系统
- 定义工作流触发规则
- 示例：
  - 使用工具前：检查代理设置
  - 提交前：运行代码检查
  - 结束后：更新MEMORY.md

#### (3) 环境变量存储
- 存储API密钥、模型参数等敏感配置
- 示例：
  - 飞书API密钥
  - 豆包API密钥
  - OpenRouter API密钥

**水星艺术馆配置示例**：
```json
{
  "env": {
    "FEISHU_APP_ID": "cli_a90dbd544bb8dcb2",
    "FEISHU_APP_SECRET": "dwBXEcMgSD4pxGGEqSKB3tYQDdiBwgf2",
    "DOUBAO_API_KEY": "your_doubao_key",
    "OPENROUTER_API_KEY": "your_openrouter_key"
  }
}
```

---

### 3. rules - 编码规范与安全基线

**核心定位**：代码编码规范与安全规则的强制执行文件，确保所有项目遵循统一标准。

**典型规则**：
- 代码风格：PEP8（Python）、ESLint（JavaScript）
- 安全检查：禁止硬编码密钥、禁止SQL注入
- 文件命名：统一命名规范

## 项目层级配置（场景化应用）

### 核心价值

为不同项目打造"专属AI助理"，自动加载项目记忆与规则，减少重复沟通成本。

---

### 1. 项目专属 CLAUDE.md

**核心定位**：项目背景与工作方式的详细说明。

**应用场景**：

#### 场景一：亚马逊选品项目
```markdown
# 项目背景
- 项目名称：亚马逊选品
- 选品方向：家居用品、厨房工具
- 选品策略：高频刚需、高复购率、价格适中

# 工作方式
- 每周一更新选品清单
- 使用飞书多维表格管理选品数据
- 自动生成选品报告
```

#### 场景二：短视频创作项目（水星艺术馆）
```markdown
# 项目背景
- 项目名称：水星艺术馆
- 业务类型：抖音短视频带货（艺术书籍类目）
- 内容风格：学术深度 + 内行人解码 + 知识降维

# 工作方式
- 使用 /copywriter 生成文案
- 遵循个人视觉系统设计规范
- 封面比例必须是 3:4（1080x1440）
```

---

### 2. MEMORY.md - 项目专属记忆库

**核心定位**：项目专属记忆库（系统层级无此文件）。

**关键作用**：
- 自动加载历史交互记录
- 保存产品信息、选品规则等项目数据
- 支持跨会话内容延续与关联

**水星艺术馆 MEMORY.md 示例**：
```markdown
# 项目记忆

## 文案生成工作流（2026-04-21 重构）
- 使用 /copywriter Skill 替代 Python 脚本
- 三大风格：余上沅、九厘米的雾、Ad Scout
- 配置文档：Wiki知识库/wiki/文案生成配置.md

## 知识库寻址规则（2026-04-14）
- 新路径：Wiki知识库/（根目录）
- 旧路径：03_Assets_全局库/（仅用于资产）
- 强制寻址优先级：
  1. Wiki知识库/wiki/文案创作/选题库/
  2. Wiki知识库/wiki/
  3. Wiki知识库/raw/
```

---

### 3. commands - 项目专属命令集

**核心定位**：项目专属命令集，优化特定场景操作效率。

**示例**：
- `/copywriter` - 生成三套文案
- `/dbs-content` - DBS内容检定
- `/cover-generator` - 生成封面

---

### 4. settings - 项目专属配置

**核心定位**：项目级别的配置项，覆盖系统层级未包含的个性化需求。

**示例**：
- 项目专属环境变量
- 项目专属权限设置
- 项目专属钩子

---

## 配置实施路径

### 第一步：基础构建（系统层级）

1. **编写 CLAUDE.md**
   - 定义用户身份
   - 设定工作准则
   - 配置特殊场景规则

2. **配置 settings.json**
   - 设置工具权限
   - 配置钩子系统
   - 存储环境变量

3. **定义 rules**
   - 编码规范
   - 安全规则

---

### 第二步：项目适配（项目层级）

1. **创建项目专属 CLAUDE.md**
   - 记录项目背景
   - 定义工作方式
   - 配置项目规则

2. **初始化 MEMORY.md**
   - 记录关键决策
   - 保存项目数据
   - 记录历史教训

3. **配置 commands 和 settings**
   - 定义项目专属命令
   - 配置项目专属设置

---

### 第三步：协同生效

**系统配置 + 项目配置 = 项目专属AI助理**

进入项目文件夹后，AI自动加载：
- 系统层级配置（全局规则）
- 项目层级配置（项目专属规则）
- 项目记忆（历史数据）

实现"一次配置，永久复用"。

---

## 关键价值

### 1. 效率提升
- 避免重复介绍项目背景与规则
- AI自动加载记忆
- 减少沟通成本

### 2. 一致性保障
- 全局规则确保工作流与安全标准统一
- 所有项目遵循相同的编码规范

### 3. 个性化定制
- 项目层级配置满足不同场景的差异化需求
- 每个项目都有专属AI助理

## 水星艺术馆配置示例

### 系统层级 CLAUDE.md（部分）

```markdown
# 用户身份
- 角色：抖音电商创业者（艺术书籍类目）
- 项目：水星艺术馆
- 技术栈：Python、飞书API、豆包API、GPT-SoVITS

# 工作准则
- 先确认方案再动手
- 禁止在根目录创建文件
- Python代码只能放在 06_Python Scripts/

# 代理设置
终端无法访问GitHub时：
```powershell
$env:HTTP_PROXY="http://127.0.0.1:7890"
$env:HTTPS_PROXY="http://127.0.0.1:7890"
```
```

### 项目层级 CLAUDE.md（部分）

```markdown
# 项目概述
水星艺术馆 — 抖音电商项目（艺术品类目）
业务流：选品 → 文案生成(/copywriter) → 视频制作(外包) → 性能追踪 → 资产管理

# 文案生成工作流
使用 /copywriter Skill：
- 三大风格：余上沅、九厘米的雾、Ad Scout
- 配置文档：Wiki知识库/wiki/文案生成配置.md

# 视觉规范强制遵守
生成所有图片、封面、文件版式时，必须严格遵循：
- 色彩系统：主背景 #F5F4F0、主文本 #2D2B2A、点缀色 #D36B4D
- 封面比例：3:4（1080x1440）
```
