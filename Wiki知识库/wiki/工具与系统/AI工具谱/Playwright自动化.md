# Playwright 浏览器自动化指南

> AI + Playwright CLI = 零成本浏览器自动化，减少 4 倍 Token 消耗

---

## 核心技术框架

**技术组合**：
- **AI框架**：Claude Code 或 Codex（自然语言驱动）
- **浏览器自动化工具**：**Playwright CLI**（2026年初微软开源）
- **浏览器**：Chrome（推荐）或 Edge

**关键优势**：
- 相比传统 Playwright MCP 方案**减少 4 倍 Token 消耗**
- 支持**零 AI 参与**的全自动脚本执行
- 仅需自然语言即可完成复杂任务

---

## 工具准备与基础配置

### 前置依赖安装

1. **Node.js**
   - 下载：https://nodejs.org/
   - 安装后验证：`node --version`

2. **Playwright CLI**
   ```bash
   npm install -g @playwright/cli
   ```

3. **浏览器**
   - 推荐：Chrome（兼容性更佳）
   - 备选：Edge

---

### 基础命令测试

**启动浏览器**：
```bash
playwright cli [命令] --headed
```

**参数说明**：
- `--headed`：启用有头模式（便于调试，可以看到浏览器操作）
- 默认：无头模式（静默运行，不显示浏览器窗口）
- `--persistent`：保存 cookie、登录状态，避免重复登录

**核心特性**：
- **网页摘要输出**：仅返回简洁摘要，详细结构需读取本地快照文件（减少上下文占用）
- **截图本地化**：截图保存为本地文件而非直接传入 AI 上下文
- **状态持久化**：保存登录状态，避免重复登录

## AI 框架接入与 Skill 配置

### Claude Code 框架接入

1. **新建项目文件夹**
   ```bash
   mkdir playwright-automation
   cd playwright-automation
   ```

2. **安装 Playwright CLI Skill**
   - 将 Skill 文件夹放入项目目录 `.claude/skills/`

3. **验证 Skill 加载**
   - 启动 Claude Code
   - 询问："你有哪些 skills？"
   - 确认 Playwright CLI 技能已加载

---

### 基础任务测试

**案例**：使用 Playwright CLI 打开网页，查询信息。

**示例命令**：
```
使用 Playwright CLI 打开百度，搜索"抖音选品技巧"
```

**AI 自动完成**：
1. 打开浏览器
2. 导航到百度
3. 输入搜索关键词
4. 点击搜索按钮
5. 返回结果

## 进阶应用与效率优化

### 应用一：商品评论抓取与 CSV 导出

**场景**：抓取抖音商品评论，分析用户反馈。

**首次执行**（AI 自主探索）：
1. 打开商品页
2. 验证 URL
3. 点击"查看全部评价"
4. 执行 JS 获取评论
5. 保存为 CSV

**消耗**：41% 上下文窗口

**Skill 固化**（提炼流程为 Skill）：
- 将流程提炼为 Skill
- 包含复用逻辑与避坑指南

**二次执行**（依赖 Skill 指导）：
- 仅消耗 **5% 上下文窗口**
- 效率提升近 **10 倍**

**零 AI 脚本化**（生成独立脚本）：
- 生成 PowerShell 脚本
- 无需 AI 参与，直接运行
- 完全自动化

---

### 应用二：Markdown 文章自动发布到社交平台

**痛点**：
- 直接粘贴 Markdown 格式错乱
- 图片丢失
- HTML 格式图片需手动替换

**自动化流程**：

1. **预处理**（Python 脚本）
   - 下载图片并编号
   - 转换为本地图片 Markdown
   - 通过 Pandoc 转为 HTML

2. **发布执行**（Playwright CLI）
   - 自动打开社交平台
   - 创建草稿
   - 粘贴 HTML 内容
   - 删除图片占位符
   - 按顺序上传本地图片

**成果**：
- 生成可复用 Skill
- 配套脚本
- 实现"输入文章路径即可自动发布"

---

### 应用三：Web App 自动化测试

**场景**：定期测试网站功能，发现 bug。

**测试文档生成**（AI 阅读代码）：
- 输出中文测试文档
- 包含注册、登录、功能验证步骤

**自动化执行**（Playwright CLI）：
1. 注册测试账号
2. 登录
3. 创建测试数据
4. 上传文件
5. 验证主体流程

**扩展应用**：
- 结合定时任务框架
- 实现系统定期自动测试
- 自动发现 bug

## 技术趋势

**Playwright CLI + Skill 组合正在取代传统 MCP 方式**，成为浏览器自动化的主流方案。

**优势对比**：

| 维度 | 传统 MCP | Playwright CLI + Skill |
|------|---------|----------------------|
| Token 消耗 | 高（4倍） | 低 |
| 学习成本 | 高（需要编程） | 低（自然语言） |
