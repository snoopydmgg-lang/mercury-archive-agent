## 四、月卡 + 按量共存操作方案

当前配置（2026-04-13）:
- 按量付费 $100（余额模式，留作备用）
- CC月卡 每天30刀/¥289（日常 Claude Code 使用）
- API Key: sk-f0c...106a
- Base URL: https://cc.codesome.ai
- cc-switch Provider: CodeSOME-Sonnet

### 切换步骤：让 Claude Code 走月卡而非按量

1. 登录控制台: https://cc.codesome.ai
2. 进入【兑换】页面，输入月卡兑换码完成激活
3. 进入【API Key 管理】或【令牌】页面
4. 找到当前使用的 API Key（sk-f0c...106a）
5. 将该 Key 的分组从「余额分组」切换到「订阅/月卡分组」
6. 保存后，Claude Code 自动走月卡额度，$100余额不再被扣

如果控制台不支持同一 Key 切换分组，则:
- 在月卡分组下新建一个 API Key
- 用 cc-switch 更新 CodeSOME-Sonnet 的 ANTHROPIC_AUTH_TOKEN 为新 Key
- 或者新建一个 Provider（如 CodeSOME-Monthly）专门走月卡

### 验证是否切换成功

使用后到控制台查看:
- 月卡额度是否在减少（说明走月卡了）
- 按量余额是否不变（说明没被扣）

### 双模式使用策略

| 场景 | 走哪个 | 原因 |
|------|--------|------|
| 日常 Claude Code 开发 | 月卡（每天30刀） | 性价比高，¥289/月覆盖$900 |
| 月卡当日额度用完 | 按量（$100余额） | 自动或手动切换到余额分组 |
| 高峰期月卡不稳定 | 按量（$100余额） | 按量稳定性更好 |
| 月卡到期未续费 | 按量（$100余额） | 保证不断档 |

成本预估:
- 月卡日常: ¥289/月（每天$30额度，你日均消耗约$8.64，绰绰有余）
- 按量$100备用: 约可撑11.5天满负荷使用
- 总月成本: ¥289 + 偶尔按量消耗

## 八、风险提示

1. 非官方渠道 -- 存在封号/跑路/服务中断风险
2. 每日额度清零制 -- 月卡未用完的当日额度不累积到次日
3. 高峰期不稳定 -- 13:00-18:00 可能出现响应慢或中断
4. 模型差异 -- GPT5.4 定制版与官方 Claude 模型可能存在差异
5. 订阅缓存问题 -- 使用第三方后切回官方需执行 fix-sub（见 [[cc-switch使用指南]]）
