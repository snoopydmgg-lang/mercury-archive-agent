## Obsidian + Claudian 快速参考

### Obsidian
- **定位**：本地优先的 Markdown 笔记应用
- **核心优势**：所有笔记都是独立 Markdown 文件，软件停更笔记也不会丢失
- **关键功能**：双向链接、知识图谱可视化

### Claudian 插件
- **定位**：将 Claude Code 以图形化界面接入 Obsidian
- **核心功能**：
  - 图形化侧边栏，无需命令行
  - 直接拖拽文件引用
  - 可视化上下文管理
  - 自动读取 CC Switch 配置

**安装方式**：
1. 通过 BRAT 插件管理器安装
2. 仓库地址：`https://github.com/YishenTu/claudian`
3. 支持多种 API（官方 Claude、DeepSeek、智谱 GLM、CC Switch）

## Graphify 快速参考

### 核心价值
- **70倍 token 压缩**：原始需处理 10万字代码，压缩后仅需 1400字
- **多模态支持**：处理代码、PDF、截图、录音等多种格式
- **自动更新**：代码修改后实时同步图谱
- **完全本地**：零数据库依赖，确保数据隐私

### 工作流水线
```
Detect → Ingest → Build → Cluster → Analyse → Report → Export
```

### 核心输出文件

| 文件名 | 作用 |
|--------|------|
| `graphify_graph_report.md` | 知识摘要，汇总项目架构全貌 |
| `graph.html` | 图谱可视化看板（网页格式） |
| `graph.json` | 图谱原始数据源，支持自定义查询 |
| `cache/` | 增量编译核心，仅处理变动代码 |

### 使用场景
- 代码库知识图谱构建
- 大型项目架构理解
- 多模态知识管理（代码、PDF、截图、录音）

## extract-getnote-articles

**位置**：`C:/Users/Administrator/.claude/skills/extract-getnote-articles`

**功能**：批量爬取 Get笔记博主文案
**速度**：并行模式 25-30 篇/分钟
**特点**：断点续传、自动去重、博主文件夹命名

**使用**：
```bash
cd "C:/Users/Administrator/.claude/skills/extract-getnote-articles"
node extract.js "<完整URL>" "<输出目录>" <最大页数> <最大文章数> <并发数>

# 示例
node extract.js "https://www.biji.com/subject/qY2BZ56Y/DEFAULT?followId=1206096&followName=%E5%8F%A4%E6%9C%88%E5%AE%89%E7%9A%84%E5%AE%9D%E8%97%8F" "E:/1.work/douyin/1.shuixing/古月安的宝藏" 0 0 3
```

**参数说明**：
- 最大页数：0=全部
- 最大文章数：0=全部
- 并发数：默认3，建议不超过5

## 知识库维护流程

### 每日工作流（Karpathy 推荐）

**早晨**：
- 📖 浏览 RSS/Twitter，发现好文章
- 📌 一键 Clip 到 Obsidian `raw/`

**中午**：
- ☕ 午休时打开 Claudian
- ⚡ 执行 `/compile`
- 🤖 AI 自动整理上午收集的资料

**晚上**：
- 📝 打开 `wiki/concepts/` 浏览今日新增概念
- 💡 结合灵感，开始写作

---

### 每月健康检查

**自动检查**（在 Claudian 中执行）：
```bash
/lint
```

**手动检查**（Python 脚本）：
```bash
python "06_Python Scripts/06_工具/wiki_lint.py"
```

检查项：死链 / 孤立页面 / 索引一致性

### 知识图谱可视化

**查看方式**：
- 点击 Obsidian 左侧"查看关系图谱"
- 所有笔记以节点形式平铺
- 有链接关系的笔记用线条连接

**Canvas 画布**：
- 使用 `/json-canvas` Skill 创建结构化画布
- 可视化复杂的知识关系
- 适合项目规划和思维导图
