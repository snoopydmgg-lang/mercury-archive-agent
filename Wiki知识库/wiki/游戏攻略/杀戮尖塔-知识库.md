## 一、游戏概述

《杀戮尖塔》是一款融合 Roguelike + 回合制卡牌策略 + 牌组构筑的游戏。玩家选择角色从高塔底层向上攀登，每次死亡为永久死亡，地图、敌人、卡牌均为随机生成。

- **4 位可玩角色**：铁卫军（Ironclad）、静默猎人（Silent）、故障机器人（Defect）、观者（Watcher）
- **楼层结构**：3 大层 + 隐藏第 4 层（终幕），每层终点有 BOSS
- **游戏模式**：标准模式、进阶模式（1-20级）、每日挑战、自定义模式
- **胜利条件**：击败第 3 层 BOSS（或解锁终幕后击败第 4 层 BOSS）

## 二、核心机制

### 2.1 战斗系统

- **回合制**：玩家与敌人轮流行动，敌人意图完全可见
- **每回合**：抽 5 张牌，获得 3 点能量（基础值）
- **手牌管理**：回合结束未使用的手牌全部弃置。抽牌堆耗尽时，弃牌堆洗入抽牌堆
- **格挡（Block）**：临时护盾，仅在本回合有效，回合结束时清零
- **能量（Energy）**：打出卡牌所需的资源，每回合重置

### 2.2 地图与路线

```
地图为树状分支结构，从下往上攀登。
节点类型：
├── 一般敌人（Enemy）：金币 + 选牌 + 可能药水
├── 精英敌人（Elite）：金币 + 选牌 + 遗物 + 可能药水
├── 休息处（Rest）：回血 ~20HP 或 强化一张卡牌
├── 商店（Shop）：买卡/遗物/药水 + 删牌服务
├── 事件（?）：随机文字事件，有好有坏
├── 宝箱（Chest）：金币 + 随机遗物
└── BOSS：金币 + 选牌 + BOSS 遗物 3 选 1
```

### 2.3 资源体系

| 资源 | 换算/说明 |
|------|-----------|
| 火堆（休息处） | ≈ 20 点回血 或 1 次永久强化。通常优先强化 |
| 金币 | 普战 +10，精英 +30，BOSS + 更多 |
| 商店 | 约等于半个火堆，一条路线上的商店+火堆总数与其他路线差异不大 |
| 药水 | 战斗中一次性使用，上限 3 瓶 |

### 2.4 涅奥的祝福

每局开局可从大鲸鱼涅奥处选择起始祝福。如果上局见到第一层 BOSS，有 4 个选项（包含需代价的高奖励选项）。如果上局未见到 BOSS 就死亡，只有 2 个选项：
- **涅奥的悲恸**：前 3 场战斗敌人血量变为 1（若有精英在 3 场内则极有价值）
- **最大生命值上升**

**技巧**：选择祝福前先点右上角地图查看路线，判断"悲恸"能否覆盖精英。

## 三、卡牌系统

### 3.1 卡牌类型

| 类型 | 特征 | 说明 |
|------|------|------|
| **攻击牌（Attack）** | 红色边框 | 直接造成伤害 |
| **技能牌（Skill）** | 蓝色边框 | 提供格挡/抽牌/其他辅助效果 |
| **能力牌（Power）** | 金色边框 | 整场战斗持续生效，使用后移出牌堆 |
| **状态牌/诅咒牌** | 灰色/黑色 | 负面效果（晕眩、伤口、烧伤等），通常无法主动打出，占用抽牌位 |
| **无色牌** | 白色边框 | 可通过商店/事件获得，不限于特定角色 |

### 3.2 卡牌评价维度

每张卡从以下 5 个维度评价：
1. **费用与效果** — 基础数值
2. **升级效果** — 强化后的提升幅度
3. **用途** — 在卡组中发挥什么作用（输出/防御/过牌/辅助）
4. **抓取时机** — 什么时候该拿、什么时候不该拿
5. **相性** — 与什么牌/遗物配合好，与什么牌冲突

### 3.3 四角色专属特色

| 角色 | 初始遗物 | 专属机制 | 核心风格 |
|------|---------|---------|---------|
| 铁卫军 | 燃烧之血（战后回血 6） | 力量、消耗、自伤 | 卖血输出 / 叠甲反击 / 力量流 |
| 静默猎人 | 蛇之戒指（首回合多抽 2） | 毒、小刀、弃牌 | 毒流 / 小刀流 / 弃牌流 |
| 故障机器人 | 破损核心（战斗开始生成 1 充能球） | 充能球（电/冰/黑暗/等离子） | 球流 / 能力流 / 无限流 |
| 观者 | 纯净之水（战斗开始进入平静） | 姿态切换（平静/愤怒/神格） | 姿态流 / 无限流 / 高爆发 |

## 四、卡组构建理论（核心）

> 以下内容来自游民星空攻略《牌组构建思路与心得》（作者 morgana_xmu）

### 4.1 节奏（Tempo）理论

**节奏定义**：两个火堆之间的战斗消耗的血量。
- **亏节奏**：损失血量过多 → 被迫在火堆休息 → 失去强化机会
- **抢节奏**：损失血量较少 → 火堆强化 → 永久战力提升

**能力牌**属于典型的亏节奏牌——费用越高亏损越多。第一回合打 3 费恶魔形态意味着无法叠盾只能卖血。
**过牌卡**前期也亏节奏，因为花 1 费抽卡占用了防御所需能量。
**0 费牌**不损失节奏，可弥补过牌亏损。

**节奏卡**：同时提供攻击+防御的卡（如"当头棒喝"2 费打 12 + 获得等额格挡）。在愤怒状态下打 24 伤害 + 24 格挡，非常强力。

### 4.2 卡组组件分类

按重要性从高到低：

1. **核心卡（Win Condition）**：制胜手段——靠什么输出。
   - 第一层输出压力小，第二层起压力急剧增大
   - 例如：暴怒 + 心如止水、暴怒 + 招牌技、毒雾 + 催化剂
2. **支点卡（Enabler）**：保证核心卡能打出的护航卡。
   - 例如：猛虎下山（进入愤怒抽 2）配合暴怒体系；过牌卡保证快速抽干牌库
3. **一般组件**：填充卡，提供基础攻防

**关键原则**：
- 核心卡和支点卡是逐步加入的，需不断调整
- 拿到关键遗物后，构筑思路往往围绕遗物展开——遗物成为支点
- **能力卡上限**：15 张牌的卡组最多投入 2 张能力卡，否则连续让节奏导致血线危险

### 4.3 小卡组 vs 大卡组

| | 小卡组（≤15张） | 大卡组 |
|---|---|---|
| 优势 | 核心卡上手率高、易计算斩杀、手札事故率低 | 可塞复数关键卡（浓度高）、允许多套轴并行（Plan B） |
| 劣势 | 适应性差、Plan B 困难 | 需要充足过牌支撑，否则绝对劣于小卡组 |
| 数学证明 | 10 张全同种类概率 = 2/252 | 20 张全同种类概率 = 504/15504 |

**重要纠正**："大卡组稳定性更高"是**错误认知**。大卡组的优势在于允许塞入复数关键卡使浓度更高 + 允许多套轴，而非稳定性。若过牌不够，大卡组绝对劣于小卡组。

### 4.4 实例：观者符文金字塔蓄爆流

- **初始遗物交换**：换到符文金字塔（回合结束不弃牌）
- **核心思路**：利用蓄爆空间，凑齐暴怒 + 招牌技，一轮造成 80 伤害
- **防御侧**：精神护盾（按手牌数提供格挡，2 费 20+ 防御）——可拿第二张
- **攻击侧**：招牌技（2 费，手牌中只有此张攻击牌时可用）+ 暴怒（愤怒状态伤害翻倍）
- **支点卡**：天眼（观星）、评估（0 费过 2）、猛虎下山（进入愤怒抽 2）
- **BOSS 金卡**：机械降神（扩充手牌 + 额外 3 能量，与精神护盾配合极佳）
- **删牌原则**：观者先删打击而非防御（因为可能拿招牌技）
- **失误记录**：第二张天眼是多余的；精神护盾拿第二张是对的（中后期需要连续几回合高格挡）

### 4.5 常见构筑问题

| 问题类型 | 表现 | 解决 |
|---------|------|------|
| 防御有余输出不足 | 有复数"如水"+"护身"，但只有打击+暴怒 | 必须补充输出卡，否则遇到叠甲怪（如球）无法取胜 |
| 输出有余防御不足 | 招牌技+暴怒但缺乏优质防御组件 | 补充心灵堡垒/精神护盾等防御支点 |
| 贪精英 | 有黑星遗物多打精英，但防御不足导致血线快速下降 | 量力而行，评估当前卡组强度再决定路线 |
| 缺乏退姿态手段 | 暴怒状态转不回来而暴毙 | 务必备好 1 费平静卡（如内心宁静） |

### 4.6 观者无限流

- **核心卡**：猛虎下山、不惧妖邪、暴怒、内心宁静
- **支点卡**：潦草急救（过牌）
- **思路**：猛虎下山后，快速抽干牌库，暴怒 + 1 费平静卡无限连营
- **卡组规模**：至少精简到 11 张以内（能力卡打出后不再出现，实际抽卡数需扣除能力卡）
- **遗物策略**：初始换钥匙，一路宝箱不开，第二层卡组成型后多打精英攒钱删牌买遗物

## 五、怪物应对策略

### 5.1 底层（第一层）BOSS

#### 史莱姆王
- **行动**：第 1 回合塞粘液 → 第 2 回合准备 → 第 3 回合 30+ 斩杀，循环
- **特性**：血量 < 50% 后分裂为两只大型史莱姆（血量与本体相同）
- **应对**：
  - 带赌徒药水应对粘液卡手
  - 将血量控制在 50% 左右后一回合内打出最大伤害
  - 火焰药剂能同时压低两只分裂史莱姆 20 血（双倍收益）
  - 没有爆发就抓 AOE 清理分裂后的史莱姆

#### 六火亡魂
- **行动**：第 1 回合准备 → 第 2 回合斩杀 → 之后平A/塞烧伤/上 debuff/防御轮流
- **特性**：6 个蓝色火焰全部转绿后，释放斩杀（6 次攻击，受力量加成）并塞烧伤+。斩杀基础伤害与进 BOSS 时血量相关。
- **应对**：
  - 速战速决！六火自身平 A 极弱，输出空间大
  - 门前篝火可以不睡觉（进 BOSS 时血量低则斩杀伤害低）
  - 在门前适当卖血以提高输出效率

#### 守护者（高达）
- **行动**：第 1 回合上盾 → 第 2 回合斩杀 → 第 3 回合 debuff → 第 4 回合 4 连攻击
- **特性**：伤害阈值（首次 30，每次 +10），超过后进入防御模式（+20 格挡 + 3 荆棘），防御模式下攻击微弱
- **应对**：
  - 抓住节奏——第一二回合打出防御模式触发
  - 防御模式下尽量防住，起身后的旋风斩吃力量降低多，是最佳输出时机
  - 循环触发防御模式即可规避斩杀

### 5.2 底层精英

#### 三柱神
- **行动**：中间柱子和两边柱子轮流攻击/塞眩晕
- **特性**：初始带 1 层"人工制品"
- **应对**：优先清理两边柱子中血量较少的一只，剩下的慢慢耗。萌新之友，送遗物。

#### 乐加维林（乐嘉老师）
- **行动**：开战沉睡 3 回合（有格挡），被打醒则眩晕一回合。醒来后 18/20 攻击两回合、灵魂吸取（掉敏捷力量）一回合，循环。
- **应对**：
  - 需要启动的卡组趁睡觉时启动
  - 不需要启动的直接打醒
  - 攻击非常强悍，防御为主，趁灵魂吸取回合输出
  - 对低输出苟活卡组极度不友好

#### 大地精（小红）
- **行动**：第 1 回合上 buff（你使用技能牌时给它 + 力量），之后平 A/大平 A 轮流
- **应对**：最纯粹的数据检测器——考的就是卡组强度，直接硬打。下回合能斩杀时可交防御牌止损。

### 5.3 底层小怪

| 怪物 | 要点 |
|------|------|
| 虫子 | 首次受伤获得格挡，秒杀可跳过格挡，或第一回合只打一刀拖掉格挡 |
| 大史莱姆 | 血量 < 50% 分裂，同史莱姆王——控血一回合斩杀 |
| 奴隶贩子 | 攻击很痛，速战速决，被贴 buff 时疯狂输出 |
| 真菌兽（死老鼠） | 死亡时给你上易伤，与其他怪同时出现时留到后面杀 |
| 小嘴兽（kaka!） | 第 1 回合加每回合力量 buff，尽快击杀 |
| 盗贼 | 每次攻击偷钱，逃跑则损失所有钱。集中输出打死，或没钱时苟到逃跑也能拿卡牌奖励 |
| 地精群 | 优先击杀清洁工（上 debuff）和法师（蓄力斩杀），AOE 处理最方便 |

## 九、实战技巧与策略

### 9.1 通用原则

1. **路线规划优先**：开局先看地图，确认 BOSS 类型和精英位置，规划好火堆和商店的节奏
2. **删牌很重要**：删掉基础打击/防御比拿新牌更重要。每间商店必买删牌服务（价格递增：75→100→125...）
3. **不要什么牌都拿**：跳过（Skip）是最被低估的选择。不匹配核心思路的牌不要拿
4. **强化 > 休息**（通常）：强化是永久收益，只有血量危险时才休息
5. **精英不是越多越好**：贪精英前评估当前卡组强度，死掉的牌组没有输出
6. **BOSS 面前卖血**：打六火、守护者这类 BOSS 时，门前火堆不睡觉反而有利

### 9.2 各角色策略要点

**铁卫军（战士）**：
- 初始遗物回血 = 可以更激进地卖血输出
- 力量流（力量 + 多段攻击）是最经典的构筑
- 消耗体系（腐化 + 黑暗之拥）是进阶高层的强力方向
- 关键卡：恶魔形态、突破极限、死亡收割、祭品

**静默猎人（猎人）**：
- 毒流：致命毒药 + 催化剂 → 指数级毒伤
- 小刀流：无限刀刃 + 精准 + 余像 → 多段输出 + 叠甲
- 初始遗物多抽 2 + 符文金字塔 = 极强 combo
- 关键卡：催化剂、尸爆术、肾上腺素、幽魂形态

**故障机器人（机器人）**：
- 核心是充能球管理：电球（伤害）/冰球（格挡）/黑暗球（蓄力）/等离子球（能量）
- 能力流是机器人最强方向之一（多张能力牌互相叠加）
- 集中（Focus）是最强属性——提升所有球的数值
- 关键卡：偏差认知、电动力学、回响形态、耗尽

**观者**：
- 姿态切换是核心——愤怒（2 倍伤）↔ 平静（+2 能量出）
- 无限流最容易达成的角色（精简卡组到 11 张以内）
- 爆发极高但容错低——转不回来就会暴毙
- 关键卡：猛虎下山、不惧妖邪、暴怒、内心宁静

### 9.3 进阶模式（Ascension）要点

进阶 1-20 难度递增，关键变化节点：
- **进阶 10**：初始获得一张"凡庸"诅咒
- **进阶 17**：敌人伤害和行动更凶残
- **进阶 20**：击败第 3 层 BOSS 后进入第 4 层，需要击败双 BOSS

高等进阶下，"卖血换节奏"的策略需要更保守地使用。

### 9.4 终幕（第 4 层）

解锁条件：用铁卫军、静默猎人、故障机器人各通关一次。
第 4 层挑战：固定 1 个休息处 → 1 个商店 → 1 个精英 → 最终 BOSS（腐化之心）。
腐化之心有无敌回合和极高伤害，需要极其完善的卡组才能击败。

## 十、术语表

| 术语 | 解释 |
|------|------|
| 力量（Strength） | 攻击牌伤害 + 力量值 |
| 敏捷（Dexterity） | 技能牌格挡 + 敏捷值 |
| 集中（Focus） | 机器人充能球效果 + 集中值 |
| 易伤（Vulnerable） | 受到的攻击伤害 × 1.5，持续 N 回合 |
| 虚弱（Weak） | 造成的攻击伤害 × 0.75，持续 N 回合 |
| 缠绕（Entangle） | 本回合无法打出攻击牌 |
| 格挡（Block） | 本回合有效，回合结束清零 |
| 荆棘（Thorns） | 攻击者受到荆棘值的反伤 |
| 人工制品（Artifact） | 抵挡一次负面效果 |
| 连营 | 通过特定 combo 实现无限循环出牌 |
| 蓄爆 | 将关键卡留在手牌中，等待最佳时机一波打出 |
| 观星 | 查看/调整抽牌堆顶部的卡牌 |
| 保留（Retain） | 回合结束时不弃掉此牌 |
| 消耗（Exhaust） | 本场战斗中将此牌移出牌堆 |
