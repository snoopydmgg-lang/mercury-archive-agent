# 封面设计规则

**目标**: 降低2秒跳出率至 < 40%

**核心原则**: 封面必须视觉化标题，让用户一眼看懂"这个视频讲什么"

---

## 规则1: 封面必须视觉化标题

**原则**: 标题中的关键词，必须在封面中以视觉形式呈现

### 示例1: 版式设计

❌ **错误做法**:
```
标题: "留白九成的海报，才是最难的部分"
封面: 纯文字标题 + 书籍封面
```

✅ **正确做法**:
```
标题: "留白九成的海报，才是最难的部分"
封面: 实际海报案例 + 红框标注"90%留白区域"
```

**设计要点**:
- 用红框/箭头标注留白区域
- 大号文字"90%"放在显眼位置
- 对比图: 左边堆满 vs 右边留白

### 示例2: 摄影构图

❌ **错误做法**:
```
标题: "光圈差1档，照片价值差10倍"
封面: 纯文字标题 + 书籍封面
```

✅ **正确做法**:
```
标题: "光圈差1档，照片价值差10倍"
封面: 左右对比图
       左边: f/8光圈照片 + 标注"¥500"
       右边: f/1.4光圈照片 + 标注"¥5000"
```

**设计要点**:
- 用左右分屏展示对比
- 用箭头标注光圈参数
- 用价格标签强化"价值差10倍"

### 示例3: 艺术鉴赏

❌ **错误做法**:
```
标题: "17万张手稿，全部手绘"
封面: 宫崎骏照片 + 文字标题
```

✅ **正确做法**:
```
标题: "17万张手稿，全部手绘"
封面: 手稿堆积如山的画面 + 大号数字"17万"
```

**设计要点**:
- 用实际手稿照片制造视觉冲击
- 大号数字"17万"占据画面1/3
- 用箭头指向手稿细节

---

## 规则2: 封面必须有"数字"

**原则**: 数字是最强的视觉锚点，必须在封面中突出显示

### 2.1 数字的视觉层级

**优先级排序**:
1. **大号数字** > 文字说明
2. **对比数字** > 单一数字
3. **百分比/倍数** > 绝对数值

### 示例1: 大号数字

```
标题: "77种版式策略"
封面设计:
  - 大号数字"77"占据画面中心（字号 > 100pt）
  - 小字说明"种版式策略"放在数字下方
  - 背景: 版式案例的网格系统
```

### 示例2: 对比数字

```
标题: "野路子 vs 科班，报价差3倍"
封面设计:
  - 左边: "¥500"（野路子）
  - 右边: "¥5000"（科班）
  - 中间: 大号"3倍"
  - 背景: 左右对比的设计作品
```

### 示例3: 百分比

```
标题: "留白比例高达70%"
封面设计:
  - 大号"70%"占据画面右上角
  - 用红框圈出留白区域
  - 背景: 实际海报案例
```

---

## 规则3: 封面必须有"对比"

**原则**: 对比制造视觉冲击，让用户立即看到"差距"

### 3.1 对比类型

| 对比类型 | 适用场景 | 视觉呈现 |
|----------|----------|----------|
| 左右对比 | 野路子 vs 科班 | 左右分屏 + 打叉/打勾 |
| 前后对比 | 优化前 vs 优化后 | 上下分屏 + 箭头 |
| 数字对比 | 价格/倍数差距 | 大号数字 + 对比色 |
| 色彩对比 | 普通 vs 高级 | 饱和色 vs 低饱和色 |

### 示例1: 左右对比

```
标题: "野路子和科班的差距"
封面设计:
  - 左边: 堆满元素的海报 + 红色打叉 + "野路子"
  - 右边: 留白的海报 + 绿色打勾 + "科班"
  - 中间: 大号"VS"
```

### 示例2: 前后对比

```
标题: "掌握网格系统，报价翻3倍"
封面设计:
  - 上半部分: 无网格的设计 + "优化前 ¥500"
  - 下半部分: 有网格的设计 + "优化后 ¥5000"
  - 中间: 向下箭头 + "3倍"
```

### 示例3: 数字对比

```
标题: "光圈差1档，照片价值差10倍"
封面设计:
  - 左边: f/8照片 + 红色"¥500"
  - 右边: f/1.4照片 + 绿色"¥5000"
  - 中间: 大号"10倍"
```

---

## 规则4: 封面必须有"标注"

**原则**: 用红框/箭头/文字标注关键信息，降低理解成本

### 4.1 标注工具

| 工具 | 用途 | 颜色 |
|------|------|------|
| 红框 | 圈出关键区域 | #FF0000 |
| 箭头 | 指向重点 | #FF0000 或 #FFD700 |
| 文字标签 | 说明数字/参数 | 白底黑字 或 黑底白字 |
| 打叉/打勾 | 对错判断 | 红色打叉 / 绿色打勾 |

### 示例1: 红框标注

```
标题: "留白比例高达70%"
封面设计:
  - 背景: 日本海报案例
  - 红框: 圈出留白区域
  - 文字标签: "70%留白"放在红框旁边
```

### 示例2: 箭头标注

```
标题: "网格系统决定设计报价"
封面设计:
  - 背景: 带网格的海报
  - 箭头: 指向网格线
  - 文字标签: "12列网格"
```

### 示例3: 打叉/打勾

```
标题: "野路子和科班的差距"
封面设计:
  - 左边: 野路子作品 + 红色打叉
  - 右边: 科班作品 + 绿色打勾
```

---

## 规则5: 封面必须符合"3秒可读"原则

**原则**: 用户在3秒内必须看懂封面要表达什么

### 5.1 信息层级

**优先级排序**:
1. **核心数字**（最大，最显眼）
2. **关键词**（次大，辅助理解）
3. **背景图**（最小，提供场景）

### 5.2 字号规范

| 元素 | 字号 | 字重 | 颜色 |
|------|------|------|------|
| 核心数字 | 80-120pt | Bold | #FF0000 或 #FFD700 |
| 关键词 | 40-60pt | Bold | #FFFFFF 或 #000000 |
| 说明文字 | 24-36pt | Regular | #FFFFFF 或 #000000 |

### 示例: 信息层级

```
标题: "留白比例高达70%，报价高3倍"
封面设计:
  - 第1层（最大）: "70%" + "3倍"（80pt，红色）
  - 第2层（次大）: "留白" + "报价"（50pt，白色）
  - 第3层（背景）: 日本海报案例（模糊处理）
```

---

## 规则6: 封面必须与视频内容一致

**原则**: 封面承诺 = 视频内容，避免"标题党"

### 6.1 一致性检查清单

- [ ] 封面中的数字，视频中有详细讲解
- [ ] 封面中的案例，视频中有展示
- [ ] 封面中的对比，视频中有拆解
- [ ] 封面中的结论，视频中有验证

### 示例1: 一致性良好

```
封面: "留白70%，报价高3倍" + 实际海报案例
视频内容:
  - 0-10秒: 展示该海报的留白比例
  - 10-20秒: 讲解为什么留白能提升报价
  - 20-30秒: 对比野路子和科班的报价差距
  - 30-40秒: 总结: 掌握留白，报价翻3倍
```

### 示例2: 一致性差

❌ **错误做法**:
```
封面: "留白70%，报价高3倍"
视频内容: 只讲理论，没有实际案例，没有报价对比
结果: 用户感觉被骗，2秒跳出率 > 60%
```

---

## 规则7: 封面必须符合视觉规范

**原则**: 遵循个人视觉系统设计规范

### 7.1 色彩系统

| 用途 | 颜色 | 使用场景 |
|------|------|----------|
| 主背景 | #F5F4F0 | 封面底色 |
| 主文本 | #2D2B2A | 关键词文字 |
| 点缀色 | #D36B4D | 核心数字、箭头 |
| 强调色 | #FF0000 | 红框、打叉 |
| 成功色 | #00FF00 | 打勾 |

### 7.2 字体系统

| 用途 | 字体 | 字重 |
|------|------|------|
| 核心数字 | Playfair Display / Georgia | Bold |
| 关键词 | Inter / 思源黑体 | Bold |
| 说明文字 | Inter / 思源黑体 | Regular |

### 7.3 纹理系统

- 必须添加 **2-5%** 单色噪点或纸张纹理
- 禁止: 高饱和渐变、重阴影、发光效果

---

## 规则8: 封面比例必须是 3:4（1080x1440）

**原则**: 抖音/小红书封面必须竖屏 3:4 比例

### 8.1 尺寸规范

| 平台 | 比例 | 尺寸 | 文件格式 |
|------|------|------|----------|
| 抖音 | 3:4 | 1080x1440 | JPG/PNG |
| 小红书 | 3:4 | 1080x1440 | JPG/PNG |

### 8.2 安全区域

```
总高度: 1440px
  - 顶部安全区: 0-200px（避免被UI遮挡）
  - 核心内容区: 200-1240px（放置关键信息）
  - 底部安全区: 1240-1440px（避免被UI遮挡）
```

## 使用指南

### 1. 封面设计流程

```
Step 1: 提取标题关键词
  - 标题: "留白九成的海报，才是最难的部分"
  - 关键词: "留白"、"九成"、"海报"

Step 2: 选择视觉呈现方式
  - "留白" → 实际海报案例
  - "九成" → 大号数字"90%"
  - "海报" → 红框标注留白区域

Step 3: 设计信息层级
  - 第1层: "90%"（最大）
  - 第2层: "留白"（次大）
  - 第3层: 海报案例（背景）

Step 4: 添加标注
  - 红框圈出留白区域
  - 箭头指向关键部分

Step 5: 检查一致性
  - 封面承诺 = 视频内容？
  - 3秒可读？
  - 符合视觉规范？
```

### 2. 常见错误

❌ **错误1: 纯文字封面**
```
封面: 只有标题文字，没有视觉元素
结果: 用户无法快速理解内容，2秒跳出率高
```

✅ **正确做法**:
```
封面: 视觉案例 + 数字标注 + 关键词
```

---

❌ **错误2: 封面与内容不符**
```
封面: "留白70%，报价高3倍"
视频: 只讲理论，没有案例
结果: 用户感觉被骗，2秒跳出率 > 60%
```

✅ **正确做法**:
```
封面承诺的内容，视频中必须有详细讲解
```

---

❌ **错误3: 信息过载**
```
封面: 10个关键词 + 5个数字 + 3张图
结果: 用户看不懂，3秒内无法理解
```

✅ **正确做法**:
```
封面: 1个核心数字 + 1-2个关键词 + 1张背景图
```
