## 一、产品核心信息

### 核心数据

#### 产品规格
- **收录作品**：11部经典（从《龙猫》到《你想活出怎样的人生》）
- **全系列**：26部动画（吉卜力工作室全作品）
- **形式**：原画手稿绘本，非截图、非二创，高清全彩还原
- **物理质感**：高克重铜版纸，一比一还原手绘质感，纸张挺括有声
- **附带内容**：电影导演创作备忘录、完整剧本、从未曝光的插图与手稿、人物索引、DVD推荐

#### 关键数字
- **17万张手稿**，每一张都是手绘
- **4秒地震镜头**，打磨了整整15个月
- **101分钟动画**，全手绘完成
- **85岁**，还在一笔一画地画

### 产品卖点

#### 内容体系
- 官方唯一授权简体中文版绘本，吉卜力工作室亲自监修
- 原画手稿高清全彩还原，翻开每一页都像走进他的工作室
- 收录电影导演最初提出的创作备忘录和完整剧本
- 吉卜力团队（本田雄、武重洋二）的心路历程

#### 适合人群
- **父母人群（25-40岁，有孩子）**：陪孩子看《龙猫》结果自己哭了，想把这份温柔留在书架上
- **设计师人群**：学习手绘技法、色彩运用、分镜构图
- **动画从业者**：学习叙事结构、世界观构建、角色塑造
- **艺术收藏者**：官方授权限量绘本，值得收藏一生

### 权威背书

#### 作者/品牌
- 日本动画大师，吉卜力工作室核心
- 奥斯卡最佳动画长片
- 柏林金熊奖
- 《千与千寻》成为全世界最温柔的童话

#### 评分与口碑
- 吉卜力工作室官方唯一授权
- 简体中文版绘本，官方审核认定
- 25-40岁受众对久石让音乐有极强的童年记忆锚点

## 二、产品故事

> 文案的灵魂。每个故事都能直接用在开头或中间段。有几个写几个，不强求分类。

- **85岁还在画**：腰痛得直不起来，手指发颤，每天坐进那间小小的工作室，一笔一画地画
  - 细节：CG和AI时代，全行业都在用电脑，他坚持手绘。17万张手稿，每一张都是手画的
- **七次退休七次复出**：每次都说"这是我最后一部"，每次都食言，这个"骗子"骗了全世界
  - 细节：媒体每次都报道他退休了，观众每次都信了，结果他又带着新作品回来了
- **17万张手稿**：4秒的地震镜头，打磨了整整15个月
  - 细节：101分钟的动画，全手绘完成。别的工作室用CG省时间，他用手稿换灵魂
- **为了动画自己先画漫画**：提案被拒"没有原著改编的动画没卖点"，他就自己创作漫画《风之谷》
  - 细节：对抗商业保守主义，最后拿下奥斯卡和柏林金熊奖
- **边画边改的创作方式**：别的导演先写剧本再画分镜，宫崎骏是边画分镜边想剧情
  - 细节：《千与千寻》里千寻认出父母那段，原本是"通过考验"，画到后面觉得"太套路"，直接改成"靠直觉认出"
- **给角色加缺陷**：《哈尔的移动城堡》画到一半，觉得"哈尔太完美了"，临时加了"哈尔变成怪物"的剧情
  - 细节：不在乎剧情是否严丝合缝，只在乎"这个角色是否真实，这个情节是否打动人"
- **无用镜头的价值**：《龙猫》里小月和小梅在院子里玩水、《千与千寻》里千寻坐电车看窗外、《魔女宅急便》里琪琪发呆
  - 细节：这些镜头对剧情推进没有任何作用，但它们让你感觉"这个世界是真实的"。不是在讲故事，而是在创造一种"生活感"

## 六、三大风格适配

## 七、四维约束

> copywriter 生成画面脚本时的硬约束，确保文案可被拍成视频。

### 视觉化转化

| 抽象概念 | 视觉替代方案 |
|---------|-------------|
| "手绘的灵魂" | 手稿特写 + 笔触纹理放大 |
| "七次退休七次复出" | 7个年份数字逐一划掉，最后打勾 |
| "边画边改的创作方式" | 分镜草图叠加动画，展示修改过程 |
| "无用镜头的价值" | 龙猫玩水 / 千寻看窗外 的GIF循环 |
| "85岁还在画" | 老人的手 + 铅笔特写，缓慢运镜 |

### 景别调度

- **开头**：大特写（手稿纹理/老人的手）+ 数据字幕冲击
- **中段**：中景（工作室氛围/原画展示）+ 作品画面穿插
- **收尾**：近景（书籍封面/翻开内页）
- **切换频率**：每 5-8 秒一次景别切换

### 情绪曲线

```
0-3s 冲击（反常识数据）→ 3-15s 好奇（匠人故事展开）→ 15-35s 崇敬（创作理念深度）→ 35-55s 共鸣/行动（收藏价值）
```

### 视觉连贯性

- 宫崎骏作品画面 → 手稿 → 成片对比（同场景）
- 手绘笔触 → 实物纸张 → 书籍内页（材质递进）
- 老人的手 → 铅笔 → 分镜稿 → 动画成品（创作链条）

### 混剪适配

- **禁止出现**：需要真人出镜解说的内容
- **推荐替代**：原画手稿 + 电影片段 + 数据字幕叠加；久石让BGM贯穿始终
