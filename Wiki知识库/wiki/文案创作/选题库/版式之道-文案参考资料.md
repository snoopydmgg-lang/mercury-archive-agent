# 版式之道 - 文案参考资料

> 为 `/copywriter` 提供的创作弹药库。原则：给素材不给公式，给故事不给框架，给金句不给方程。

---

## 一、产品核心信息

- **18位日本设计大师** × **6大创意风格** × **77种版式策略** × **70余案例** × **212页精印**
- 网格系统：8格/12格/16格，版心率影响设计气质，留白比例 60-70%
- CRAP原则：对比、重复、对齐、亲密性
- 出版社：SendPoints善本图书，豆瓣 7.6-8.0 分

**6大风格**：留白空间感 / 高级反差感 / 几何交错感 / 手绘活泼感 / 复古意向感 / 秩序明镜感

**大师阵容**：古平正义（留白哲学）、平野甲贺（手绘张力）、服部一成（高级反差）

---

## 二、产品故事

- **18位大师的内部秘籍公开**：只在工作室内部传授的版式判断，变成 77 种可拆解策略。留白六七成——你以为没设计完，他们说这是报价最高的部分。
- **野路子 vs 科班的差距**：不是技术、经验、设备，而是有没有掌握版式之道。平面设计最大的谎言是"越满越用心"。
- **网格系统的隐形运算**：留白不是审美直觉，是网格系统在底层运算的结果。

## 三、文案创作素材

### 金句库

| 类型 | 金句 |
|------|------|
| **钱包焦虑（钩子A）** | "你报500的设计，日本设计师报5万。差的不是水平，是一张网格纸。" |
| **反常识断言（钩子B）** | "排版好看不值钱。值钱的是你看不见的东西——网格系统。" |
| 留白哲学 | "留白，不是空着" / "空白处，才是视觉发言的地方" / "留白是按秒计费的" |
| 版式本质 | "版式不是为了好看，是为了定价" / "网格系统决定设计报价，不是创意" |
| 日本设计 | "简约却不单调，高级又不刻意" / "机器字体是尸体，手绘字体才是活的" |
| 用户思维 | "日本版式最狠的不是好看，而是能把信息传达得明明白白" / "设计不是为了炫技，而是为了让用户更方便" |

### 矛盾反差点

- 留白六成的大师，报价比堆满的高三倍
- 平面设计最大的谎言：越满越用心
- 设计师在填格子，不是在做设计
- 不会留白的设计师，永远卖不出高价

### 情感共鸣点（设计师痛点）

- "为什么你做的海报总像路边摊上的牛皮癣？"
- "为什么你熬夜做的PPT，老板看一眼就说'不够大气'？"
- "排版总被甲方喷？" / "字一多就乱" / "感觉自己的设计很廉价"

## 四、爆款公式

### 核心公式：反常识 + 利益锚定

```
[反常识事实] + [观众预期] + [利益反转]
```

已验证：「留白九成的海报」→ 以为没设计完 → 报价是最高的部分（73,652播放，5s完播率 32.3%）

### 5s完播率分档（核心数据）

| 5s完播率 | 平均播放 | 结论 |
|---------|---------|------|
| **30%+** | **37,127** | 质变线——超这条才有大流量 |
| 20-30% | 496 | 基础盘 |
| <20% | <720 | 底部 |

**20%→30% 的差距 = 75 倍播放。** 5s完播率是算法推流的关键信号，2s跳出率不是。

### 验证通过的钩子

| 钩子 | 5s完播 | 播放 | 适用场景 |
|------|--------|------|---------|
| "留白九成…报价最高" | 32.3% | 73,652 | 反常识+利益锚定，首选 |
| **钩子A：钱包焦虑** | 待测 | 待测 | "你报500的设计，日本设计师报5万。差的不是水平，是一张网格纸。"——价格反差，泛人群秒懂，不依赖视觉素材 |
| **钩子B：看不见的价值** | 待测 | 待测 | "排版好看不值钱。值钱的是你看不见的东西——网格系统。"——反常识断言，制造"什么东西？"好奇缺口 |

**规律**：反常识+利益锚定 = 30%+。只有利益没有反常识 → 16%。两者缺一不可。

**钩子使用建议**：A 和 B 可叠加使用——A 做前 2 秒钩子（钱包焦虑），B 做 2-5 秒认知重构（看不见的价值）。A 负责留人，B 负责制造好奇缺口。

### 公式模板

**开头（0-3s）**：反常识金句 = 普遍认知 + "最大的谎言" + 颠覆观点
**认知重构（3-15s）**：具体数据 + "你以为..." + "他们说..." + 反差结论
**价值锚定（15-20s）**：核心观点1（价值量化）+ 核心观点2（颠覆认知）
**产品介绍（20-35s）**：权威背书 + N个数据（逗号分隔，数字递增：18→77→212）
**身份认同（55-65s）**："A和B的差距" + "不在X、Y" + "在于Z"

### 封面与标题

封面必须视觉化标题。爆款封面：实际海报案例 + "90%"（大号红色）+ "留白"（白色）+ 红框标注留白区域。

## 七、四维约束

### 视觉化转化

| 抽象概念 | 视觉替代 |
|---------|---------|
| "留白是按秒计费的" | 留白90%海报 + 红框标注 + 报价数字弹出 |
| "网格系统决定报价" | 8格/12格/16格网格叠加动画 |
| "CRAP原则" | 4个字母逐个出现，各配一个案例 |
| "版心率" | 同一张海报，高/低版心率对比 |

### 景别调度

开头：大特写（留白细节+数据字幕）→ 中段：中景（案例/网格动画）→ 收尾：近景（书籍封面）。每 5-8 秒切换一次。

### 情绪曲线

```
0-3s 冲击 → 3-15s 认知重构 → 15-35s 方法获得感 → 35-55s 身份认同/行动
```

### 混剪适配

禁止真人出镜讲理论。推荐：海报案例对比 + 网格标注动画 + 数据字幕叠加。

## 八、执行规范

### DBS 必须删除

| 删除 | 原因 |
|------|------|
| "欢迎来到版式的奇妙屋" | AI味开场白 |
| "推开第一扇门/第二扇门/第三扇门" | 排比句堆叠 |
| "版式设计是一门艺术" | 陈述句无冲击力（2s跳出59.8%） |
| "今天给大家介绍一本设计书" | 平淡开场（2s跳出54.7%） |
| "不是...而是..." 双向对比句式 | AI味重 |
| 模糊表达（"很多"、"非常"） | 降低可信度 |

### DBS 必须保留

| 保留 | 原因 |
|------|------|
| 反常识开头钩子 | 5s完播率30.3% |
| 具体数据（"六七成""18位""77种"） | 可感知，增强可信度 |
| 金句连击（"留白是按秒计费的"） | 价值量化，可传播 |
| 身份焦虑（"野路子vs科班"） | 击中痛点 |

### 开头设计原则

1. 开头必须独立工作——不假设用户看了标题，前3秒包含完整话题信息
2. 制造悬念，不给答案——用事实冲击替代逻辑推演
3. 口播友好——避免书面语和抽象概念
4. 钩子优先级：**钱包焦虑（A）** > **反常识断言（B）** > 留白利益锚定 > 身份焦虑
5. 钩子必须对泛人群零认知税——不能需要观众"理解"才能 get 到

### 数据使用原则

具体数字优于模糊。数字递增制造丰富感（18→77→212）。逗号分隔制造信息密度。

### 话题标签

- 核心：#版式设计 #排版设计
- 选 2-3：#版式之道 #平面设计 #日本设计
- 禁止同时用 #宫崎骏 #摄影 等无关标签

## 九、失败教训速查（禁用钩子）

| 钩子/问题 | 数据 | 结论 | 状态 |
|-----------|------|------|------|
| "留白九成的海报"开头（0523草莓结构） | 5s完播 ~20%，6h仅103播放 | 视觉素材撑不住钩子，Before/After 需要专门拍摄 | ❌ 禁用 |
| "网格在替你排版" | 5s完播 22.8%，留存-27pp vs 同类 | 泛人群太抽象，全新角度≠有效角度 | ❌ 禁用 |
| "路边摊牛皮癣" | 5s完播 15.7%，866播放 | "牛皮癣"劝退非设计师 | ❌ 禁用 |
| "报价高三倍" | 5s完播 16.4%，936播放 | 缺反常识层，纯利益无冲击 | ❌ 禁用 |
| "版式设计是一门艺术" | 5s完播 <15%，<200播放 | 陈述句无效 | ❌ 禁用 |
| "为什么你的设计总像路边摊？" | 2s跳出 61.15%，5s完播 12.69% | 目标用户太窄 | ❌ 禁用 |
| 抽象概念（"设计空气""视觉动线"） | 平均播放 4秒 | 普通用户听不懂 | ❌ 禁用 |

**核心教训**：
1. 开头钩子必须对泛人群可理解，不能只针对设计师
2. 抽象概念需要认知税，观众不会给你 2-3 秒去理解
3. Before/After 视觉冲击需要专门拍摄/制作，现成素材撑不住
4. 钩子本身够硬才能不依赖视觉——钱包焦虑（A）和反常识断言（B）对泛人群零认知税
