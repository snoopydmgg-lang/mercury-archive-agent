> 来源：AI 对话整理 | 已采购药品标记见各模块

## 一、根因分析

### 头皮问题（脂溢性皮炎/头皮糠疹）
- **核心致病因子**：马拉色菌（Malassezia），人类皮肤常驻共生菌，**无法被永久消灭**
- **复发闭环**：皮脂分泌 → 马拉色菌分解油脂产生游离脂肪酸 → 穿透角质层 → 免疫炎症 → 瘙痒/脱屑
- **耐药恶性循环**：长期单一使用酮康唑/二硫化硒 → 菌群耐受 + 屏障受损 → 代偿性出油增加 → 菌群反弹

### 甲床分离的系统性预警
- 单纯脂溢性皮炎**不会**导致甲床分离
- 【轻度甲床分离 + 头皮重度脱屑 + 硬痛毛囊炎 + 中轴关节炎症】组合 → 高度疑似**银屑病关节炎（PsA）**早期表征
- 需排查：非典型银屑病关节炎、强直性脊柱炎、甲状腺功能异常

## 二、头皮干预方案

### 核心策略：先剥脱、后杀菌、多靶点轮换

**洗剂轮换矩阵（每周各1次，防止耐药）**

| 成分 | 作用机制 | 备注 |
| :--- | :--- | :--- |
| 酮康唑 (2%) | 破坏真菌细胞膜合成 | 已有 |
| 二硫化硒 (2.5%) | 抑制细胞核分裂，降低角质更新速度 | 已有 |
| 环吡酮胺 (1.5%) | 干扰真菌跨膜转运，兼具抗炎 | 破除酮康唑耐药性的首选 |
| 水杨酸 (2-3%) | 溶解角质，剥脱游离脂肪酸 | 用于洗发前"破甲" |

**洗发日 SOP**
1. **干发状态**：水杨酸软膏涂抹大块鳞屑处，停留 15 分钟（化学剥脱，替代物理撕扯）
2. **冲洗上药**：温水（35-37℃）冲净后，使用酮康唑洗剂，揉搓起泡**停留 5 分钟**后冲净
3. **吹干点涂**：冷风/温风吹干，毛囊炎包块处点涂夫西地酸乳膏

**屏障修复**
- 日常洗发水改用氨基酸表活，**拒绝 SLS/SLES**
- 水温严格 35-37℃，禁止高温

**绝对禁令**
- 禁止物理撕扯鳞屑（触发同形反应/Koebner现象，加倍爆发）
- 禁止搽剂/酊剂用于头皮（酒精基质会化学烧伤破损区域）
- 禁止红霉素软膏（凡士林基质封闭毛囊 + 喂养真菌）

## 三、足癣与甲癣干预

### 足底皮肤
- **药物**：盐酸特比萘芬乳膏 或 联苯苄唑乳膏（丙烯胺类，酮康唑效力不足）
- **SOP**：洗澡后彻底擦干脚趾缝 → 全脚底+趾缝涂抹（超出病灶2cm）→ **症状消失后继续4周**
- **禁止**：用手抠刮（真菌孢子残留指甲缝 → 手癣 + 自体接种至头皮）

### 灰指甲（甲癣）
- 常规药膏分子过大，**无法穿透甲板**
- **方案**：先溶甲，后上漆
  1. 物理打磨病甲表面（锉刀一次性使用后丢弃）
  2. 30-40% 尿素霜厚涂 + 封包过夜，次日剔除软化病变角质
  3. 5% 阿莫罗芬搽剂涂抹，形成防水药膜，每周 1-2 次

### 交叉感染阻断
- 接触脚部后**必须肥皂流水洗手**才能接触头皮
- 袜子与内裤/上衣分开高温洗涤或消毒液

## 四、内部代谢优化

### 抗炎与皮脂控制
- **鱼油（Omega-3）**：EPA > DHA，纯度 > 80%（rTG形式），对冲饮食中过高 Omega-6
- **复合维生素B族**：药字号小白瓶（B2、B6），直接参与脂质代谢
- **锌**：葡萄糖酸锌/甘氨酸锌，抑制皮脂腺过度活跃
- **饮食调整**：减少植物油（高Omega-6），增加橄榄油/椰子油

> 结合胸椎/肩胛骨康复期 + 减脂增肌需求，以上补剂同时服务于全身抗炎

## 六、医学检查（待执行）

当前干预仅针对表层，需通过客观数据切断假设路径。

### 必须执行的检验
1. **真菌荧光镜检**（皮肤科）：头皮鳞屑 + 甲床碎屑采样，确认是否存在真菌。若阴性 → 停用所有抗真菌洗剂
2. **炎症与自身免疫筛查**（风湿免疫科）：CRP、ESR、**HLA-B27** → 排查强直性脊柱炎/银屑病关节炎
3. **甲功五项**（内分泌科）：TSH/FT3/FT4等 → 排查甲状腺功能异常导致的角化异常

### 熔断机制
- 严格执行轮换策略 **4周** 后，瘙痒未下降 70% → 立即中断，转诊
- 出现以下特征立即就医：银白色厚鳞屑、发际线越界红斑、指甲顶针样凹陷、晨僵

## 七、药物禁忌警告

- **口服抗真菌药（伊曲康唑/特比萘芬）绝对禁止**：当前服用塞来昔布（NSAIDs），叠加产生极高肝肾代谢毒性。未做肝功能检测（ALT/AST）前不得自行服用
- **搽剂/酊剂禁止用于头皮**：酒精基质对破损区域造成化学烧伤
- **红霉素软膏废弃**：凡士林基质封闭毛囊 + 成为真菌培养基

## 八、每周执行循环（周历）

> 以下基于你手上已有的药品制定。环吡酮胺是乳膏剂型，适合局部涂抹，不参与洗发轮换。

### 每日固定项（早晚各一次）

| 时段 | 动作 | 药品/方法 |
| :--- | :--- | :--- |
| **早** | 鱼油 1 粒 + 葡萄糖酸锌 1 片 | 饭后服用 |

| 4 | 彻底冲净，吹干 | 冷风/温风 | — |

### 非洗发日

- 不用药洗头，若头皮油腻可用清水冲洗
- 如有新冒出的毛囊炎包块，继续点涂**夫西地酸乳膏**
- **环吡酮胺乳膏**：可用于局部瘙痒严重区域薄涂（作为辅助抗炎）

### 灰指甲专项（每周 1 次：周日）

## 九、预期恢复时间线

### 头皮（脂溢性皮炎/毛囊炎）

| 阶段 | 时间 | 预期表现 |
| :--- | :--- | :--- |
| **急性控制期** | 第 1-2 周 | 鳞屑明显减少，瘙痒频率下降 30-50% |
| **稳定维持期** | 第 3-4 周 | 毛囊炎包块消退，瘙痒下降 70%+ |
| **长期管理期** | 第 5 周起 | 降为每周 1 次药用洗发，症状可控 |

> 头皮问题**无法根除**（马拉色菌是常驻菌），但可通过轮换维持长期不发作。若 4 周后无改善 → 转诊皮肤科做真菌镜检。

### 足癣（脚底）

| 阶段 | 时间 | 预期表现 |
| :--- | :--- | :--- |
| **症状消退** | 第 2-3 周 | 白泥/滑溜感消失 |
| **巩固期** | 第 4-8 周 | 症状消失后**必须继续涂 4 周**，覆盖角质更迭周期 |

### 灰指甲（甲癣）

| 阶段 | 时间 | 预期表现 |
| :--- | :--- | :--- |
| **软化清理期** | 第 1-4 周 | 病变角质逐步清除，甲床露出 |
| **新甲生长期** | 第 2-6 个月 | 健康指甲从甲根部缓慢推出 |
| **痊愈** | **6-12 个月** | 指甲完全更替（趾甲生长极慢，约 1-1.5mm/月） |

> 灰指甲是所有症状中最慢的，必须有耐心。阿莫罗芬搽剂每周 1 次，持续到新甲完全长出。

### 系统性排查（关键节点）

| 时间点 | 动作 |
| :--- | :--- |
| **第 4 周末** | 评估头皮效果。若未达 70% 改善 → 立即挂号皮肤科+风湿免疫科 |
| **尽快** | 做真菌镜检 + CRP/ESR/HLA-B27 + 甲功五项 |
| **拿到报告后** | 根据数据决定是否调整方案（如排除真菌 → 停抗真菌药；确认 PsA → 转风湿科系统治疗） |
