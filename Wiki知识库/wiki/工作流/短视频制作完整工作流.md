# 短视频制作完整工作流

**最后更新**：2026-05-06  
**适用账号**：水星艺术馆（抖音电商 - 艺术品类目）  
**校准系统**：cheat-on-content v1.0.0（79 校准样本 / 258 对标样本 / rubric v0）

---

## 一、完整流程（12 步 + 2 持续动作）

```
选品 → 找对标 → 知识库查找 → 背景研究 → 文案生成 → 质量校准 → 内容诊断 → 配音 → 拍摄登记 → 外包交付 → 发布登记 → 数据复盘
                                                                                            ↑
                                                                                   cheat-bump(每5篇) + cheat-status(随时)
```

### 两条管线

| | 触发条件 | 管线 |
|---|---|---|
| **A: 主线** | 有明确产品 | 选品 → cheat-learn-from 对标 → /copywriter 三套文案 → cheat-score+预测 → ... |
| **B: 支线** | 有想法/无产品 | /cheat-seed 选题深挖 → 手动改写 → cheat-score+预测 → ... |

### cheat-on-content 校准层

```
文案完成 → /cheat-score(打分探索) → /cheat-predict(盲预测锁,不可改) → DBS检定 → 拍摄
                                                                        ↑
                                                              误差信号反馈 → /cheat-retro(T+3) → /cheat-bump(每5篇)
```

## 二、详细步骤

### 步骤 1：选品

**目标**：找到适合带货的艺术/书籍产品

**工具**：
- 精选联盟（抖音）
- 灰豚数据
- 橱窗商品

**选品标准**：
- 客单价：¥50-150（冲动消费区间）
- 佣金率：>15%
- 近30天销量：>100
- 短视频出单占比：>50%
- 商家体验分：>4.5

**输出**：
- 产品名称
- 商品链接
- 选品理由

**存储位置**：
- 飞书多维表格（选品追踪表）
- `01_Projects_制作中/{产品名}/`

### 步骤 2：找对标

**目标**：找到同类产品的爆款视频，拆解 pattern

**工具**：
- `/cheat-learn-from {账号名}`（主力）— 自动拆解对标账号的 script + 数据 → 写入 `.cheat/benchmark.md`
- 抖音搜索（搜产品名）
- 灰豚数据（达人榜）

**对标标准**：
- 播放量 >10万
- 点赞量 >5000
- 评论量 >100
- 带货成交 >50单

**输出**：
- `.cheat/benchmark.md`（对标账号中央 reference）
- `.cheat/script_patterns.md`（提取的可复用 pattern）
- `.cheat/rubric_notes.md`（派生的 rubric 信号）
- `.cheat/data/samples/{账号名}/`（对标视频/转录）

**存储位置**：
- `.cheat/benchmark.md` + `.cheat/data/samples/`

### 步骤 5：文案生成

**工具**：
- **A 主线（有产品）**：`/copywriter` Skill

**A 主线命令**：

```bash
/copywriter {产品名} --styles 1,2       # 只生成风格1和2
```

**B 支线命令**：
```bash
/cheat-seed              # AI 围绕你的输入深挖，一次一个选题，产出初稿到 .cheat/data/scripts/
/cheat-seed --batch 5    # 批量 brainstorm 5 个候选 + 5 份初稿
```

**三大风格**：
1. **余上沅的奇妙屋** - 学术深度解析与工艺细节呈现
2. **九厘米的雾** - 内行人解码世界规则

**输出**：

- `Wiki知识库/wiki/文案创作/数字化钩子库.md`
- `.cheat/script_patterns.md`（从对标/历史提取的写作 pattern）

### 步骤 6：质量校准（cheat 预测锁）

**目标**：在拍摄前对最终稿做 rubric 打分 + 盲预测，锁定预测不可逆

**工具**：
- `/cheat-score {稿子路径}` — 7 维 rubric 打分（仅控制台输出，不写文件，可反复跑）
- `/cheat-predict {稿子路径}` — 写 immutable 盲预测日志（**一次性，hook 锁定不可改**）
- `/cheat-recommend` — 从候选池按 rubric 排序推荐 top N（有多个候选时用）

**7 维 rubric（v0 等权）**：
1. **ER (Engagement Rate)** — 前 5 秒完播率预估
2. **SR (Share Rate)** — 分享动机强度
3. **HP (Hook Power)** — 钩子力度
4. **ID (Information Density)** — 信息密度
5. **SC (Social Currency)** — 社交货币
6. **AV (Altruistic Value)** — 利他价值
7. **CE (Conversion Expectation)** — 转化预期

**工作流**：
```
文案定稿 → /cheat-score 反复打分调整 → 满意后 /cheat-predict 锁预测 → 进入 DBS 检定
```

**注意**：
- predict 后再改稿 → 必须重新 predict
- 预测段一旦写入任何人都不能修改（hook 强制），复盘只能追加到下半段
- 前 5 篇预测精度约 ±50%（confidence 🔴），第 5 次复盘后首次校准 → 🟡

**参考文档**：
- `.cheat/rubric_notes.md`（你的 rubric 维度定义和权重）
- `.cheat/WORKFLOW.md`（cheat 完整流速查）
- `Wiki知识库/wiki/视频制作/5秒完播率优化指南.md`（开头优化参考）

---

### 步骤 7：内容诊断（DBS 检定）

**目标**：用 DBS 方法论检定文案质量（在 cheat-predict 之后）

**工具**：`/dbs-content` Skill

**检定维度**：
- 选题是否通过（痛点+悬念）
- 内容是否有干货密度
- 是否有社交货币（分享动机）
- 是否有利他价值（帮助他人）

**输出**：
- DBS 检定报告
- 修改建议

**注意**：
- DBS 检定在 cheat-predict **之后**——如检定触发大改，需重新 `/cheat-predict`
- 新产品首次生成时需要检定
- 成熟产品（如版式之道）可以跳过

### 步骤 9：拍摄登记（cheat-shoot）

**目标**：登记视频已拍摄，建 video folder，buffer +1

**工具**：`/cheat-shoot {稿子路径或 ID}`

**命令**：
```bash
/cheat-shoot .cheat/data/scripts/0506_a1b2c3_留白九成.md
```

**行为**：
1. 在 `.cheat/data/videos/` 创建 `{date}_{id}_{short}/` 目录
2. 询问"拍摄时实际用的稿子和 scripts/{id}.md 一致吗？"
   - 一致 → 自动复制 scripts/{id}.md → videos/{id}/script.md
   - 不一致 → 用户提供最终拍摄稿，存为 videos/{id}/script.md
3. buffer +1（状态看板可见积压）

**输出**：
- `.cheat/data/videos/{date}_{id}_{short}/script.md`

### 步骤 10：外包交付

**目标**：将素材打包交付给视频制作外包

**交付清单**：
- 文案脚本（MD 文件）
- 配音文件（MP3）
- 参考素材（图片/视频）
- 封面设计要求

**封面规范**：
- 比例：3:4（1080x1440）
- 遵循视觉规范：`Wiki知识库/wiki/个人视觉系统设计/`
- 色彩：主背景 `#F5F4F0`、主文本 `#2D2B2A`、点缀色 `#D36B4D`

**外包平台**：
- 自有外包团队

---

### 步骤 11：发布登记（cheat-publish）

**目标**：登记视频已发布，写入元数据到预测文件和 state

**工具**：`/cheat-publish {链接}`

**命令**：
```bash
/cheat-publish https://www.douyin.com/video/...
```

**行为**：
1. 把 URL / 平台 ID / 发布时间写入对应预测文件 header
2. 更新 `.cheat/state.json` 的 `last_published_at` / `last_published_file` / `shoots[]`
3. buffer -1

**注意**：
- **不动预测段任何字符**（hook 层面也禁止）
- 发布后立刻登记，不要等 T+3 复盘时再补

---

### 步骤 12：数据复盘（cheat-retro）

**目标**：T+3 天回收数据 + 复盘 + 更新 rubric

**工具**：`/cheat-retro {video 文件夹路径}`

**命令**：
```bash
/cheat-retro .cheat/data/videos/0506_a1b2c3_留白九成/
```

**行为**：
1. 抓数据（adapter 自动 / 用户手动粘 top 20+ 评论含赞数）
2. 写 `.cheat/data/videos/{id}/report.md`（播放/点赞/评论/转发/5s完播率）
3. 追加 `## 复盘` 段到 `predictions/{id}.md`（**下半段**，不动上半段预测）
4. diff `scripts/{id}.md` vs `videos/{id}/script.md` → 学用户改稿 pattern
5. 更新 `.cheat/rubric_notes.md` / `.cheat/script_patterns.md`

**发布后监控**：
| 时间 | 监控指标 | 操作 |
|------|---------|------|
| 1 小时 | 播放量 >100 | 标记为正常推荐 |
| 3 小时 | **5秒完播率** | 如果 <40%，分析开头问题 |
| 6 小时 | 分享量 >5 | 考虑投 DOU+ |
| 12 小时 | 综合评估 | 决定是否继续投放 |

**复盘维度**：
- 5秒完播率（核心指标）
- 分享量（传播价值）
- 收藏量（内容价值）
- 点赞量（共鸣指标）
- GMV（变现能力）
- **预测偏差分析**（高估了什么？低估了什么？）→ 写入 rubric_notes

**T+3 复盘后**：
- 累计 ≥3 同向偏差 → 运行 `/cheat-bump` 校准 rubric 权重
- 每 5 篇复盘 → rubric v0 → v1 → v2... 渐进校准

**复盘模板**：
- `Wiki知识库/raw/账号数据/`
- `.cheat/data/predictions/`（预测 + 复盘在同一文件，上下半段分离）

## 三、关键原则

### 原则 1：知识库优先

**文案生成前必须查找知识库**：
1. `Wiki知识库/wiki/选题库/` - 产品背景资料
2. `Wiki知识库/wiki/文案创作/` - 方法论和规则
3. `Wiki知识库/raw/博主文案库/` - 对标爆款文案

**禁止**：
- 从收件箱开始盲目遍历
- 跳过知识库直接生成文案

---

### 原则 2：5秒完播率是生死线

**核心指标**：
- 5秒完播率 >40%（及格线）
- 5秒完播率 >50%（优秀）
- 5秒完播率 >60%（爆款）

**优化重点**：
- 前 2 秒：视觉冲击
- 2-5 秒：信息密度 + 悬念

**参考文档**：
- `Wiki知识库/wiki/视频制作/5秒完播率优化指南.md`

---

### 原则 3：稳定输出 > 单条爆款

**账号权重恢复策略**：
- 连续 3-5 条稳定输出
- 目标：5秒完播率 >35%，分享量 >3
- 不要求爆款，只要求稳定

**为什么？**
- 系统判断账号活跃度的标准是"连续性"
- 连续稳定输出，系统会恢复权重

---

### 原则 4：复制爆款系列

**最低风险策略**：
- 找到你的爆款（如《留白九成的海报》）
- 做系列第 2、3、4 条
- 复制爆款的四大要素：痛点+悬念、干货密度、社交货币、强关联

**为什么？**
- 内容标签精准，系统知道推给谁
- 受众已验证，降低风险
- 连续输出，系统恢复权重

## 五、常见问题

### Q1：为什么播放量只有几十？

**可能原因**：
1. **账号权重低**（上周视频表现差）
2. **5秒完播率 <40%**（系统判定质量差）
3. **发布时间差**（凌晨 2-6 点）
4. **内容标签不精准**（系统不知道推给谁）

**解决方案**：
- 连续 3-5 条稳定输出（5秒完播率 >35%）
- 复制爆款系列（降低风险）
- 避开凌晨发布

---

### Q2：如何提升 5秒完播率？

**优化方向**：
1. **视觉冲击开头**：前 2 秒放最震撼的画面
2. **信息密度最大化**：删掉所有废话
3. **制造悬念**：抛出问题，不给答案
4. **节奏加快**：每 3 秒一个信息点

**参考文档**：
- `Wiki知识库/wiki/视频制作/5秒完播率优化指南.md`

---

### Q3：如何恢复账号权重？

**策略**：
1. **连续 3-5 条稳定输出**（不要求爆款）
2. **复制爆款系列**（降低风险）
3. **提升分享量**（>3）
4. **避开冷门产品**（先做成熟产品）

**目标**：
- 5秒完播率 >35%
- 分享量 >3
- 涨粉 >2

---

### Q4：cheat-on-content 和 DBS 是什么关系？

cheat-on-content 是**校准系统**，DBS 是**质检系统**，两者互补：

| | cheat-on-content | DBS |
|---|---|---|
| 定位 | 预测→复盘→校准循环 | 内容质量即时检定 |
| 打分 | 7 维 rubric（含预测） | 选题/干货/社交货币/利他 |
| 写文件 | 是（预测日志 + 复盘） | 否（仅报告） |
| 锁预测 | 是（hook 强制 immutable） | 否 |
| 校准 | 是（每 5 篇 bump） | 否 |

**建议**：cheat-predict → DBS 检定，两个都跑。如有冲突以 cheat-retro 数据为准。

---

### Q5：Pipeline A 和 B 怎么选？

- **A（/copywriter）**：选中了产品，需要快速产出三套风格文案 → 批量生产
- **B（/cheat-seed）**：没选品但有一个想法/话题想深挖 → 精耕单篇
- 两者可以混合：先用 A 产出三套，选一套用 B 的思路深挖改写
