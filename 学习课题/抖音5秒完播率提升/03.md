# 03｜前 2 秒抓人 + 2-5 秒留人 — 漏斗每一层怎么做

## 这一篇要解决的问题

回答你的两个核心问题：前 2 秒靠什么抓人？2-5 秒怎么把人留住？

---

## 一、先回应你的观察：5s 完播率是递减函数

你说得对。5s 完播率不是固定值，它随受众池扩大而递减。

抖音的推荐是逐层扩池的。第一层推给 200-500 人，这些人是算法认为「最可能喜欢你内容」的精准用户。他们的 5s 完播率天然就高——因为他们本来就是冲着这类内容来的。

当视频进入第二层、第三层，受众从精准用户变成泛人群。泛人群对你的内容没有天然兴趣，5s 完播率自然下降。

这就是为什么你在基础流量池里能看到 40-50% 的 5s 完播率，但推到一定程度后会掉得很快。不是你的内容变差了，是观众变了。

**对你的启示**：不要拿泛流量池的 5s 完播率和冷启动池比。看数据的时候，关注的是「在当前流量层级，我的 5s 完播率有没有过线」。冷启动池 40% 是及格线，泛流量池 25-30% 可能就够了。

---

## 二、投流和自然推流是两套逻辑

你提到投流作品 5s 完播率只有 10%+，但能出单。停投之后自然推流就停了。

这是因为投流绕过了 5s 完播率这道门槛。

自然推流：系统先考 5s 完播率，过了才给更多流量。5s 完播率是门票。

投流（放心推/DOU+）：你花钱买了流量，系统直接把视频推给目标人群，不再用 5s 完播率做筛选。这时候考核的是 GPM——千次曝光成交额。只要能出单，系统就继续推。

但停投之后，视频回到自然推流的赛道，5s 完播率重新成为门槛。10% 的 5s 完播率在自然推流里 = 立刻停推。

**两种打法**：

| | 自然推流 | 投流 |
|---|---|---|
| 核心指标 | 5s 完播率 | GPM |
| 门票 | 5s 完播率 ≥40% | 能出单就行 |
| 流量上限 | 取决于内容质量 | 取决于预算 |
| 停了之后 | 数据好的继续推 | 立刻停 |

所以投流不是「5s 完播率不重要」，而是「投流用另一套指标替代了它」。你的长期策略还是要把自然推流的 5s 完播率做上去，投流作为加速器配合使用。

## 三、前 2 秒靠什么抓人？

你的问题是：文案、画面、音乐哪个重要？有没有普适办法？

先说结论，再解释：

**前 2 秒，画面 > 文案 > 音乐。**

### 为什么画面排第一？

因为抖音是信息流。用户在快速滑动，大脑处理视觉信息的速度远快于文字和声音。用户还没来得及读字幕、听清配音，画面已经进入了大脑。

你的数据也能验证这一点：

- 72K 爆款和其他作品的 2s 跳出率几乎一样（53% vs 52.6%），说明封面/首帧的「停住人」能力在这个账号里差异不大。
- 但「留白九成」那个爆款的首帧是**一张留白极多的海报**——视觉上就制造了「为什么这么空？」的疑问。画面本身就在攻击预测系统。

### 普适的前 2 秒画面策略

有三种画面能在 2 秒内抓住人：

**1. 反差画面** — 观觉上「不应该出现的东西」出现在「不应该出现的地方」。

- 一张 90% 空白的海报（「为什么这么空？」）
- 一本书被撕开又重新装订（「为什么撕？」）
- 一张丑照片突然变成大片（「怎么做到的？」）

**2. 极端画面** — 视觉上「大到不合理」或「小到不合理」。

- 17 万张手稿铺满整个画面（「这么多？」）
- 指尖捏着一页薄如蝉翼的纸（「这么薄？」）
- 一本 8 开精装书和一个火柴盒的对比（「这么大？」）

**3. 动态冲突画面** — 画面里有「正在进行的动作」制造张力。

- 翻书的手突然停下来（「为什么停？」）
- 镜头快速推进到一个细节（「让我看看」）
- 两张图片并排滑动对比（「区别在哪？」）

### 文案在前 2 秒的角色

文案不是不重要，而是在前 2 秒它要配合画面，不能单独作战。

**好的前 2 秒文案**：和画面形成「1+1 > 2」的关系。

- 画面：一张留白极多的海报
- 文案字幕：「留白九成」
- 效果：画面制造疑问，文案确认疑问 → 双重劫持

**差的前 2 秒文案**：和画面无关，或者画面本身就是废话。

- 画面：书的封面
- 文案字幕：「今天给大家介绍一本书」
- 效果：画面没有疑问，文案没有冲突 → 零劫持

### 音乐在前 2 秒的角色

音乐在前 2 秒的作用是**氛围铺垫**，不是主角。它能放大画面和文案的情绪，但不能单独制造劫持。

有一个例外：**音效**（不是 BGM）。一个突然的「Boom」、翻书声、撕裂声可以在 0.5 秒内制造注意力冲击。但这属于锦上添花，不是基本盘。

### 小结：前 2 秒的优先级

```
画面（制造疑问）> 文案（确认疑问）> 音乐（放大情绪）
```

画面负责让用户的手指停下来，文案负责让用户的大脑确认「值得继续看」，音乐负责让情绪到位。

## 四、2-5 秒怎么留人？

这是你最想展开的部分。也是整条视频的生死线。

先把时间窗拆清楚：

```
0-2秒：钩子 → 用户停下来了，但半信半疑
2-5秒：兑现 → 用户决定「继续看」还是「划走」
5-8秒：展开 → 用户进入内容节奏
8秒+：  产品登场 → 自然引出商品
```

2-5 秒的任务只有一个：**让在前 2 秒停下来的人觉得「这个人不是在骗我」。**

### 方法 1：直接给答案

钩子提出了问题，2-5 秒立刻给答案。不铺垫、不过渡、不绕弯。

**错误示范**（你的数据，5s 完播 12.2%）：
```
0-2秒：为什么你的设计总像路边摊？
2-5秒：日本 18 位设计大师 30 年经验总结，77 种可复用版式策略……
```
用户期待「为什么」的答案，得到的是产品规格 → 骗子 → 划走。

**正确示范**：
```
0-2秒：为什么你的设计总像路边摊？
2-5秒：新手拼命往画面里塞东西，高手拼命往外删东西。
```
用户得到了「为什么」的答案 → 好奇心被满足 → 想看「怎么删」→ 继续。

### 方法 2：先证明再说

钩子说了一个反常识的事，2-5 秒用权威或数据证明「这是真的」。

**示例**（72K 爆款的结构）：
```
0-2秒：留白九成的海报，才是最难的部分。
2-5秒：日本设计师的留白比例，往往高达六七成。你以为没设计完，他们说——这是报价最高的部分。
```

前半句用权威群体 + 数据证明（「日本设计师」「六七成」），后半句用反转强化（「你以为 A → 实际是 B」）。

### 方法 3：制造「啊原来如此」的瞬间

2-5 秒内必须有至少一个让观众觉得「原来如此」的时刻。这个时刻的本质是：**打破观众的一个既有认知**。

**示例**：
```
0-2秒：宫崎骏：85 岁还手绘的「骗子」。
2-5秒：17 万张原画，每一张都是手绘。他不是不会用电脑，是拒绝用电脑。
```

「不是不会用，是拒绝用」= 打破「老年人不会技术」的既有认知 → 「啊原来如此」。

### 方法 4：给出具体画面

如果钩子制造了抽象的疑问，2-5 秒用一个具体的画面或细节把它具象化。

**示例**：
```
0-2秒：这本书的护封设计，99% 的人都没注意到。
2-5秒：（画面：手指拨开护封，露出里面的烫金细节）
```

抽象的「没注意到」→ 具体的「让我指给你看」→ 用户被画面拉着走。

## 六、小结

- 5s 完播率是递减函数，随受众池扩大而衰减。关注的是「在当前层级有没有过线」。
- 投流用 GPM 替代了 5s 完播率的筛选，但自然推流仍然以 5s 完播率为门槛。两者配合使用。
- 前 2 秒：画面 > 文案 > 音乐。画面负责停住手指，文案负责确认大脑。
- 前 2 秒的三种画面策略：反差画面、极端画面、动态冲突画面。
- 2-5 秒的任务只有一个：让停下来的人觉得「不是在骗我」。
- 2-5 秒的四种方法：直接给答案、先证明再说、制造「啊原来如此」、给出具体画面。
- 产品信息最早出现在 5 秒之后。
