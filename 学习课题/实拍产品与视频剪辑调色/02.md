# 02｜桌面拍摄的布光空间

## 这一篇要解决的问题

搞清楚光源在三维空间里到底摆在哪里，侧光和辅光到底什么关系，以及一个「桌拍」场景的具体布置方案。

## 正文

### 先画一张俯视图

第一篇里说的「前方 45°」确实容易让人困惑，因为没有说清楚参考系。现在换一种方式——从正上方往下看你的桌面：

```
                  【背景纸/布】
                      ↑
                      |
        ·—————————————·—————————————·
        |             |             |
        |    辅光     |     产品     |    轮廓光
        |   (弱)     |    🎯       |   (后方)
        |             |             |
        ·—————————————·—————————————·
                      |
                      ↓
                 【相机/手机】
```

这不是一个平面图，而是一个三维空间的俯视投影。实际拍摄时：

- **产品**放在桌子中间偏后的位置
- **相机**在桌子正前方，对着产品
- **主光**在产品的左前方或右前方（你选一侧），从侧面 45° 打过来
- **辅光**在主光的对面，比主光弱
- **轮廓光**在产品背后，朝相机方向打

「前方」指的是**相机面对的方向**，也就是你站在桌子前面、面对产品时你所在的位置。主光在产品的左前方 45°，意思是：从你站的位置看过去，光在产品的左边偏前的位置，斜着打过来。

### 侧光 ≠ 辅光

这两个概念在第一篇里混在一起了，现在拆清楚：

**侧光**描述的是光的**方向**——从产品的侧面打过来。侧光可以是主光，也可以是辅光，取决于它是不是最亮的那盏。

**辅光**描述的是光的**功能**——它不是主角，它的作用是减弱主光造成的阴影，让暗部不要死黑。辅光通常放在主光的对面。

所以它们是两个不同维度的概念：

| | 侧光 | 辅光 |
|---|---|---|
| 描述的是 | 方向（从侧面来） | 功能（补暗部） |
| 可以是什么光 | 主光或辅光 | 通常是弱光 |
| 位置 | 产品侧面 | 主光对面 |

实际操作中，你的「侧光」往往就是主光，「辅光」放在对面补光。如果两盏灯亮度一样，那就没有主辅之分了——这时候画面会显得平，没有立体感。

### 后期能补救多少

简短回答：能补，但有上限。

后期能做的：
- 提亮暗部（但暗部细节本来就没拍到的话，提亮只会出噪点）
- 调整色温（偏冷偏暖可以改）
- 加对比度、饱和度
- 局部提亮/压暗（用遮罩）

后期做不了的：
- 把正面光拍的平画面变成有立体感的侧光效果
- 把杂乱的反光擦掉（除非逐帧修）
- 把模糊的照片变清晰
- 把错误的色温完全纠正（偏绿很难救）

**核心原则：前期解决 80% 的问题，后期解决 20% 的风格化。** 前期布光对了，后期只需要微调；前期布光错了，后期怎么调都不对。

### 桌面拍摄的具体布置

你说了大部分产品都是桌拍，这是一个很常见的场景。下面是一个可以直接照着做的方案：

**需要的东西：**
- 一张桌子
- 一个手机支架或三脚架（相机也行）
- 一盏台灯或补光灯（主光）
- 一张 A4 白纸或白色泡沫板（辅光/反光板）
- 一张纯色纸或布做背景

**摆放步骤：**

```
步骤 1：背景
在桌子后方立一张纯色纸或布，弯出一个弧形过渡到桌面。
产品和背景之间保持 30-50cm 距离。

步骤 2：产品位置
产品放在桌子中间偏后，离背景 30-50cm。
不要贴着背景，否则背景会有产品的影子。

步骤 3：主光
台灯放在产品的左前方（或右前方），距离产品 50-80cm。
灯的高度：比产品高 30-45° 角往下打。
灯前面可以蒙一层白纸柔光。

步骤 4：反光板（辅光）
在主光对面放一张白纸或泡沫板，朝向产品。
它不需要通电，只是反射主光的光到产品的暗部。
距离产品 30-50cm。

步骤 5：相机位置
手机/相机在桌子正前方，镜头和产品保持平行或略俯视。
不要从上往下拍（俯拍 90°），除非是刻意要拍平铺效果。

步骤 6：调整
先拍一张，看看产品的亮面和暗面比例。
如果暗部太暗：把反光板靠近产品，或增大白纸面积。
如果亮部太亮：把主灯拉远，或加一层柔光。
```

### 一个检查清单

拍完之后，对照这几项看：

- [ ] 产品有没有明暗过渡？（有 = 有立体感）
- [ ] 暗部有没有细节？（有 = 辅光到位）
- [ ] 产品边缘有没有和背景区分开？（有 = 轮廓光或背景对比到位）
- [ ] 背景有没有影子？（没有 = 产品和背景距离够）
- [ ] 画面有没有杂乱的反光？（没有 = 柔光到位）

## 小结

- 「前方」指的是相机面对的方向，主光在产品侧前方 45° 是指从你站的位置看过去的方位
- 侧光是方向描述，辅光是功能描述，两者不是同一个东西
- 前期布光解决 80% 的画面问题，后期只能补剩下的 20%
- 桌拍最简方案：一盏灯 + 一张反光白纸 + 一个纯色背景
- 拍完用检查清单逐项确认，哪里不对就调哪里
