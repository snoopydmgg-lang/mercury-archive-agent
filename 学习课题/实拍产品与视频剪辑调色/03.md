# 03｜一个人拍书：反光、设备和镜头角度

## 这一篇要解决的问题

针对你的真实条件（一个人拍、书类产品、现有设备），解决三个卡点：覆膜/铜版纸的反光怎么处理、现有设备怎么摆、镜头角度到底怎么理解。

## 正文

### 色温前期怎么注意

你理解得对。后期偏绿难救，所以前期就要控制。具体做法：

- 拍摄时**只开一种色温的光源**。如果你用补光灯，就只开补光灯，关掉房间其他灯（包括电脑屏幕灯、顶灯）。混用不同色温的灯，画面会发绿发灰，后期很难统一。
- 补光灯色温调到 **5000-5500K**（日光色），这个范围最接近自然光，后期空间最大。
- 如果你只有一个灯泡，确认它是不是 LED。老式白炽灯色温偏低（偏黄），LED 灯一般有色温标注。淘宝上十几块的灯泡通常都能调色温。
- **白平衡手动锁定**：手机拍照时长按屏幕锁定白平衡，或用专业模式手动设色温值，避免自动白平衡来回跳。

一句话：**一个灯、一个色温、锁白平衡**，绿光问题就解决了。

### 书的反光怎么处理

覆膜封面和铜版纸是反光重灾区。反光的本质是：光源的像刚好反射进了你的镜头。解决思路是**改变反射角度**，让反光射到镜头外面去。

**方法一：调灯位（最有效）**

反光发生在「入射角 = 反射角」的时候。如果你的灯在左前方 45°，反光刚好射进正前方的镜头——这就是你看到反光的原因。

解法：把灯**抬高**或**移偏**。

```
原来的灯位：灯 → 45° → 产品 → 反射进镜头（有反光）
调整后：灯抬高到 60-70° → 反射角度变了 → 反光射到镜头上方（没反光）
```

具体操作：把灯从侧面 45° 往上抬，直到你在手机屏幕里看不到反光为止。一般抬到 60-70° 角就能消除大部分反光。

**方法二：调产品角度**

如果灯位不能动（比如桌面空间有限），就把书**稍微倾斜**。

- 不要把书完全平放在桌面上
- 用一个小支架或几本书垫在书的下方，让书面倾斜 15-30°
- 书面向上倾斜 = 反光射到镜头上方 = 消失

**方法三：偏振片（进阶）**

如果你愿意投入几十块钱，买一个手机偏振镜（CPL），拧在手机镜头前面。旋转偏振片可以过滤掉大部分反射光。对铜版纸和覆膜效果很好。淘宝搜「手机 CPL 偏振镜」，十几块到几十块都有。

**三种方法优先级：先调灯位，再调产品角度，最后考虑偏振片。**

### 你现有的设备够不够用

你描述的设备清单：

| 设备 | 能用吗 | 怎么用 |
|---|---|---|
| 三角支架/手机支架 | 能 | 固定机位，拍视频必备 |
| 淘宝补光灯 | 能 | 做主光，色温调到 5000-5500K |
| 电脑屏幕灯 | 能（有条件） | 可以当辅光/反光用，但要调到同色温 |
| 房间灯泡（右后方 45°） | 能 | 做轮廓光，勾勒书的边缘 |

**这个条件完全够用。** 不需要买额外的灯。

**具体布置方案：**

```
                  【背景：见下文】
                      ↑
        ·—————————————·—————————————·
        |             |             |
        |  补光灯     |    书       |  房间灯泡
        | (主光)     |  (倾斜放置)  | (轮廓光)
        | 左前方      |             | 右后方45°
        ·—————————————·—————————————·
                      |
                 【手机/支架】
                      ↑
              电脑屏幕灯关掉或调暗
              （避免混合色温）
```

- 补光灯在左前方，抬高到 60-70°（解决反光）
- 书倾斜 15-30° 放在桌面上
- 房间灯泡在右后方 45°，做轮廓光
- 电脑屏幕灯拍摄时**关掉或调到最暗**，避免混合色温发绿
- 如果暗部太暗，在补光灯对面放一张白纸当反光板

**反光板不用买。** 一张 A4 白纸立起来就行，用书或夹子固定。如果面积不够，用两张拼。

### 背景怎么解决（一个人拍摄）

你没有助手帮你举背景，但有几种方案不需要人：

**方案一：买一个 L 型背景架（推荐）**

淘宝搜「产品拍摄背景架」或「静物台背景架」，30-80 块钱。就是一个金属架，上面可以夹背景纸/布，纸自然垂下来弯成弧形。一个人就能搞定。

优点：稳定、可重复使用、背景纸可以换
缺点：占桌面空间

**方案二：利用现有家具**

- 把背景纸用夹子夹在显示器顶部，纸自然垂下来
- 或者夹在椅背上，椅子放在桌子后面
- 或者用两个书立夹住背景纸两端，立在桌子后方

优点：不花钱
缺点：不太稳定，换背景麻烦

**方案三：纯墙面做背景**

如果你的墙是干净的白墙或浅灰墙，直接把桌子推到墙前面，用墙面当背景。产品离墙 30-50cm 就行。

优点：零成本
缺点：墙面颜色不可控，有污渍或开关插座会入镜

**我的建议：先用方案二或三起步，拍几条确认流程跑通了，再决定要不要买背景架。**

### 镜头角度：平行和俯视到底是什么意思

你问得很好。「平行」容易被误解。用图来解释：

```
俯视 90°（正上方往下拍）：
        📷
        ↓
     ————————  ← 桌面
      产品

略俯视 30-45°（最常用的产品拍摄角度）：
        📷
         \
          \
     ————————  ← 桌面
      产品

平行 0°（镜头和产品等高，水平拍）：
     📷 ————————→ 产品
     （在同一高度）
```

- **平行**：镜头和产品在同一高度，水平拍摄。这时候你看到的是产品的侧面。对于书来说，就是拍书脊那一面。这不是最常用的拍法。
- **略俯视 30-45°**：镜头比产品高一点，往下倾斜 30-45°。这是产品拍摄最常用的角度——你既能看到封面，又能看到一点书的厚度和侧面。大多数电商产品图都是这个角度。
- **俯视 90°**：正上方往下拍，只能看到封面平面。适合拍平铺效果（比如把书和配件摆在一起）。

**对于书类产品，推荐 30-45° 俯视。** 你既能展示封面设计，又能体现书的厚度和质感。

## 小结

- 前期控制色温：一个灯、一个色温、锁白平衡，绿光问题就解决了
- 书的反光：先抬高灯位到 60-70°，再倾斜书面 15-30°，最后考虑偏振片
- 你现有的设备完全够用，不需要额外买灯
- 背景：L 型背景架最省事，也可以用夹子夹在显示器/椅背上，零成本起步
- 镜头角度：30-45° 俯视是产品拍摄最常用的角度，既能看到封面又能体现厚度
