# 04｜手机拍摄参数、45° 角的精确含义、静物台值不值得买

## 这一篇要解决的问题

把上一篇遗留的五个实操问题逐个拆掉：手机专业模式怎么调、45° 角到底怎么量、黄光行不行、背景杂乱怎么办、静物台能不能一步到位。

## 正文

### 手机专业模式参数设置

你的场景：手机用支架固定，离产品 50cm 左右，拍书。下面是具体的参数。

**iPhone 用户：**

iPhone 没有原生「专业模式」，但可以这样操作：

- **曝光锁定**：长按屏幕 2 秒，出现「AE/AF 锁定」，然后上下滑动调整曝光补偿（小太阳图标）。拍产品一般往下拉 0.3-0.7 档，让画面略暗一点，高光不会过曝。
- **白平衡**：iPhone 原生相机不支持手动白平衡。如果你需要精确控制，用第三方 App（比如 ProCam、Halide），里面可以设色温值（K 值）。设到 5000-5500K。
- **对焦**：点击产品封面，锁定对焦。

**安卓用户（华为/小米/OPPO/vivo 等）：**

大多数安卓手机有「专业模式」或「Pro 模式」，打开后可以调这些参数：

| 参数 | 设什么 | 为什么 |
|---|---|---|
| ISO | 100-200 | 越低越好，噪点最少。光线不够时再往上调 |
| 快门速度 | 1/60-1/125 | 手机固定在支架上，不需要太快。光线暗就放慢到 1/30 |
| 白平衡（WB） | 5000-5500K，或选「日光」预设 | 防止自动白平衡跳来跳去 |
| 对焦模式 | AF-S（单次自动对焦） | 拍静物用单次对焦就够了 |
| 曝光补偿 | -0.3 到 -0.7 | 略微欠曝，保留高光细节 |
| 测光模式 | 点测光 | 对准产品测光，不受背景干扰 |

**一个关键点：ISO 和快门速度是联动的。** 光线充足时 ISO 100 + 快门 1/125；光线不足时先试 ISO 200 + 快门 1/60，还不够亮就继续降快门速度（但低于 1/30 手持会糊，支架固定的话可以到 1/15）。

**拍视频的话：**

| 参数 | 设什么 |
|---|---|
| 分辨率 | 1080p 或 4K |
| 帧率 | 30fps（日常）或 24fps（电影感） |
| 快门速度 | 帧率的 2 倍倒数（30fps → 1/60，24fps → 1/50） |
| ISO | 尽量低 |
| 白平衡 | 锁定 5000-5500K |
| 对焦 | 点击产品锁定 |

### 45° 角到底怎么量

这个问题你问了两次，说明之前解释得不够清楚。现在换一种方式。

**45° 角指的是：光线照射到产品表面时，光线和产品表面之间的夹角。**

用侧面图来解释：

```
情况 A：灯在产品正上方（90°）
        💡
        |
        |  ← 光线垂直射下来
        ↓
     ————————  ← 产品表面
     光线和表面夹角 = 90°

情况 B：灯在产品侧面（0°）
     💡 ————————→ 产品
     光线和表面平行，夹角 = 0°

情况 C：灯在产品侧前方（45°）
        💡
         \
          \  ← 光线斜着射下来
           \
     ————————  ← 产品表面
     光线和表面夹角 = 45°
```

所以「主光放在产品侧前方 45°」的意思是：

1. 灯在产品的侧面（不是正上方，也不是正前方）
2. 灯的高度使得光线射到产品表面时，形成大约 45° 的夹角
3. 具体操作：灯放在桌面上，距离产品 50-80cm，灯的高度比产品高 30-50cm

**怎么验证角度对不对？** 打开手机相机看画面。如果产品的亮面和暗面各占大约一半，角度差不多就是 45°。如果亮面多暗面少，说明灯太高太偏正面了；如果暗面多亮面少，说明灯太低太偏侧面了。

### 黄光行不行

黄光（色温 3000K 左右）可以拍，但有两个后果：

**后果一：后期可调空间小。**

黄光往冷方向调（3000K → 5500K），画面会变灰变绿。白光往暖方向调（5500K → 3000K）则很自然。所以用黄光拍，后期只能在暖色范围内微调，想变成中性白光几乎不可能。

**后果二：产品颜色会偏。**

白纸在黄光下变黄，蓝色产品在黄光下变灰。如果你的产品有颜色需要准确还原（比如封面有特定色彩），黄光会误导观众。

**结论：如果你只是想要温暖柔和的氛围，黄光可以。但如果你需要准确还原产品颜色，用 5000-5500K 的白光，后期再加暖色调。** 这样你既有准确的颜色基准，又有后期调色的自由度。

### 反光板怎么放

对，放在主光的对面。更具体一点：

```
        主光（左前方）
            \
             \
              产品 ———— 反光板（右前方）
             /
            /
        相机（正前方）
```

- 反光板和主光在同一水平高度（不需要太高）
- 朝向产品，反射主光的光到产品的暗部
- 距离产品 30-50cm
- 如果反光太强（暗部变得和亮部一样亮），把反光板拉远一点或换成更小的面积

### 背景杂乱怎么办

你说了背景是电视、显示器、显示器支架、书、桌面杂物。这个确实没法当背景用。

**最直接的解决方案：买一个静物台/布景台。**

你的问题是对的——静物台能不能一步到位？答案是：**能解决背景问题，但不能完全替代灯光布置。**

静物台的好处：
- 自带弧形背景，一个人就能拍出干净背景
- 小型静物台放在桌面上，不占太多空间
- 价格便宜，淘宝 30-100 块

静物台解决不了的：
- 布光还是需要你自己调（灯位、角度、柔光）
- 反光问题还是要靠调灯位解决
- 大件产品放不进去（但你的书没问题）

**我的建议：买一个静物台。** 30-80 块钱，一步解决背景问题，把精力集中在布光和拍摄上。淘宝搜「产品拍摄静物台」或「小型静物棚」，选 40-60cm 宽的就够了（书的尺寸）。

**买静物台的同时，还需要一个东西：夹子。** 用来固定背景纸、调整背景位置。淘宝几块钱一包。

### 你现在的采购清单

如果要一步到位解决你目前的所有问题：

| 物品 | 价格 | 解决什么问题 |
|---|---|---|
| 小型静物台/布景台 | 30-80 元 | 背景杂乱 |
| 手机 CPL 偏振镜 | 15-40 元 | 书的覆膜反光 |
| 背景纸（白色/浅灰） | 10-20 元 | 配合静物台使用 |
| 夹子若干 | 5-10 元 | 固定背景纸 |

总预算：60-150 元。你现有的灯和支架不需要换。

## 小结

- 手机拍摄：ISO 尽量低、白平衡锁定 5000-5500K、曝光略欠、点测光对准产品
- 45° 角 = 光线射到产品表面时与表面的夹角，不是灯的水平位置角度
- 黄光可以拍但后期空间小、颜色会偏，建议用白光拍、后期加暖
- 反光板放在主光对面，朝向产品，高度和主光持平
- 静物台能解决背景问题但不能替代布光，建议买一个 30-80 块的
- 采购清单总共 60-150 元
