# 01｜光是一切的起点

## 这一篇要解决的问题

理解「光」在产品拍摄中的核心作用——你拍出来的东西好不好看，80% 取决于光，不取决于相机。

## 正文

### 你手机里的「自动模式」在骗你

手机拍照时，算法会自动帮你拉高亮度、压暗部、提对比。结果就是：所有东西看起来都「还行」，但没有一个东西看起来「高级」。

原因很简单——算法追求的是「看得清」，而好看的画面追求的是「有层次」。

层次从哪来？从光的方向、强弱、软硬来。

### 光的三个基本属性

**方向**：光从哪里来，决定了物体的立体感。

- 正面光：物体平，没有阴影，像证件照
- 侧面光：一半亮一半暗，立体感最强
- 逆光：物体边缘发光，背景暗，有氛围感
- 顶光：从上往下打，适合拍食物、珠宝

**强弱**：光的亮度决定了画面的明暗对比。

- 强光 = 硬光 = 阴影边缘锐利（比如正午太阳）
- 弱光 = 软光 = 阴影边缘柔和（比如阴天）

**色温**：光的冷暖色调。

- 暖光（3000K 左右）：温馨、食欲、高级感
- 冷光（5500K 以上）：科技感、清爽、距离感
- 混合光：同一个画面里有冷有暖，容易脏

### 产品拍摄的布光公式

大多数产品拍摄，核心就是三盏灯：

```
主光（Key Light）
├── 最亮的那盏，决定整体明暗
├── 放在产品侧前方 45° 角
└── 用柔光箱/柔光布把光打散

辅光（Fill Light）
├── 比主光弱，用来补暗部
├── 放在主光对面
└── 强度约为主光的 1/2 到 1/3

轮廓光（Rim Light）
├── 从后方打，勾勒产品边缘
└── 让产品从背景里「跳出来」
```

### 不同产品的布光思路

| 产品类型        | 核心挑战  | 布光策略          |
| ----------- | ----- | ------------- |
| 哑光产品（书、布料）  | 容易拍平  | 侧光 + 弱辅光，强调纹理 |
| 反光产品（金属、玻璃） | 反射杂乱  | 大面积柔光，避免点光源   |
| 透光产品（液体、香水） | 通透感不够 | 逆光 + 黑色背景     |
| 食物          | 要拍出食欲 | 侧逆光 + 暖色温     |

### 一个最小可用方案

如果你现在只有手机和一盏台灯：

1. 把台灯放在产品侧面 45°
2. 台灯前面蒙一层白纸（柔光）
3. 产品另一侧放一张白纸（反射补光）
4. 背景用纯色纸或布

这个方案能解决 80% 的基础拍摄问题。剩下的 20% 靠多拍多练。

## 小结

- 拍出来不好看，先检查光，不要先换相机
- 光有三个维度：方向、强弱、色温，每个维度都会影响画面感觉
- 三盏灯（主光 + 辅光 + 轮廓光）是产品拍摄的基础布光
- 不同材质的产品需要不同的布光策略，反光产品最难处理
- 最小方案：一盏灯 + 柔光 + 反射板，就能起步
