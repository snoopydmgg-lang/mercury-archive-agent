## 核心发现（2026-05-29 验证）

### 1. 5s完播率<25%是硬天花板

**证据**（3个样本）：
- 摄影构图（5/22）：5s完播率 24.2% → 播放 243
- 版式之道（5/20）：5s完播率 22.29% → 播放 1,110
- 版式之道（5/24）：5s完播率 22.45% → 播放 542

**结论**：无论composite多高，5s完播率<25%都会把流量锁在基础盘以下。

### 2. 品类势能是独立于composite的隐藏变量

**证据**：
- 有兽焉品类：1,092 和 413（中等偏弱）
- 版式之道品类：1,110 和 542（中等，但不稳定）
- 摄影构图品类：243（极弱，与账号不匹配）

**结论**：同为带货品类，实绩差异可达4x以上。品类与账号受众匹配度是独立的预测因子。

### 3. 版式之道品类势能不稳定

**证据**：
- 5/20（网格角度）：1,110 播放
- 5/24（留白角度）：542 播放

**结论**：文案角度对版式之道品类影响巨大（2x差异），需要找到正确的文案角度。

### 4. "先看再讲"结构不是万能公式

**证据**：
- 版式之道5/24复制草莓文案的"先看再讲"结构，但63.06%跳出率
- 该结构在非草莓品类失效

**结论**：成功公式不能简单复制，需要验证具体场景。

### 5. 有兽焉品类势能中等偏弱

**证据**：
- 有兽焉5/25：1,092 播放
- 有兽焉5/26：413 播放

**结论**：有兽焉IP有加持但有限，不如版式之道品类。

## 预测校准教训

### HP维度需要拆分

**问题**：当前HP定义混淆了"抓注意力"和"维持注意力"两个独立能力。

**证据**：
- 摄影构图5/22：1s留存85.69%（钩子有效）但2s跳出45.55%（维持失败）
- 有兽焉5/25：数据钩子抓了人但42.97%跳出

**建议**：HP打分时必须参考5s完播率预期。

### form_coefficient需要下调

**问题**：带货品类的form_coefficient 0.6仍然偏高。

**证据**：
- 摄影构图composite 3.09实绩243（高估5x）
- 版式之道composite 3.26实绩1,110（接近baseline）

**建议**：带货品类、"讲解式"风格下调至0.5。

### "话术感"是平台级负面信号

**证据**：
- 有兽焉5/26：搜索主导（29.5%）+推荐降权（63.9%，-12.2%）
- 抖音审核标记"标准话术"与实绩一致

**建议**：去掉"话术感"，增加个人态度和使用场景。
