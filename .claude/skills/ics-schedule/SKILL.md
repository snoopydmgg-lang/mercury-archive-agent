# ICS日程管理

## 功能

1. **生成日程ICS文件**：根据用户提供的日期、时间生成ICS文件
2. **自动保存到收件箱**：生成的ICS文件自动保存到 `00_InBox_收件箱/`
3. **设置提醒**：自动添加30分钟前提醒

## 脚本位置

`06_Python Scripts/06_工具/ics_generator.py`

## 用法

```bash
cd "E:/1.work/douyin/1.shuixing/06_Python Scripts"
python ics_generator.py "<标题>" "<日期>" "<时间>" <时长> <提醒分钟>

# 参数说明
# 标题: 事件名称（必填）
# 日期: YYYY-MM-DD 格式（必填）
# 时间: HH:MM 格式（必填）
# 时长: 分钟数（默认60）
# 提醒: 提前分钟数（默认30）
```

## 触发场景

当用户说以下话时，自动生成ICS：

1. **提醒我做什么** → "提醒我下午3点开会"
2. **设置日程** → "设置日程：明天下午2点去医院"
3. **具体时间** → "明天上午10点有会"
4. **周几** → "周五下午5点复盘"
5. **今天** → "今天下午2点半去医院"

## 流程

### 1. 识别时间信息

从用户话语中提取：
- 标题（事件内容）
- 日期（今天/明天/具体日期/周几）
- 时间（几点几分）
- 时长（可选，默认60分钟）
- 提醒时间（可选，默认30分钟）

### 2. 确认信息

展示给用户确认：
- 标题：xxx
- 日期：2026-03-xx
- 时间：xx:xx
- 时长：xx分钟
- 提醒：提前xx分钟

### 3. 生成ICS

执行脚本，保存到收件箱：
```
E:/1.work/douyin/1.shuixing/00_InBox_收件箱/{标题}.ics
```

### 4. 通知用户

告诉用户文件已生成，提醒他导入手机。

## 日期解析规则

| 用户说 | 解析为 |
|--------|--------|
| 今天 | 当前日期 |
| 明天 | 当前日期+1 |
| 后天 | 当前日期+2 |
| 周一/周二... | 下一个指定星期几的日期 |
| 下午/上午 | 转换：下午=12-18，上午=6-12 |

## 示例

用户说："明天下午两点半去医院"

解析：
- 标题：去医院
- 日期：2026-03-17（明天）
- 时间：14:30
- 时长：120（默认或询问）
- 提醒：30

执行：
```bash
python ics_generator.py "去医院" "2026-03-17" "14:30" 120 30
```

输出文件：`E:/1.work/douyin/1.shuixing/00_InBox_收件箱/去医院.ics`

## 注意事项

- 必须先确认日期和时间再生成，不能自动确认
- 如果信息不全（如只说了"去医院"没说时间），要询问具体时间
- 生成后告诉用户文件位置，提示导入手机
- 如果用户说的日期是"这周五"，当前是周一/周二...周五，需要计算具体日期
