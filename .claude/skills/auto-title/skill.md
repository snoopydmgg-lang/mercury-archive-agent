# 自动写标题和简介

## 功能

读取飞书多维表格中状态为"已完成"但缺少标题/简介的记录，用 DeepSeek 自动生成：
- 视频标题（20字以内，含强情绪符号）
- 视频简介（50-100字，含话题标签）
- 商品短标题（严格10字以内）

## 脚本位置

`06_Python Scripts/01_AI文案/自动写标题和简介.py`

## 使用方法

```bash
cd "06_Python Scripts/01_AI文案" && python 自动写标题和简介.py
```

## 触发词

- "生成标题"
- "自动写标题"
- "生成简介"
- "回填标题"
- "更新飞书标题"

## 注意事项

- 脚本已内置编码修复，可直接运行
- 只处理"已完成"状态且缺少标题/简介的记录
- 不会重复生成已有标题的记录
