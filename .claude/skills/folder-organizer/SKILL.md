| 功能 | 说明 |

| 项目目录整理 | 整理项目文件夹结构 |

## 收件箱整理流程

### 1. 清理收件箱（全部删除）

**当用户要求清空收件箱时：**

1. **列出收件箱内容**
   ```bash
   ls -la "E:/1.work/douyin/1.shuixing/00_InBox_收件箱/"
   ```

2. **删除所有文件**
   ```bash
   rm -rf "E:/1.work/douyin/1.shuixing/00_InBox_收件箱/"*
   ```

3. **确认清理完成**
   ```bash
   ls -la "E:/1.work/douyin/1.shuixing/00_InBox_收件箱/"
   ```

### 2. 整理收件箱（按规则分类）

**当用户要求整理收件箱时：**

运行整理脚本：
```bash
cd "E:/1.work/douyin/1.shuixing/06_Python Scripts"
python 收件箱整理.py
```

**脚本功能**：
1. 为文件名添加修改日期后缀（格式：`原名_YYYYMMDD.扩展名`）
2. 按文件名关键字自动分类到对应目录
3. 自动删除 Windows 临时文件（`~$*`）

### 3. DropIt 文件名分类规则

**文件名规范**：`{项目名}-{日期}-{类型}.扩展名`

例如：`小王子-20260315-成品.mp4`

**分类规则**：

| 规则名 | 文件名关键字 | 目标目录 |
|--------|-------------|----------|
| 成品冷备 | `*-*-成品*` | `02_Archive_冷备份/年/月/` |
| 封面素材 | `*-*-封面*` | `01_Projects_制作中/{项目}/01_素材_试用装/00_封面设计` |
| 未命名 | `*`（默认） | `00_InBox_收件箱/` |
| 素材/音频 | `*-*-素材*` 或 `*-*-音频*` | `01_Projects_制作中/{项目}/01_素材_试用装/` |
| 文案/脚本 | `*-*-文案*` 或 `*-*-脚本*` | `01_Projects_制作中/{项目}/02_脚本_逻辑链/` |
| 工程文件 | `*-*-工程*` | `01_Projects_制作中/{项目}/03_工程文件/` |

**其他分类规则**：

| 关键字 | 目标目录 |
|--------|----------|
| 对标达人 | `04_数据分析结果/` |
| 达人监测 | `04_数据分析结果/达人监测/` |
| 抖音数据 | `04_数据分析结果/抖音数据/` |
| 水星艺术馆 | `04_数据分析结果/水星艺术馆/` |
| 数据表现 | `04_数据分析结果/数据表现/` |
| 作品列表 | `04_数据分析结果/作品列表/` |
| data | `04_数据分析结果/data/` |
| .docx, .doc | `01_Projects_制作中/` |
| .txt, .md | `01_Projects_制作中/` |

### 3. 更新目录结构文档

**每次整理完收件箱后，必须自动更新 CLAUDE.md 中的目录结构。**

1. **列出项目目录内容**
   ```bash
   ls -la "E:/1.work/douyin/1.shuixing/01_Projects_制作中/"
   ```

2. **列出全局资源目录内容**
   ```bash
   ls -la "E:/1.work/douyin/1.shuixing/03_Assets_全局库/"
   ```

3. **列出根目录所有文件夹**
   ```bash
   ls -la "E:/1.work/douyin/1.shuixing/"
   ```

4. **读取当前 CLAUDE.md 中的目录结构部分**
   - 找到 `## 2. 目录结构 (PARA 风格)` 或 `## 当前目录结构` 章节

5. **更新 CLAUDE.md**
   - 根据实际目录结构更新目录结构部分
   - 保持格式一致：使用 `├──` 表示子目录
   - 重点更新：
     - `01_Projects_制作中/` 下的所有子项目文件夹
     - `03_Assets_全局库/` 下的子目录
     - 确认是否有新增的顶层目录
