# 医药行业合规红线

## 定位

这个文件的目的是保护使用者的职业安全。不是教你"怎么绕过规则"，而是帮你看清楚"线在哪里"，在合规范围内把客情做好。

---

## 一、绝对红线（碰了就是违法，没有例外）

### 1. 现金和类现金利益

- **禁止**：直接给现金、微信/支付宝转账、购物卡、充值卡、礼品卡
- **禁止**：以任何名义给医生个人报销费用（机票、餐费、购物）
- **禁止**：给医生家属好处（安排工作、子女入学帮忙等与业务挂钩的行为）
- **理由**：反不正当竞争法第七条，商业贿赂认定

### 2. 与处方量/用量挂钩的利益输送

- **禁止**：按处方量给回扣、提成、"咨询费"
- **禁止**：以"讲课费""顾问费"名义支付与处方量挂钩的费用
- **禁止**：统方行为（获取医生个人处方数据并据此支付报酬）
- **理由**：这是商业贿赂的核心认定要素，查到即定性

### 3. 虚假学术活动套现

- **禁止**：虚构学术会议、编造参会名单套取会议经费
- **禁止**：以学术名义组织旅游、娱乐活动
- **禁止**：给讲者的费用明显超出合理市场标准
- **理由**：骗取公司费用+变相行贿，双重违法

### 4. 代挂号、代购药

- **禁止**：帮医生或其家属代开处方药
- **禁止**：利用职务便利为他人获取紧缺药品资源
- **理由**：违反药品管理法规

## 二、灰色地带（不违法但有风险，需要判断）

### 1. 请客吃饭

| 风险等级 | 判断标准 | 建议 |
|----------|----------|------|
| 低风险 | 工作餐、人均 200 以内、有正当业务讨论 | 可以做，保留消费凭证和会议记录 |
| 中风险 | 正式宴请、人均 200-500、有少量业务讨论 | 控制频次（同一客户季度不超过 2 次），多人参加 |
| 高风险 | 高档消费、人均 500+、纯社交无业务内容 | 不建议，容易被定性为"拉拢腐蚀" |

**安全做法**：每次饭局留痕（和谁、聊了什么、达成什么共识），既是合规保护，也是工作记录。

### 2. 学术会议邀请讲者

| 安全要素 | 说明 |
|----------|------|
| 有真实的学术议题 | 不是随便找个题目凑数 |
| 讲者费合理 | 参照行业标准，不超出市场价 |
| 有会议记录和签到 | 能证明活动真实发生 |
| 非处方挂钩 | 不能"用我们的药才请讲课" |

**风险信号**：同一个人被反复邀请讲同一个题目、讲者费明显高于市场价、活动照片造假——这些是审计重点。

### 3. 赠送礼品/样品

| 风险等级 | 判断标准 | 建议 |
|----------|----------|------|
| 低风险 | 公司统一制作的品牌周边（笔、本、U 盘）、学术资料 | 可以，走公司流程 |
| 中风险 | 小额礼品（200 以内）、节日伴手礼 | 控制频次，最好多人一起送，不单独给 |
| 高风险 | 贵重礼品（奢侈品、电子产品）、个人化礼物 | 不建议，容易被认定为利益输送 |

**原则**：礼品要"能放上台面"——如果这个东西被放在科室公共区域不会觉得奇怪，那大概率安全。

### 4. 帮忙类事项

**可以做**（正常社交范围内）：
- 帮忙订个会议室
- 代领一份快递
- 分享一个行业资讯
- 帮忙推荐靠谱的装修公司（非利益关联）

**不能做**（超出正常社交范围）：
- 帮客户私人办的事和业务挂钩
- 涉及金钱往来
- 利用公司资源为个人服务
- 需要隐瞒或说谎才能做的事

## 三、合规的客情维护方式

以下做法既合规又有效，是长期经营关系的正道：

### 1. 学术服务（最核心）

- 组织科内会、院内会、城市会
- 邀请参加正规学术会议（有CME学分的更好）
- 提供最新的临床研究数据和文献
- 帮助客户了解竞品动态和行业趋势

**本质**：你能给医生提供的最大价值是"信息"和"平台"，不是钱。

### 2. 专业能力支持

- 协助准备学术演讲的PPT材料（不涉及学术造假）
- 提供产品相关的循证医学证据
- 帮助对接其他医院的专家做学术交流
- 及时反馈产品在临床使用中的真实反馈

### 3. 正常社交礼仪

- 节日问候（微信/短信，不附带任何要求）
- 生日祝福（知道就发，不知道不刻意打听）
- 工作餐（有业务议题，人均合理）
- 婚丧嫁娶随礼（按当地普通同事标准，不过高）

### 4. 情绪价值

- 耐心倾听（很多医生的压力无人可说）
- 记住客户说过的小事（孩子考试、家人生病）
- 在客户需要帮忙时伸出援手（非利益关联的正常帮助）
- 真诚赞美专业能力（有具体内容，不空洞）

## 四、安全行为检查清单

在做任何客情动作之前，过一遍这个清单：

- [ ] 这件事如果被我领导知道了，我能解释得清楚吗？
- [ ] 这件事如果被纪检知道了，我能说得明白吗？
- [ ] 如果这个医生明天和我翻脸了，这件事会不会变成把柄？
- [ ] 这件事有没有书面记录能证明"合规"？
- [ ] 其他代表做同样的事，我会觉得正常吗？

**如果任何一个问题的答案让你犹豫，那就不要做。**

## 五、被客户暗示要好处时的应对

这是医药代表最常见也最棘手的合规场景。核心原则：**温和拒绝，给台阶下，提供替代方案**。

### 应对策略

1. **装听不懂**（适用于暗示阶段）——对方没有明说，你就当没听懂，把话题转到学术上
2. **搬出公司制度**（适用于明示阶段）——"这个我们公司有严格规定，我真做不了主，但我可以用XX方式支持您"
3. **提供合规替代**——对方真正需要的可能是"被重视""有面子""有资源"，用合规方式满足这些需求
4. **记录留痕**——如果对方明确索要违规利益，留好证据保护自己

## 六、特别提醒

1. **合规不是障碍**——真正厉害的代表是在规则内把关系做到位，而不是靠砸钱
2. **短期利益 vs 长期安全**——一次违规可能带来短期业绩，但一旦出事就是职业生涯的终结
3. **公司合规部门是盟友**——遇到拿不准的事，主动咨询公司合规部门，这不丢人
4. **每个客户都有底线**——尊重这条底线，不试探、不突破、不侥幸
