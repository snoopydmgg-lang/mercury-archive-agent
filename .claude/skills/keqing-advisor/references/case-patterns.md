# 典型场景案例模式库

## 破局思维——从马伯庸学到的方法论

### 李善德式破局思维

《长安的荔枝》里的核心智慧：接到一个"不可能完成的任务"时，不要先想"我做不到"，而是想"怎么拆解到我能做到"。

**方法论提炼**：

1. **拆解到最小可行单元**——不要看整座山，只看下一步脚踩哪里。一个大指标拆成每周的小目标，每个小目标再拆成每天的动作。

2. **借用他人的利益驱动力**——让这件事对别人也有好处，他们就会主动帮你推。不要单打独斗，找到"做这件事对你也有利"的人。

3. **用流程和细节保护自己**——每一步都留痕、每一步都有人确认、每一步都有备选方案。当事情出了问题，你能说清楚"我做了什么、为什么这么做"。

4. **预判"上面"的变卦**——领导的承诺、客户的口头同意，都不算数。只有落到纸面上、形成惯例、变成对方的成本，才算真正"锁定"。

### 天庭办事逻辑

《太白金星有点烦》里的核心智慧：多头领导、各方都要交代时，最危险的不是做错事，而是"被夹在中间还说不清楚"。

**方法论提炼**：

1. **识别真正的决策者**——你以为的决策者（科室主任）可能只是明面上的，真正的决策者可能是院长、药剂科主任、甚至是院长夫人。搞清楚"谁说了算"比"怎么说"更重要。

2. **各方都满意的汇报术**——同一个动作，对不同的人讲不同的版本。对A讲"这是我们对您的支持"，对B讲"这是A主任的建议"。不撒谎，但选择性地突出不同信息。

3. **夹缝中的自我保护**——当你被两方拉扯时，最高策略不是"选边站"，而是"让两边都觉得你是他的人"。这需要极高的信息管理和情绪控制能力。

4. **背锅预警**——当事情开始出问题，第一个动作是"确认自己有没有被留证据"。提前建立好"我做了什么"的记录链。

## 十大高频场景分析

### 场景一：新接手科室，前任口碑不好

**局面要点**：
- 前任代表留下的负面印象会自动"继承"到你身上
- 客户不知道你是谁，会默认"又是一个来忽悠的"
- 可能存在前任没处理完的历史问题（承诺没兑现、投诉没解决）

**常见错误**：
- 上来就说"我和XX不一样"——越解释越可疑
- 急于证明自己，第一次拜访就推产品——让人觉得你也是来"卖东西的"
- 否认前任的问题——客户会觉得你们是一伙的

> 🧠 本场景框架：差序格局（你在"有前科的人群里的新面孔"，需要先回到正常外人位置）+ 面子分析（他需要的不是面子，是安全感）

**推荐思路**：
1. 第一次见面不谈产品，只做一件事：听。"我刚接手，想先了解一下科室的情况，您方便的话能跟我说说之前有哪些地方做得不到位的吗？"
2. 对前任的问题不评价、不否认，只说"我了解了，后面我注意"
3. 从小事做起证明靠谱——答应的事情按时做到，哪怕只是"明天把资料发给您"
4. 给 2-3 周的缓冲期，用行动替代语言

**参考话术**：
- "X老师您好，我是新接手咱们科室的小X，之前同事在对接上可能有些地方没做到位，我想先来听听您的想法，有什么做得不好的您直接跟我说。"
- "您提的这些问题我都记下来了，我先整理一下，回头给您一个明确的回复。"

### 场景二：主任态度冷淡但小医生关系好

**局面要点**：
- 科室权力结构通常是金字塔型——主任说了算
- 小医生关系好是突破口，但不能跳过主任
- 主任冷淡的原因可能是：不信任新人、竞品绑定、性格如此、前任的遗留问题

**常见错误**：
- 只和小医生玩，把主任晾着——主任会觉得你不把他放眼里
- 通过小医生去"攻略"主任——容易被主任看穿，而且让小医生为难
- 资源全押在主任身上，忽视小医生——万一主任这条线打不通，连退路都没有

> 🧠 本场景框架：差序格局（主任在外围圈、主治在中间圈，7:2:1精力分配）+ 关键对话（找共同目标，用学术价值而非人情突破）

**推荐思路**：
1. 资源分配遵循"7:2:1"——70%精力给主任、20%给关系好的小医生、10%给其他科室成员
2. 通过小医生了解主任的真实需求和性格特点（不是让他帮你说话，是帮你"摸情况"）
3. 给主任找到一个他需要你的理由——学术支持、信息差、某个具体问题的解决方案
4. 耐心，不急于突破，用 1-2 个月慢慢渗透

**参考话术**（对小医生）：
- "王老师，咱们主任平时比较关注哪些方面的学术信息？我想提供一些更有针对性的资料。"
- "最近科室有没有什么需要协助的地方？我在公司这边能调动一些资源。"

**参考话术**（对主任，找切入点）：
- "X主任，最近看到一篇关于XX的最新研究，和咱们科室的方向很相关，我给您打印了一份，您有空看看。"
- "我们下周有个线上学术沙龙，讲者是XX医院的XX教授，我帮您留了一个名额？"

### 场景三：客户暗示想要超出合规范围的好处

**局面要点**：
- 对方可能是在"试探"你的底线
- 对方可能已经被竞品"惯"坏了
- 对方可能确实有难处，不是故意为难你
- 这个时刻决定了你们关系的底色

**常见错误**：
- 直接说"不行，这是违法的"——撕破脸，以后没法合作
- 假装没听懂然后避开——问题没解决，下次还会来
- 委曲求全答应下来——一旦开头，后面的胃口只会越来越大

> 🧠 本场景框架：关键对话（高风险拒绝时营造安全感+事实-感受分离）+ 刘墉自保（不留把柄+漂亮地拒绝：理解+限制+替代）+ 合规红线

**推荐思路**：
1. 先判断对方是"明示"还是"暗示"——暗示阶段可以装听不懂
2. 如果是明示，用"公司制度"做挡箭牌（不是"我不愿意"，是"公司有规定"）
3. 立刻提供合规的替代方案，让对方感觉"虽然A不行，但B也不错"
4. 态度温和但立场坚定——"为难"的表情比"拒绝"的话更有说服力

**参考话术**：
- 暗示阶段（装听不懂，转话题）："您说的这个我理解，其实公司对咱们学术活动的支持力度挺大的，比如下个月有个城市会，我帮您争取个名额？"
- 明示阶段（搬制度）："X老师，您说的这个我真做不了主，公司这边有非常严格的合规流程，我怕给您添麻烦。不过学术支持这块我可以全力配合，您看XX方面有没有我能帮上忙的？"
- 如果对方坚持："我理解您的想法，但这个我确实过不了合规。不过您看这样行不行——[提出替代方案]。"

### 场景四：竞品代表和关键客户走得很近

**局面要点**：
- "近"可能意味着利益绑定（危险）、也可能只是关系好（可竞争）
- 竞品代表的优势可能是：来得早、人情做得深、产品确实有优势
- 正面攻击竞品是最差策略——客户会反感

**常见错误**：
- 当着客户面说竞品坏话——显得格局小
- 试图在人情上"超过"竞品——很容易变成恶性竞争，而且你不知道对方投了多少
- 因为觉得打不过就放弃——客户还没说不用你的产品

> 🧠 本场景框架：差序格局（你在外围圈，竞品可能在中间圈，不要在人情深度上硬碰硬）+ 影响力·社会认同（用真实的多中心数据而非人情取胜）+ 刘墉自保（看穿不说穿：竞品的利益绑定你知道就好，不要点破）

**推荐思路**：
1. **差异化竞争**——不要在竞品的强项上硬碰硬，找到你的独特价值
2. **学术路线**——用循证数据说话，这是竞品代表靠"人情"弥补不了的
3. **找到缝隙**——再好的关系也有盲区，可能是某个学术问题没被解答、某个临床需求没被满足
4. **做好自己人**——不贬低对手，只证明自己更专业、更靠谱

**参考话术**：
- "XX代表确实挺用心的，我听说他们产品在XX方面表现不错。不过我们最近有个多中心研究的数据，在XX指标上有一些新的发现，您有兴趣看看吗？"
- （当客户说"我和XX代表关系很好"）"那挺好的，说明您这个科室对治疗方案很重视。我也希望有机会能跟您深入合作，到时候您对比一下两个方案，选最适合您科室的。"

### 场景五：饭局的座次、敬酒、话题禁区

**局面要点**：
- 饭局不是"吃饭"，是"社交场"——目的是加深关系、传递信息、观察人
- 座次反映了权力关系，搞错了会得罪人
- 饭局上说的话比正式场合更真实，但也更容易被记住

**座次规则**：
- 主位（面对门的位置）：留给最重要的客人或买单的人
- 主位两侧：次重要的人
- 你（请客方）坐在主位对面或靠近门口的位置（方便叫服务员、买单）
- 如果有多个客户：让客户之间自己选座位，你不要安排，除非客户让你安排

**敬酒规则**：
- 第一轮敬酒：你先站起来，敬最重要的客人，杯子低于对方
- 顺序：按地位从高到低，不要跳过中间的人
- 敬酒词：简短、真诚、有具体内容。"X主任，感谢您一直以来的支持"比"我敬您"好
- 量力而行：不要劝酒、不要灌酒、自己也别喝多。客户能喝多少喝多少，你不能比客户先醉

**话题禁区**：
- 政治、宗教——除非客户主动聊，而且你很确定他的立场

> 🧠 本场景框架：差序格局（座次反映关系圈层排序）+ 面子操作（敬酒=给面子的公开仪式，座次=地位的无声表达）+ 刘墉心法（话到嘴边留半句：饭局上说的话比正式场合更容易被记住）

**推荐话题**：
- 对方的专业成就（真心请教，不是拍马屁）
- 行业动态（国家政策、最新研究、其他医院的做法）
- 子女教育、养生、旅游——安全且容易找到共同点
- 对方最近的公开成绩（论文发表、获奖、会议发言）

### 场景六：客户帮了忙，如何还人情

**局面要点**：
- 还人情是一门技术活——还轻了显得不重视，还重了让对方有压力
- 最好的人情是"对方不觉得你在还人情"
- 时机比方式更重要——不要帮完忙第二天就"回报"，太刻意

**常见错误**：
- 马上送等价或更贵的礼物——像"交易"，侮辱了对方的善意
- 只在口头感谢没有后续行动——说了谢谢然后人消失了
- 欠太久不还——人情是有"利息"的，越拖越难还

> 🧠 本场景框架：人情账户（大额存款不能用交易思维清账，还人情不是等价交换）+ 面子操作（在他需要的场景给他做面子，比私下送礼有效）+ 刘墉心法（人情是存款不是筹码：帮完就忘，不在公开场合暗示对方欠你）

**推荐思路**：
1. 第一时间真诚感谢（微信或当面，具体说出帮了什么忙）
2. 在 1-2 周内找一个自然的机会"回馈"——不是直接还，而是"恰好"有一个对对方有用的信息或资源
3. 如果对方帮的是大忙，用"分次小额"的方式还——请吃个饭（不是大餐）、送个小礼物（不是贵的）、提供一个学术信息
4. 最高级的还人情：帮对方解决一个他自己都没想到的问题

**参考话术**：
- 感谢："X主任，上次的事情真的太感谢了，帮了我大忙。我知道您时间宝贵，专门抽时间帮我，我记在心里了。"
- 自然回馈："对了，上次您提到在关注XX方面的进展，我刚好拿到一份最新的数据，给您发过去？"
- 请吃饭："最近新开了一家XX菜，评价不错，您哪天方便我请您尝尝？就咱俩，聊聊天。"

### 场景七：被客户放鸽子/临时取消

**局面要点**：
- 临时取消的原因可能和你无关——科室来了急诊、领导突然开会、家里有事
- 也可能和你有关——对方觉得见你没价值、故意晾你
- 区分这两种情况，采取不同策略

**常见错误**：
- 马上追问"那什么时候方便"——给人压迫感
- 表现出不高兴——对方下次更不想见你
- 当作没发生——浪费了一次了解对方真实态度的机会

> 🧠 本场景框架：刘墉心法（场面话要会听：对方说"最近忙"是真是假看行动不看言语）+ 圆通智慧（以退为进：不追问，留余地，给对方空间）+ 后备方案（被放鸽子的备选去处）

**推荐思路**：
1. 第一反应：表示理解。"没关系，您忙您的，不着急。"
2. 等 1-2 天后，找一个非拜访的理由重新联系（发个资料、分享个信息），自然地重新约时间
3. 如果连续被放 2 次以上：反思自己的拜访是否有价值，是否需要改变方式
4. 如果是故意晾你：降低频率，但不要断——偶尔发个有价值的信息保持存在感

**参考话术**：
- 当次回应："没事X主任，您先忙，改天再约，不着急的。"
- 重新约（2天后）："X主任，上次咱们没聊成，刚好我这边有一份XX的资料想给您看看，您看这周哪天方便我过去一趟？就十分钟。"
- 连续被拒后（降低频率）：不再主动约见面，改为定期发学术信息，等对方主动。

### 场景八：学术会议邀请讲者的沟通策略

**局面要点**：
- 医生的学术需求是真实的——他们需要发论文、晋升、扩大影响力
- 学术会议是合规且有效的客情方式
- 邀请的核心是"对医生有什么好处"而不是"对我有什么好处"

**常见错误**：
- 只说"我们有个会想请您讲课"——没有说清楚价值
- 临时邀请——医生时间很紧，临时约大概率被拒
- 不说明讲者费和具体安排——让人觉得不靠谱

> 🧠 本场景框架：影响力·社会认同+权威（学术会议=权威平台+同行背书双重效应）+ 人情账户（讲者名额是合规的大额存款）+ 合规检查（讲者费合理/真实议题/非处方挂钩）

**推荐思路**：
1. 提前 2-4 周发出邀请，给对方留准备时间
2. 说清楚：什么主题、什么受众、时间地点、讲者费、有没有其他讲者
3. 强调学术价值："这次来的都是XX领域的专家，对您在XX方面的研究很感兴趣"
4. 如果对方犹豫：提供灵活性——"时间不合适可以调整"、"可以线上参与"

**参考话术**：
- 邀请："X主任，我们下个月 15 号有一个关于XX的学术沙龙，参会的都是咱们市XX领域的专家。我跟项目组推荐了您，想邀请您做一个 20 分钟的专题分享，讲者费是XX元。您看时间方便吗？"
- 被拒时的跟进："没关系，这次时间确实紧。我把会议资料整理好发给您参考，下次有机会咱们再合作。"
- 如果对方感兴趣但有顾虑："您有什么需要我这边配合的尽管说，PPT材料、数据支持我都可以帮您准备。"

### 场景九：客户之间有矛盾，被夹在中间

**局面要点**：
- 最典型的场景：科室主任和副主任不和、同一个医院的不同科室有竞争
- 你两边都要维护关系，但两边都不想让你和对方关系好
- 这是最考验信息管理能力的场景

**常见错误**：
- 选边站——另一方会记恨你
- 两边传话——消息一定会泄露，你变成"不可信任的人"
- 假装不知道——但你的一举一动两边都看着

> 🧠 本场景框架：天庭办事逻辑（识别真正的决策者+信息隔离+夹缝中的自我保护）+ 刘墉自保（你的秘密自己守住：和A说的话绝不传到B那里）

**推荐思路**：
1. **信息隔离**——和A说的话，绝不传到B那里。包括"无伤大忌"的信息
2. **对两边都保持专业距离**——不要跟任何一方"好到像自己人"
3. **不做裁判**——两边吵架时不要发表意见，不要安慰一方批评另一方
4. **找到"安全的交集"**——在双方都认同的事情上合作（比如共同的学术目标）
5. **向上管理**——如果矛盾太大影响工作，向自己领导汇报，请领导定夺

**参考话术**（当一方试探你的立场）：
- "X主任，我和各科室合作都是为了把学术活动做好，具体科室之间的事情我不太了解，也不敢乱说。"
- （如果一方问你"XX主任怎么说我的"）"上次主要是聊学术方面的事情，其他没怎么深入。对了，您这边最近有什么需要我协助的吗？"

### 场景十：节日问候如何不落俗套又不越界

**局面要点**：
- 节日问候是最基础的客情动作，也是最容易做砸的
- 群发的消息不如不发——会让人觉得你不重视
- 不同关系阶段的问候方式完全不同

**常见错误**：
- 群发祝福短信——一看就是复制粘贴的，减分
- 问候里夹带产品推广——"祝您中秋快乐，顺便说一下我们的产品……"——大忌
- 送月饼/粽子等传统礼品——千篇一律，没有记忆点
- 深夜或凌晨发消息——打扰人休息

> 🧠 本场景框架：差序格局（外围/中间/核心三圈层的问候方式完全不同）+ 面子操作（个性化问候=给面子，群发=丢面子）+ 人情账户（节日是小额存款的最佳时机）

**推荐思路**：

**外围圈客户**（不太熟）：
- 微信发一条简短的节日问候
- 内容：节日祝福 + 一句个性化的话（"上次您提到XX，祝XX顺利"）
- 不送礼、不提业务、不要求回复
- 时间：节日当天上午 9-10 点

**中间圈客户**（有交情）：
- 微信问候 + 一通电话（不超过 2 分钟）
- 电话内容：节日祝福 + 简单近况 + "有什么需要帮忙的说一声"
- 可以送小礼物（公司品牌周边或实用小物），不超过 200 元
- 时间：节日前 1-2 天

**核心圈客户**（自己人）：
- 不需要等节日才联系，日常就有互动
- 节日当天可以发一条只有你们懂的内容（之前聊天的梗、共同的经历）
- 可以约饭，但不要在节日当天（太刻意），节日前后都可以
- 礼物可以更个人化（对方提过想要的东西），但注意合规

> ⚠️ 合规边界提醒：礼品限于正常社交礼仪范围（通常单次不超过一两百元的食品/土特产类）；仅限节日等正常社交节点，不可形成定期给付模式；现金等价物（卡券）任何金额都不行——即使是核心圈客户。

**参考话术**（个性化节日问候）：
- "X老师，中秋快乐！上次您说孩子快考试了，这会儿应该放榜了吧？祝一切顺利。"
- "X主任，新年好！今年在您的指导下学到了很多，感谢您一直以来的指点。新的一年继续加油！"
- （核心圈客户）"姐，中秋快乐。上次你推荐的那家月饼我买了，确实不错，给你留了一盒，啥时候方便我给你送过去。"
