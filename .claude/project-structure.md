## 根目录保护规则

| 规则 | 说明 |
|------|------|
| 根目录只允许上述目录存在 | 任何新建必须先确认归类 |
| `npm init`/`pip install` 禁止在根目录执行 | 必须指定目标目录 |
| Python 代码 → `06_Python Scripts/` | .py 禁止散落他处 |
| 临时文件用完即删（GC） | 根目录零污染 |

---

## 知识库规则

### Wiki知识库 vs 03_Assets_全局库

| 目录 | 用途 | 规则 |
|------|------|------|
| `Wiki知识库/` | 知识文档（方法论/规则/参考资料） | 主动读写，萃取维护 |
| `Wiki知识库/wiki/` | 萃取知识 | 从 raw 萃取，持续迭代 |
| `Wiki知识库/raw/` | 原始资料 | 只读，不编辑不移动，禁止删除 |
| `03_Assets_全局库/` | 全局资产（BGM/封面/分形） | **禁止写入知识文档** |

### 知识库寻址优先级

1. `Wiki知识库/wiki/选题库/` — 产品背景
2. `Wiki知识库/wiki/` — 方法论和规则
3. `Wiki知识库/raw/` — 原始资料
4. **禁止**从 `00_InBox_收件箱/` 遍历

### 索引红线

- `index.md` 内禁止链接到 `raw/` 文件夹
- Wiki Lint 检查: `python 06_Python Scripts/06_工具/wiki_lint.py`

---

## 核心原则

1. **根目录零文件** — 所有文件放对应子目录
2. **Python → `06_Python Scripts/`** — 禁止散落
3. **知识文档 → `Wiki知识库/`** — 不向 `03_Assets_全局库/` 写知识文档
4. **定期 GC** — 临时文件用完即删
