## 核心工作流（10步）

```
1.选品 → 2.找对标 → 3.知识库查找 → 4.背景研究 → 5.文案生成 → 6.开头优化 → 7.DBS检定 → 8.配音 → 9.外包交付 → 10.发布复盘
```

## 选品标准

- 客单价：¥50-150（冲动消费区间）
- 佣金率：>15%
- 近30天销量：>100
- 短视频出单占比：>50%
- 商家体验分：>4.5
- 好评率：≥95%

**三大原则**：产品质优 + 平台热卖 + 价格适中（详见 `wiki/选品方法论/选品原则与方法.md`）

## 文案创作标准

### 知识库寻址优先级（强制）

1. `Wiki知识库/wiki/文案创作/选题库/{产品}-文案参考资料.md`
2. `Wiki知识库/wiki/文案创作/`
3. `Wiki知识库/raw/博主文案库/`
4. **禁止**从 `00_InBox_收件箱/` 遍历

### 文案产出要求

- 三套风格：余上沅的奇妙屋 / 九厘米的雾 / Ad Scout
- 同步产出：视频标题 + 商品短标题 + 产品简介
- 命名：`MMDD-{产品}-三套文案.md`
- 必须指定匹配 BGM 的 MP3 路径

## 5秒完播率（核心 KPI）

**生死线**：40% 及格 / 50% 优秀 / 60% 爆款（百万级流量）

| 时间 | 监控 | 操作 |
|------|------|------|
| 发布后 1h | 播放量 >100 | 正常推荐标记 |
| 发布后 3h | 5秒完播率 | <40% → 分析开头问题 |
| 发布后 6h | 播放量 >500 | >50% → 考虑投 DOU+ |
| 发布后 12h | 综合评估 | 决定是否继续投放 |

**优化重点**：前 2 秒视觉冲击 → 2-5 秒信息密度 + 悬念（详见 `wiki/视频制作/5秒完播率优化指南.md`）

## 账号运营

- **稳定输出 > 单条爆款** — 连续 3-5 条稳定输出恢复权重
- **复制爆款系列** — 找爆款要素（痛点+悬念、干货密度、社交货币），做系列第 2/3/4 条
- **标题含精准关键词** — 帮算法快速定位目标人群（详见 `wiki/抖音运营/算法分发机制.md`）
