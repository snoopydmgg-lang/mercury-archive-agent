# 小红书标题公式工具

输入话题，从75个验证过的爆款公式中自动匹配最合适的定制标题。

## 核心能力

- **输入**: 一个话题
- **输出**: 5-8个定制标题，每个附带公式编号、原始爆款案例、推荐理由
- **最终交付**: Top 3 推荐

## 12类心理触发器

| 编号 | 触发器 | 说明 |
|------|--------|------|
| 1 | 认知冲突 | 打破读者认知 |
| 2 | 好奇缺口 | 制造信息差 |
| 3 | 恐惧损失 | 不做会后悔 |
| 4 | 身份代入 | 我就是这样的人 |
| 5 | 数字锚定 | 具体数字说服 |
| 6 | 结果承诺 | 承诺明确效果 |
| 7 | 社会证明 | 大家都在用 |
| 8 | 争议挑衅 | 引发讨论 |
| 9 | 场景条件 | 在XX情况下 |
| 10 | 行动号召 | 立刻行动 |
| 11 | 权威借力 | 专家都说 |
| 12 | 互动测试 | 测试类标题 |

## 工作流程

### Step 1: 接收话题

询问用户想推广的主题/话题：
> 请告诉我你想写什么话题的小红书？

### Step 2: 匹配公式

根据话题，从75个公式中匹配5-8个最合适的公式，涵盖至少3种不同心理触发器类型。

### Step 3: 生成标题

每个标题输出：
```
【公式编号-触发器类型】
标题文案

原始案例：「小红书原爆款标题」
推荐理由：为什么这个公式适合这个话题
```

### Step 4: Top 3 推荐

最终从5-8个标题中精选3个最强推荐，附带理由。

## 公式示例

**公式001-认知冲突**
> 99%的人都不知道的XX（赶紧收藏）
案例：「99%的人都不知道的上海小众书店」

**公式012-数字锚点**
> XX个XX，让你一次就学会XX
案例：「7个技巧，让你一次就学会构图」
