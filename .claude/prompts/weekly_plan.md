# 周计划生成 Prompt - 双轨调度逻辑

## 核心框架

**双轨调度**：先铺基线任务，再填动态任务，确保每日番茄数不超过 11 个。

---

## 1. 提取 (Extract)

**强制约束**：调用 `/getnote` 提取笔记后，**必须严格对比本地 `06_Python Scripts/07_Todoist/sync_state.json` 中的已处理记录。仅对未处理的新笔记执行拆解动作。

步骤：
1. 调用 GetNote API 获取过去7天日记
2. 读取 `sync_state.json`，获取 `processed_note_ids` 列表
3. 过滤掉 ID 已存在于 `processed_note_ids` 中的笔记
4. 仅保留未处理的新笔记进行后续分析

---

## 2. 基线铺排 (Baseline)

读取 `06_Python Scripts/07_Todoist/weekly_baseline.json`，将所有固定任务按设定的星期几写入 Todoist。

**每日番茄上限：11 个**（基于 6小时/天，25+5分钟/轮，连续3轮后休息15分钟的工作流）

从本周总产能（66番茄）中扣除基线任务的番茄数。

---

## 3. 动态填充 (Dynamic)

将 GetNote 提取的新痛点/目标拆解为任务，分配到每天剩余的番茄钟空槽中。

**拆解约束**：
1. **绝对禁止**生成任何与"外包"相关的任务
2. **绝对禁止**安排任何上肢训练任务（腱鞘炎康复期）
3. 必须生成严格的父子层级结构
   - 父任务 = 宏观目标（如 `[PAIN] 改善睡眠质量`）
   - 子任务 = 具体动作（如 `购买低咖啡因饮品`）

**排期约束**：
- 每天总番茄数不能超过 11 个
- 优先填入番茄槽未满的日期

---

## 4. 映射与装箱 (Map & Pack)

根据产能模型分配任务：
- 每周可用 **66 个番茄钟**
- 每番茄 = 25分钟工作 + 5分钟休息
- 连续3轮后休息15分钟
- 每天约11有效番茄

为每个子任务估算番茄钟数量（1-3个），分配到下周的周一至周六。

---

## 5. 更新状态

**强制约束**：拆解并成功排期后，**务必更新 `sync_state.json`**：
1. 将新处理的笔记 ID 追加到 `processed_note_ids`
2. 更新 `last_sync_at` 为当前时间戳
3. 保存文件

---

## 6. 输出报告

执行完毕后，以 Markdown 表格形式输出下周的产能装箱报告：

| 日期 | 来源 | 父任务 | 子任务 | 预估番茄数 |
|------|------|--------|--------|-----------|
| 周一 | 基线 | [KERNEL] 视频开场 | AI生成动画素材 | 2 |
| 周一 | 动态 | [PAIN] 早晨效率 | 识别琐事清单 | 1 |
| ... | ... | ... | ... | ... |

**汇总行**：
- 基线任务: N个, 共X番茄
- 动态任务: N个, 共X番茄
- 总排期: X/66番茄 | 剩余产能: X番茄
