# 周计划生成器 · 单人7更极客框架

## 功能

基于"单人单机每周7条视频（完全无外包）"目标，生成以周为单位、灵活且注重精力保护的工作与生活安排框架。

## 核心框架

### 视频生产四环节批处理
```
[策划] → [素材] → [剪辑] → [发布]
  ↓         ↓        ↓        ↓
脚本+选题   搜集+整理   剪辑+封面   定时+复盘
```

### 周任务池分配

| 日期 | 核心节奏 | 产出目标 |
|------|----------|----------|
| **周一** | 启动与收尾 | 选题确认+上周复盘 |
| **周二** | 脚本爆发日（KERNEL峰值） | 3-4条脚本 |
| **周三** | 素材储备日（MINING密集） | 素材库填充 |
| **周四** | 脚本收尾+封面批量 | 2-3条脚本+封面 |
| **周五** | 剪辑马拉松（RENDER峰值） | 2-3条剪辑 |
| **周六** | 批量发布+实拍储备 | 发布+机动剪辑 |
| **周日** | 休息与规划 | 绝对恢复+下周规划 |

### 任务标签系统

| 标签 | 含义 | 适用任务 |
|------|------|----------|
| `[KERNEL]` | 高脑力运算 | 脚本撰写、策划、背景研究 |
| `[MINING]` | 数据挖掘/素材搜集 | 素材搜索、整理、标签化 |
| `[RENDER]` | 机械劳动/剪辑渲染 | 视频剪辑、封面生成 |
| `[OPS]` | 运营杂务 | 发布、数据复盘、表格更新 |

### 每日精力预算：约12番茄（≈6小时深度工作）

```
早间（起床后30min发呆） → 0番茄，缓冲不工作
上午（9-12）            → 4-5番茄，KERNEL峰值
午间                     → 0番茄，散步+发呆
下午（14-17）           → 3-4番茄，MINING/RENDER
傍晚（17-19）           → 1-2番茄，OPS
晚间                     → 健身/休息，不工作
```

### 每日恢复仪式（必选≥2项）

- [ ] 晨间发呆缓冲：起床后30分钟不看手机
- [ ] 午间散步：12:00-12:30，户外15分钟
- [ ] 碳水后置：午餐减少碳水，保持下午清醒
- [ ] 小睡20分钟：14:00前，感到疲惫时启用
- [ ] 晚间健身：19:00-20:00（力量训练40min）
- [ ] 屏幕外时间：21:00后不刷手机

### 精力透支红线

> **如果出现以下症状，立即切换到低能耗任务：**
> - 对脚本创作感到厌恶 → 切换到MINING/OPS
> - 剪辑变成机械刷手机 → 强制休息20分钟
> - 连续3天起床后仍然疲惫 → 周日必须全休

## SOP提效建议

### 1. 素材库先行（最高优先级）
```
03_Assets_全局库/
├── 01_通用BGM/      ← 每次剪辑直接调用
├── 02_视觉素材/     ← 按类目标签化命名
└── 03_脚本模板/      ← 开头/转场/结尾模板
```
**命名规范**：`[宫崎骏]_天空之城_引用片段.mp4`

### 2. AI辅助写脚本
- 背景研究用 Perplexity 搜索（深度模式）
- 文案生成用三套风格模板（余上沅/九厘米/Ad Scout）
- 每条脚本AI初稿 + 人工微调（不改框架，只改细节）

### 3. 剪辑批处理
- 封面批生成：豆包图生图，一次性生成5-7张
- 剪辑模板化：开头3秒模板 + 转场特效库 + 结尾关注引导
- 并行剪辑：同时打开两个工程，一个渲染、一个剪辑

### 4. 发布自动化
- 飞书表格记录 + 抖音创作者号定时发布
- 封面文案+BGM配置标准化，减少发布决策

## 执行流程

当用户触发时：

1. **读取Todoist** - 获取本周未完成任务
2. **读取上周数据** - 播放量/完播率（04_数据分析结果/）
3. **匹配框架** - 将任务填入周任务池
4. **输出周计划** - 每日任务包 + 视频产出排期

## 注意事项

- 不生成精确到分钟的严苛时间表
- 每日只给任务池和精力档位，不规定具体时刻
- 始终保留发呆/休息/健身的缓冲时间
- 优先考虑可持续性，而非单周最大化产出
