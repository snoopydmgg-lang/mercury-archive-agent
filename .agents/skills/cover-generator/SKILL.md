# 抖音视频封面生成工具

使用豆包图生图 API，基于已有的家族式风格生成新的封面图片。

**本 skill 只负责生成封面，不做其他事情。**

## 功能

| 功能 | 说明 |
|------|------|
| 封面生成 | 基于风格模板生成新封面 |
| 风格延续 | 保持与现有封面的家族风格一致 |
| 批量生成 | 一次生成多个版本供选择 |

## 已有封面风格库

已分析 11 个项目封面，总结出以下风格分类：

### 风格分类

| 类型 | 项目示例 | 特点 |
|------|----------|------|
| **艺术感** | 多雷插画集、莫奈追寻光影、莎士比亚集 | 作品图为焦点，艺术氛围强 |
| **知识感** | 摄影构图艺术、最优雅的科学、版式之道 | 几何图形/示意图，科技感 |
| **文化感** | 中国传统色、小王子、星空帝国 | 东方美学/文学意境 |
| **品质感** | DK伟大的汽车 | 暗背景 + 金属色文字 |

### 共同特征

- **构图**: 左右/上下分区，图文分离
- **边框**: 细线边框或装饰角
- **文字**: 标题大字号 + 副标题小字号
- **背景**: 简洁纯色或渐变，不复杂

## 输入输出规则

- **输入图片**: 放入 `00_InBox_收件箱/` 文件夹，运行时手动指定
- **输出图片**: 自动保存到输入图片同一目录，文件名加 `_output.png`

### 文件命名规则

封面文件命名格式：`MMDD-书名-封面（版本）.png`

| 部分 | 说明 | 示例 |
|------|------|------|
| MMDD | 生产日期（月月日日） | 0314 |
| 书名 | 项目/书籍名称 | 莎士比亚集 |
| 版本 | 封面状态 | 纯净、成品 |

**示例**：
- `0314-莎士比亚集-封面（纯净）.JPG` - 原始封面图
- `0314-莎士比亚集-封面（成品）.png` - AI生成成品

## 常用风格关键词

### 配色
- 浅色背景、深色文字、金色点缀

- **重要**：背景颜色应从书籍封面提取，如金色、白色、书籍装饰花纹

### 字体
- 现代无衬线、优雅衬线、书法风格
- **重要**：字体颜色推荐金色或白色，纯净无描边边框

### 元素
- 细边框、几何图形、装饰角、光影效果
- **重要**：可使用书籍封面上的装饰元素（绘图、花纹）作为背景纹理

### 氛围
- 高级感、简约、学术、艺术、奢华

## 封面生成关键规则（经验总结）

### 1. 比例要求
- **必须使用 3:4 比例**（脚本已自动设置为 1920x2560）

### 2. 书籍封面来源
- 通过淘宝/京东搜索书名，找到对应书籍封面图
- 优先选择清晰、背景简洁的封面

### 3. 背景颜色选择
- **优先从原书籍封面提取颜色**
- 如果封面元素颜色少于3种或饱和度低，使用白色背景
- 推荐：白色背景 + 书籍装饰花纹元素
- 避免：过于鲜艳或刺眼的颜色

### 4. 字体排版规则
- **字体颜色**：金色或白色
- **重要**：字体**绝对不能有描边边框**，必须是纯净的颜色
- **字号**：顶部标题稍大（20%），底部副标题稍小（14%）
- **排列方式**：
  - 两端对齐，均匀分布
  - 第一个字靠左/上边框，最后一个字靠右/下边框
  - 字间距要宽
- 顶部文字靠近上边框，底部文字靠近下边框

### 5. 去除AI水印
- 在提示词中添加：**无任何AI水印或签名**

### 6. 脚本配置
- 封面生成脚本已默认配置：
  - 尺寸：1920x2560（3:4比例）
  - 质量：hd（高清）
  - 代理：使用环境变量 HTTP_PROXY/HTTPS_PROXY
