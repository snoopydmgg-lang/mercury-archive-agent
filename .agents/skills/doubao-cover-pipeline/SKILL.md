# 豆包封面自动化流水线

**架构原则：图文分离 + 新古典人文主义视觉系统**

将用户需求（产品名称 + 核心概念）转化为高质量3:4竖版封面，全自动完成。

## 个人视觉系统设计规范

**原始规范文档**：`03_Assets_全局库/wiki/设计规范/封面设计规范-豆包专用.md`

**以后生成封面时，必须先读取此文档作为原始提示词基础。**

### 色彩系统

| 角色 | 色值 | 名称 |
|------|------|------|
| 主背景 | `#F5F4F0` | 羊皮纸白 |
| 主文本 | `#2D2B2A` | 暖炭灰 |
| 核心点缀 | `#D36B4D` | 赤陶土 |
| 辅助柔和 | `#E6C8B5` | 灰桃色 |

### 字体规范

- **主标题**：衬线体 (Georgia / 宋体)
- **副标题/元数据**：无衬线体 (微软雅黑)

### 质感要求

- **必须**：2-5% 单色噪点 + 纸张纹理
- **禁止**：发光、高饱和渐变、重阴影

### 装饰元素

- 有机分形图形（呼应 Codex 3 图标风格）
- 1px 赤陶色分隔线
- 底部品牌标识 `MERCURY ARCHIVE`

## 流水线三步骤

```
Step 1: 调用豆包API生成纯背景底图 (新古典人文主义Prompt)
         ↓
Step 2: PIL渲染文字 + 有机分形 + 噪点纹理
         ↓
Step 3: 输出到收件箱 (00_InBox_收件箱/)
```

## 使用方法

### 自然语言模式

用户提供：
- **产品名称** → 作为主标题
- **核心概念** → 作为副标题

### 命令行模式

```bash
cd "E:/1.work/douyin/1.shuixing/06_Python Scripts/03_豆包图像"
python auto_cover_engine.py --title "版式之道" --concept "控制视觉熵的物理工程"
python auto_cover_engine.py --title "时间管理" --concept "战胜拖延症" --volume "VOL.02"
```

### 参数说明

| 参数 | 缩写 | 必须 | 说明 |
|------|------|------|------|
| --title | -t | 是 | 产品名称/主标题 |
| --concept | -c | 是 | 核心概念/副标题 |
| --volume | -v | 否 | 卷号，默认 VOL.01 |
| --date | -d | 否 | 日期，默认今天 |
| --output | -o | 否 | 输出路径 |
| --size | -s | 否 | 底图尺寸，默认 1920x2560 |

## 封面规格

| 参数 | 值 |
|------|-----|
| 画布尺寸 | 1080x1440 (3:4) |
| 图片区域 | 顶部 0-700px |
| 文字区域 | 700-1440px |
| 主标题 | 80px, 衬线体, 暖炭灰 |
| 副标题 | 32px, 无衬线体, 冷灰棕 |
| 噪点纹理 | 2.5% 单色噪点 |
| 输出格式 | PNG, 95%质量 |

## 内部Prompt模板（新古典人文主义风格）

```
画面主体：根据'[核心概念]'转化的一个有机抽象形态，
例如折叠的纸张/贝壳纹理/花瓣分形/叶脉结构。
视觉约束：新古典人文主义风格，古典印刷术质感，
大地色系（米色/桃色/赤陶色），有机生命体隐喻。
构图约束：画面上半部分70%展示主体，
画面下半部分30%保持纯色负空间留白。
质感要求：细微纸张纹理，2%-5%噪点颗粒感。
反向约束：禁止文字、水印、3D效果、重阴影、霓虹光效。
```

## 执行流程

当用户说"生成封面"时，自动触发此skill：

1. **解析需求**：提取标题、概念、卷号
2. **读取视觉规范**：从 `03_Assets_全局库/wiki/设计规范/封面设计规范-豆包专用.md` 读取原始提示词
3. **优先使用产品专属脚本**：检查 `01_Projects_制作中/[产品名]/generate_cover.py` 是否存在
4. **生成底图**：调用豆包API（新古典人文主义Prompt）
5. **渲染封面**：PIL绘制文字 + 有机分形 + 噪点纹理
6. **自动复制**：
   - 保存到 `06_Python Scripts/03_豆包图像/output/` (临时)
   - 复制到 `00_InBox_收件箱/YYYYMMDD-产品名-封面.png` (主要)
   - 如有产品专属脚本，额外复制到项目目录
7. **报告完成**：告知用户收件箱路径

## 产品专属脚本

每个产品有独立的 `generate_cover.py`，包含产品调性配置：
- 默认核心概念
- 风格关键词
- 色调描述
- 目标情绪
