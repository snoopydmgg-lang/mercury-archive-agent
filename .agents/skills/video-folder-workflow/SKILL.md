# 视频分析工作流

专注于视频分析和配乐建议。

## 功能概览

| 功能 | 说明 | 代码位置 |
|------|------|----------|
| 视频关键帧提取 | 使用 OpenCV 提取视频关键帧 | `06_Python Scripts/video_analyzer.py` |
| 音频转写 | 使用 Whisper 提取音频文字 | 同上 |
| 配乐/文案建议 | 基于视频内容给出建议 | 本技能提供 |

## 工作流

### 1. 视频分析流程

**当用户要求分析视频、配乐、文案时：**

1. **找到视频文件**
   - 收件箱：`00_InBox_收件箱/`
   - 或者用户指定路径

2. **运行视频分析脚本**
   ```bash
   cd "E:/1.work/douyin/1.shuixing/06_Python Scripts"
   python video_analyzer.py "视频路径" --frames 5
   ```

3. **查看关键帧**
   - 读取 `*_analysis/frames/` 目录下的 JPG 文件
   - 分析画面内容（人物、环境、活动类型）

4. **给出建议**（根据视频内容）
   - **口播/说话类** → 轻柔背景音乐 + 简洁文案
   - **跳舞/运动类** → 欢快节奏音乐 + 活力文案
   - **萌娃/宠物类** → 童趣音乐 + 可爱文案
   - **风景/物品类** → 舒缓纯音乐 + 情感文案

### 2. 文件夹管理流程

**当用户要求清理收件箱（全部删除）时：**

1. **列出目标文件夹内容**
   ```bash

   ```

2. **删除文件**
   ```bash
   rm -rf "E:/1.work/douyin/1.shuixing/00_InBox_收件箱/"*
   ```

3. **确认清理完成**
   ```bash
   ls -la "E:/1.work/douyin/1.shuixing/00_InBox_收件箱/"
   ```

### 3. 收件箱整理流程（按 DropIt 规则分类）

**当用户要求整理收件箱（分类）时：**

运行整理脚本：
```bash
cd "E:/1.work/douyin/1.shuixing/06_Python Scripts"
python 收件箱整理.py
```

**注意**：当前脚本使用的是 DropIt 的 `Default.ini` 规则。

**DropIt 规则格式**：`日期-项目名-内容类型`
- 例如 `20260313-水星艺术馆-成品.mp4` 表示：水星艺术馆项目的成品

**分类规则（按优先级）：**

**A. 数据分析类（文件名包含关键字）：**

处理步骤：
1. 先为文件名添加修改日期后缀（格式：`原名_YYYYMMDD.扩展名`）
2. 然后移动到对应目录

| 关键字 | 目标目录 |
|--------|----------|
| 达人监测 | `04_数据分析结果/达人监测/` |
| 抖音数据 | `04_数据分析结果/抖音数据/` |
| 水星艺术馆 | `04_数据分析结果/水星艺术馆/` |
| 数据表现 | `04_数据分析结果/数据表现/` |
| 作品列表 | `04_数据分析结果/作品列表/` |
| data | `04_数据分析结果/data/` |

**B. DropIt 规则（文件名格式：日期-项目名-内容类型）：**
| 规则 | 关键字 | 目标目录 |
|------|--------|----------|
| 1 | `*-*-成品*` | `02_Archive_冷备份/年/月/` |
| 2 | `*-*-封面*` | `01_Projects_制作中/项目名/01_素材_试用装/00_封面设计/` |
| 3 | `*-*-素材*` 或 `*-*-音频*` | `01_Projects_制作中/项目名/01_素材_试用装/` |
| 4 | `*-*-文案*` 或 `*-*-脚本*` | `01_Projects_制作中/项目名/02_脚本_逻辑链/` |
| 5 | `*-*-工程*` | `01_Projects_制作中/项目名/03_工程文件/` |
| 6 | `~$*` (临时文件) | 自动删除 |

**文件命名规范**：
```
日期-项目名-内容类型.扩展名
例如：20260313-水星艺术馆-成品.mp4
例如：20260313-水星艺术馆-素材.jpg
例如：20260313-水星艺术馆-文案.txt
```

### 4. 收件箱整理后自动更新项目文件夹结构

**每次整理完收件箱后，必须自动更新 AGENTS.md 中的目录结构。**

1. **列出项目目录内容**
   ```bash
   ls -la "E:/1.work/douyin/1.shuixing/01_Projects_制作中/"
   ```

2. **列出全局资源目录内容**
   ```bash
   ls -la "E:/1.work/douyin/1.shuixing/03_Assets_全局库/"
   ```

3. **列出根目录所有文件夹**（确认是否有新增目录）
   ```bash
   ls -la "E:/1.work/douyin/1.shuixing/"
   ```

4. **读取当前 AGENTS.md 中的目录结构部分**
   - 找到 `## 2. 目录结构 (PARA 风格)` 章节
   - 读取当前内容

5. **更新 AGENTS.md**
   - 根据实际目录结构更新 `## 2. 目录结构` 部分
   - 保持格式一致：使用 `├──` 表示子目录
   - 重点更新：
     - `01_Projects_制作中/` 下的所有子项目文件夹
     - `03_Assets_全局库/` 下的子目录
     - 确认是否有新增的顶层目录

**注意**：这是必做步骤，每次整理收件箱后都要执行，即使没有变化也要确认更新。

## 配乐与文案建议模板

### 萌娃跳舞类
- **音乐**：欢快童趣、儿歌remix、可爱钢琴曲
- **文案**：
  - "人生第一支舞"
  - "陪你一起疯"
  - "这大概就是最幸福的模样"

### 口播说话类
- **音乐**：轻柔纯音乐、咖啡馆BGM、治愈系
- **文案**：
  - "分享一个最近的心头好"
  - "3个提升自己的小方法"

### 知识分享类
- **音乐**：轻爵士、简约钢琴
- **文案**：
  - "今天想和你聊聊..."
  - "干货预警"

### 情感语录类
- **音乐**：抒情钢琴、弦乐
- **文案**：
  - "慢下来，感受生活的美好"
  - "给自己一个放松的时刻"

## 依赖安装

首次使用视频分析功能时需要安装依赖：
```bash
pip install opencv-python moviepy openai-whisper scipy imageio-ffmpeg
```
或者：
```bash
pip install -r "E:/1.work/douyin/1.shuixing/06_Python Scripts/requirements_video_analyzer.txt"
```

## 注意事项

1. **中文路径问题**：OpenCV 在写入中文路径文件时有问题，脚本已使用临时目录解决
2. **Whisper 转写**：需要 FFmpeg，建议通过 `imageio-ffmpeg` 自动安装
3. **视频音频**：如果视频没有清晰人声，Whisper 转写可能为空
