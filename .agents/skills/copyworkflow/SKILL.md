# 文案生成工作流

完整的抖音视频文案生成工作流，串联背景信息收集、文案生成、配音全流程。

## 功能

| 步骤 | 功能 | 说明 |
|------|------|------|
| 1 | 收集背景信息 | 使用 Perplexity API 收集产品/书籍背景资料 |
| 2 | 上传飞书 | 将背景信息上传到飞书多维表格 |
| 3 | 生成文案 | 调用 Codex API 生成口播文案、详细分镜、BGM、音效 |
| 4 | 配音 | 从 MD 文件读取文案，调用 Fish Speech API 生成配音 |
| 5 | 完整流程 | 一步完成所有步骤 |

## 代码位置

- **工作流入口**: `06_Python Scripts/copyworkflow_runner.py`
- **核心模块**: `06_Python Scripts/copyworkflow/`
  - `workflow.py` - 工作流编排
  - `perplexity_client.py` - 背景信息收集
  - `feishu_client.py` - 飞书操作
  - `script_generator.py` - 文案生成（含详细分镜格式）
  - `md_exporter.py` - MD 文件导出/读取
  - `audio_generator.py` - 配音生成

## 输出格式（强制执行）

### 画面分镜要求

生成的文案必须包含以下详细格式：

| 时间 | 画面分镜指令（摄影师看） | 口播文案（参考） | BGM与音效指令（剪辑师看） |
| :--- | :--- | :--- | :--- |
| 00-05s | **[景别+运镜+动作]**<br>例：微距特写，镜头缓慢扫过书脊烫金字，手指轻轻抚摸纹理。 | (当前对应的文案) | **[BGM]**：具体乐器+情绪（例：大提琴独奏，低沉叙事感）。<br>**[SFX]**：具体动作音（例：指腹摩擦纸张的沙沙声）。 |

**约束**:
1. **画面分镜**：必须包含景别（特写/全景/中景）+ 运镜（推/拉/摇/移/固定）+ 主体动作
2. **BGM**：禁止"好听的音乐"，必须描述：乐器 + 节奏 + 情绪
3. **SFX**：必须精确到具体动作音
4. **节奏卡点**：文案有转折时标注"音乐骤停"或"变奏"


```
2. 上传背景信息到飞书
3. 生成文案 -> MD文件 (不配音)
4. 配音 (从MD文件读取文案)
```

### 完整流程示例

```
# 选择选项 5，输入项目名称，选择风格
# 自动完成：
# 1. 收集背景信息 → 保存到项目文件夹
# 2. 上传到飞书多维表格
# 3. 生成文案 → 输出到 MD 文件
# 4. 配音 → 自动更新飞书（口播文案、画面脚本、BGM建议、音效建议、配音链接）
```

## 飞书更新逻辑

配音完成后自动更新飞书多维表格的最后一条记录，包含：
- 选题标题
- 口播文案
- 画面脚本（详细格式）
- BGM建议
- 音效建议
- 配音链接

## 注意事项

1. **文案可编辑**：步骤3生成MD文件后，用户可手动修改口播文案再配音
2. **飞书记录**：配音会自动更新飞书最后一条记录
3. **命名规则**：生成文件按 `日期-项目名-类型.md` 格式命名
4. **详细分镜**：新的分镜格式包含时间、景别、运镜、BGM、SFX

## 视频开场 Skill 集成

当文案脚本需要视频开场（标题动画）时，在文案完成后：

```
生成开场：[主题]
```

这会自动调用 `mercury-vis` 项目渲染 MP4 开场视频，输出到 `dist/` 目录。

适用场景：艺术主题、画家介绍、文学系列、大师作品等需要视觉包装的主题开场。
