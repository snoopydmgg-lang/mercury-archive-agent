# 豆包图生图工具

使用火山引擎豆包的图生图 API，将图片转换为指定风格。

**本脚本只做一件事：图生图。不负责其他任何任务。**

## 功能

| 功能 | 说明 |
|------|------|
| 图生图 | 将输入图片转换为指定风格 |
| 风格转换 | 支持各种艺术风格转换 |
| 保持构图 | 基于原图构图生成新图片 |

## 代码位置

`E:\1.work\douyin\1.shuixing\06_Python Scripts\doubao_img2img.py`

## 输入输出规则

- **输入图片**：放在 `00_InBox_收件箱/` 文件夹内，运行时手动指定图片路径
- **输出图片**：自动保存到和输入图片相同的文件夹，文件名加 `_output` 后缀，格式为 PNG

## 使用方法

### 基本流程

1. **放置输入图片** - 将原图放入 `00_InBox_收件箱/` 文件夹
2. **获取风格描述** - 询问用户希望的风格效果
3. **运行脚本**:
   ```bash
   cd "E:/1.work/douyin/1.shuixing/06_Python Scripts"
   python doubao_img2img.py --image "00_InBox_收件箱/图片名.png" --prompt "<风格描述>"
   ```
4. **获取输出** - 生成的图片保存在原图同目录下，文件名为 `<原文件名>_output.png`

### 参数说明

| 参数 | 说明 | 必填 |
|------|------|------|
| `--image` | 输入图片的路径（建议使用收件箱路径） | 是 |
| `--prompt` | 图像生成的提示词，描述希望生成的图片效果 | 是 |

### 示例

```bash
# 将收件箱中的图片转换为水彩画风格
python doubao_img2img.py --image "00_InBox_收件箱/photo.png" --prompt "水彩画风格，柔和的色彩"

# 将收件箱中的图片转换为油画风格
python doubao_img2img.py --image "00_InBox_收件箱/landscape.jpg" --prompt "油画风格，浓烈的色彩和笔触"

# 将收件箱中的图片转换为卡通风格
python doubao_img2img.py --image "00_InBox_收件箱/portrait.png" --prompt "卡通风格，动漫形象"
```

## 提示词技巧

### 常用风格关键词

- **艺术风格**: 水彩画、油画、卡通、动漫、素描、版画、3D渲染、赛博朋克
- **画面感**: 梦幻、浪漫、写实、抽象、极简、复古、时尚
- **色调**: 暖色调、冷色调、鲜艳、柔和、黑白

### 效果描述

可以组合使用：
- `柔和的光线效果`
- `渐变背景`
- `高对比度`
- `柔和的阴影`

- 文件命名：`<原文件名>_output.png`

## 注意事项

1. **图片格式**：支持 PNG、JPG 等常见格式
2. **图片大小**：建议不超过 10MB
3. **API 密钥**：已内置在代码中（注意安全）
4. **等待时间**：API 调用通常需要几秒钟
5. **错误处理**：如果生成失败，检查网络连接或 API 密钥是否有效
6. **AI 水印**：生成的图片右下角可能有水印，使用 CSS clip-path 裁剪隐藏即可，无需修改原图

## 自动规则（必须遵守）

**脚本会自动在提示词中添加以下规则，无需用户手动输入：**

1. **图片比例**：自动添加 3:4 纵向比例，适用于抖音封面
2. **禁止AI文字**：绝对不出现任何"AI"、"AI生成"、"人工智能"等文字
3. **禁止表情包**：不添加任何表情包符号或 emoji
4. **禁止画面文字**：绝对不要在画面中出现任何文字、字母、汉字
5. **Slogan 规则**：封面最上方必须使用书籍的名字作为标题
6. **书名规则**：如果有文字标语，必须使用书籍的名字作为 Slogan

## 封面生成进阶

### 提示词模板（抖音带货封面）

```
竖屏 9:16 构图。画面正中央放置一本精美的[产品描述]，[背景描述]。画面顶部 30% 和底部 30% 必须是纯净的[主色调]背景，没有任何物体。整体呈现高端出版物和电影海报的质感，极简主义。背景必须有[光影效果]。[禁止事项]
```

### 文字叠加

如需在图片上添加文字，使用 `add_text_to_cover.py`：
```python
# 布局参数参考
```

### 隐藏 AI 水印（CSS 方案）

```css

  height: 640px;
  overflow: hidden;
}
.cover-wrapper img {
  clip-path: inset(0 0 80px 0); /* 底部裁剪约80px */
}
```
