## 工具配置

### Get笔记 API

用于自动读取本周笔记，识别痛点和待办事项。

```bash
PYTHON="C:/Users/Administrator/AppData/Local/Programs/Python/Python310/python.exe"
GETNOTE="E:/1.work/douyin/1.shuixing/06_Python Scripts/08_Get笔记/getnote_api.py"

# 获取本周笔记
"$PYTHON" "$GETNOTE" list 50

# 语义搜索痛点相关笔记
"$PYTHON" "$GETNOTE" recall "痛点 问题 待解决"
```

**Get笔记脚本位置**: `06_Python Scripts/08_Get笔记/getnote_api.py`

## 复盘流程

### Step 1: 读取本周 Get笔记

从 Get笔记 获取本周所有笔记：

```bash
python "06_Python Scripts/08_Get笔记/getnote_api.py" list 50
```

识别以下内容：
- 记录的**痛点问题**（关键词：痛点、卡点、困难、问题）
- 想到的**改进方案**（关键词：需要、应该、优化、改进）
- **待解决**的事项（关键词：TODO、计划、下一步）
- **学到**的新知识

### Step 2: 打开复盘模板

读取 `memory/复盘SOP.md` 作为模板框架。

### Step 3: 填写本周数据

根据本周实际数据填写：

| 指标 | 数值 | 环比上周 |
|------|------|----------|
| 发布作品数 |  |  |
| 总播放量 |  |  |
| 最高播放 |  |  |
| 总点赞数 |  |  |
| 成交单数 |  |  |
| 总成交额 |  |  |
| 投入成本 |  |  |
| ROI |  | |

### Step 4: 流程回顾（7环节打分）

| 环节 | 得分(1-5) | 问题 | 改进方向 |
|------|----------|------|----------|
| 1. 选品 | | | |
| 2. 素材收集 | | | |
| 3. 文案创作 | | | |
| 4. 外包制作 | | | |
| 5. 实拍 | | | |
| 6. 发布 | | | |
| 7. 复盘 | | | |

### Step 5: 问题归因

找出 1-3 个核心问题，格式：

**问题X：[描述]**
- 属于环节：__
- 根本原因：__
- 解决方案：__

### Step 6: 工作流迭代

如果有需要修改 SOP 的内容，更新 `memory/水星艺术馆抖音带货工作流.md`

### Step 7: 保存复盘结果

复盘文件命名格式：`memory/复盘_YYYYMMDD.md`
